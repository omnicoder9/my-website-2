200 JAVA PROGRAMMING TECHNICAL INTERVIEW QUESTIONS
(Core Java only. No frameworks such as Spring, Hibernate, etc.)
=====================================================================


SECTION 1: CORE LANGUAGE & OBJECT-ORIENTED PROGRAMMING (1-25)
---------------------------------------------------------------------
1.  What is the difference between the JDK, the JRE, and the JVM?
2.  Why is Java described as "write once, run anywhere"? What makes it platform independent?
3.  Explain the four pillars of OOP (encapsulation, inheritance, polymorphism, abstraction) and how Java supports each.
4.  What is the difference between an abstract class and an interface? When would you choose one over the other?
5.  Can an interface contain method implementations? Explain default, static, and private interface methods.
6.  What is the difference between method overloading and method overriding?
7.  Can you override a static method? What happens if a subclass declares a static method with the same signature (method hiding)?
8.  Can you override a private or final method? Why or why not?
9.  What is a covariant return type?
10. What are the rules for access modifiers and return types when overriding a method?
11. Explain the difference between == and equals().
12. What is the contract between equals() and hashCode()? What breaks if you violate it?
13. What does the final keyword mean when applied to a variable, a method, and a class?
14. What is the difference between final, finally, and finalize()?
15. Explain the static keyword: static variables, static methods, static blocks, and static nested classes.
16. What is the order of initialization when an object is created (static blocks, instance initializers, constructors, superclass constructors)?
17. Can a constructor be private? What are the use cases?
18. What is constructor chaining? How do this() and super() work, and why must they be the first statement?
19. What is the difference between composition and inheritance? Why is composition often preferred?
20. Why does Java not support multiple inheritance of classes? How does it resolve the diamond problem with default methods?
21. What are the different kinds of nested classes (static nested, inner, local, anonymous)? How do they differ?
22. Is Java pass-by-value or pass-by-reference? Explain with an example involving objects.
23. What is an immutable class? Walk through the steps to design one correctly.
24. What is the purpose of the Object class? List its methods and briefly explain each.
25. What is the difference between a shallow copy and a deep copy? How does clone() work, and what are its pitfalls?

33. Why does "Integer a = 127, b = 127; a == b" return true, while the same code with 128 returns false?
34. What is the difference between int and Integer? When would you use each?
35. Explain widening and narrowing type conversions. What happens on integer overflow?
36. Why should you avoid float and double for monetary calculations? What should you use instead?
37. What does 0.1 + 0.2 == 0.3 evaluate to in Java, and why?
38. How does Java represent characters internally (UTF-16, code points, surrogate pairs)?
39. How does a switch statement on Strings work under the hood?
40. What are text blocks, and what problems do they solve?
