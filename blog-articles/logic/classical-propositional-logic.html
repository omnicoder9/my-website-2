1. Introduction

Propositional logic (also called sentential logic or the propositional calculus) studies the ways in which whole statements can be joined or modified to form more complex statements, and the logical relationships that hold among statements in virtue of that structure alone[1,2]. It treats the simplest statements as unanalysed units: it does not look inside them at subjects, predicates or quantifiers, which are the business of first-order (predicate) logic[1,3].

The logic is classical because it adopts two semantic commitments. The first is bivalence: every proposition has exactly one of two truth values, true (T) or false (F)[2,3]. The second is truth-functionality: the truth value of a compound statement is completely determined by the truth values of its components, so that each connective can be identified with a function from truth values to truth values[1,2]. Non-classical propositional logics (many-valued, intuitionistic, relevance and others) arise by relaxing one or both of these commitments[2].

Historically, the Stoics, and Chrysippus in particular, made the first serious study of statement-forming operators[1]. The modern subject begins with Frege's Begriffsschrift of 1879, which gave the first modern axiomatic calculus for logic and showed that the truth-functional connectives could be defined from negation and the conditional[1,4]. Truth tables came into wide use in the early 1920s through Post's 1921 paper and Wittgenstein's Tractatus, though Peirce appears to have used comparable methods earlier[1,5,6]. Post's paper also used the method to show that the propositional part of Principia Mathematica proves every tautology and is decidable[2,5].

The article proceeds from language to meaning. Sections 2 and 3 introduce propositions and the five standard connectives; section 4 defines the formal language; section 5 gives its semantics; section 6 defines the central logical properties; section 7 collects the standard equivalences; and section 8 develops the normal forms used in proof theory and automated reasoning.

2. Propositions

A proposition (or statement) is what is asserted by a declarative sentence, and is therefore either true or false[7,8]. Questions, commands and exclamations do not normally express propositions, because they are neither true nor false[7]. Different sentences can express the same proposition, as “It is raining” and “Il pleut” do; propositional logic, however, is indifferent to such distinctions, since it only ever looks at the truth values that propositions take[1,7].

2.1 Atomic propositions

An atomic (or simple) proposition is one that does not contain any other proposition as a component[8]. In propositional logic atomic propositions are treated as indivisible units, whatever internal grammatical structure they may have[1]. Thus “Every prime greater than 2 is odd” is atomic for propositional purposes, even though predicate logic would analyse it into a quantifier, predicates and variables[1,3].

2.2 Compound propositions

A compound proposition contains at least one simple proposition as a component, joined to or modified by a logical operator[7,8]. For example:

Example 2.1

“It is not the case that the server is up, and if the backup ran then the data is safe.”

With the key S: the server is up, B: the backup ran, D: the data is safe, this compound proposition is formalised as ¬S ∧ (B → D). It has three atomic components and three connectives.

Compound propositions built with the classical connectives are truth-functional compounds: their truth value is fixed by those of their atomic components[1]. Many natural-language operators are not truth-functional. “Ann believes that S” and “S because B” can change truth value even when the truth values of S and B are held fixed, so classical propositional logic treats such sentences as atomic[1,7].

2.3 Propositional variables

In the formal language, atomic propositions are represented by propositional variables, also called sentence symbols, statement letters or propositional atoms: P, Q, R, … or p0, p1, p2, …[9–11]. A countably infinite supply is usually assumed, so that no formula ever runs out of letters[9,11]. They are called variables because they are not tied to any particular proposition: they range over truth values, and a semantics (section 5) assigns them values[9,10].

Two finer distinctions are worth making explicit:

  • Constants and variables in applied logic. Introductory texts often write a specific English statement as an uppercase statement constant (S for “the server is up”) and use lowercase statement variables (p, q, r) to express argument and statement forms, of which particular statements are substitution instances[7,8].
  • Object language and metalanguage. When we state general laws about all formulas we use metavariables, here Greek letters φ, ψ, χ, which stand for arbitrary formulas of the object language rather than being symbols of it[9,11]. So φ ∧ ψ is not itself a formula; it is a schema whose instances, such as P ∧ (Q ∨ R), are.

Some presentations also include the propositional constants ⊤ (verum, always true) and ⊥ (falsum, always false) as atoms; van Dalen, for instance, takes ⊥ as primitive and defines negation by ¬φ := φ → ⊥[11].

3.1 Negation: ¬P

The negation ¬P is true when P is false and false when P is true[1,9]. In English it is expressed by not, it is not the case that, it is false that, and by prefixes such as un- or in-, though the last must be handled with care: “unhappy” is not simply the negation of “happy”, because someone may be neither[7,8]. Negation applied twice returns the original truth value (the law of double negation, section 7).

3.2 Conjunction: P ∧ Q

A conjunction P ∧ Q is true exactly when both conjuncts are true[1,9]. English expresses conjunction not only with and but also with but, yet, although, moreover and however; the contrastive nuance of but contributes nothing to truth conditions and is lost in translation[7,8]. Classical conjunction is also insensitive to order, whereas English and sometimes conveys temporal sequence (“she married and got pregnant” versus the reverse), which again is not part of the truth-functional connective[7].

3.3 Disjunction: P ∨ Q

A disjunction P ∨ Q is true exactly when at least one disjunct is true; it is false only when both are false[1,9]. This is inclusive disjunction (Latin vel). Exclusive disjunction, true when exactly one disjunct is true, is not a primitive connective but is definable, for example as (P ∨ Q) ∧ ¬(P ∧ Q)[7,8]. The same function is the negation of the biconditional, as the table confirms:

English unless is standardly translated as inclusive disjunction: “P unless Q” becomes P ∨ Q, which is equivalent to ¬Q → P[8].

3.4 Conditional: P → Q

The conditional P → Q has antecedent P and consequent Q. In classical logic it is the material conditional: it is false in exactly one case, when the antecedent is true and the consequent false, and true otherwise[1,9,12]. Equivalently, P → Q has the same truth table as ¬P ∨ Q and as ¬(P ∧ ¬Q)[8,10].

The many English forms of the conditional must be translated with care[7,8]:

EnglishFormalisation
if P then Q; Q if P; Q provided that P; given P, QP → Q
P only if QP → Q
P is a sufficient condition for QP → Q
P is a necessary condition for QQ → P
P unless Q¬Q → P

The two lower rows of Table 1 for the conditional, where P is false, are where intuition is weakest. Because P → Q is true whenever its antecedent is false, the material conditional is said to be vacuously true in those cases. This gives rise to the so-called paradoxes of material implication: Q alone entails P → Q, and ¬P alone entails P → Q, whatever P and Q say. Edgington notes that on the material reading, someone who thinks it unlikely that a party will win an election is committed to accepting “if that party wins, income tax will double”, which seems wrong as an account of ordinary indicative conditionals[12]. Classical logic accepts this cost in exchange for truth-functionality, and the material reading is the one adopted in standard mathematical logic texts[9,10]. It suits mathematical usage, where “for every n, if n is prime and n > 2 then n is odd” must count as true even for the values of n that fail the antecedent.

The conditional is neither commutative nor associative: P → Q is not equivalent to its converse Q → P, and (P → Q) → R is not equivalent to P → (Q → R). Both facts can be read off a truth table; the second fails, for example, when P and R are false.

3.5 Biconditional: P ↔ Q

The biconditional P ↔ Q, also called material equivalence, is true exactly when P and Q have the same truth value[1,9]. It expresses “P if and only if Q” (often abbreviated iff) and “P is necessary and sufficient for Q”[7,8]. It is equivalent to the conjunction of two conditionals and to a disjunction of two conjunctions[8,10]:

P ↔ Q  ≡  (P → Q) ∧ (Q → P)  ≡  (P ∧ Q) ∨ (¬P ∧ ¬Q).

Unlike the conditional, the biconditional is both commutative and associative.

3.6 Functional completeness

A set of connectives is functionally complete (or adequate) if every truth function can be expressed by a formula using only connectives from that set[9,10]. The set {¬, ∧, ∨} is functionally complete, so the other connectives may be viewed as abbreviations[2,9]; the proof is the disjunctive normal form theorem of section 8. Since φ ∨ ψ ≡ ¬(¬φ ∧ ¬ψ) and φ ∧ ψ ≡ ¬(¬φ ∨ ¬ψ), the pairs {¬, ∧} and {¬, ∨} are also complete, and so is {¬, →}, Frege's choice[1,10]. Sets such as {∧, ∨, →, ↔} are not complete: every formula built from them alone is true when all its variables are true, so no such formula can express negation[9,10].

Remarkably, a single binary connective suffices. Sheffer showed in 1913 that Boolean algebra can be based on one operation, now written P | Q (“not both”, NAND), from which ¬P ≡ P | P and P ∧ Q ≡ (P | Q) | (P | Q); the dual operation NOR (“neither … nor”) is likewise complete on its own[1,10,13]. Klement notes that Peirce appears to have discovered this decades before Sheffer published it[1].

4. Syntax

The syntax of propositional logic specifies which strings of symbols count as formulas, without reference to meaning. The alphabet consists of propositional variables, the connective symbols ¬, ∧, ∨, →, ↔, and the parentheses ( )[9,11].

4.1 Well-formed formulas and formation rules

Not every string over the alphabet is meaningful: P ∧ ∨ Q) is not. The meaningful strings are the well-formed formulas (wffs), defined inductively by formation rules[1,9–11]:

Definition 4.1 (well-formed formula)

  1. Every propositional variable is a wff. (These are the atomic formulas.)
  2. If φ is a wff, so is (¬φ).
  3. If φ and ψ are wffs, so are (φ ∧ ψ), (φ ∨ ψ), (φ → ψ) and (φ ↔ ψ).
  4. (Closure) Nothing is a wff unless it can be obtained by finitely many applications of rules 1–3.

Equivalently, the set of wffs is the smallest set of strings that contains the variables and is closed under the five formula-building operations[9,11]. Enderton also characterises wffs through construction sequences: a string is a wff exactly when it is the last entry of a finite sequence each of whose entries is a variable or is obtained from earlier entries by one of the formula-building operations[9].

Example 4.1 (a construction sequence)

The string ((P ∧ Q) → (¬R)) is a wff, as the following sequence shows:

  1. P rule 1
  2. Q rule 1
  3. R rule 1
  4. (P ∧ Q) rule 3 from 1, 2
  5. (¬R) rule 2 from 3
  6. ((P ∧ Q) → (¬R)) rule 3 from 4, 5

By contrast, (P ∧ Q is not a wff: every wff has equally many left and right parentheses, a property that holds of atoms and is preserved by each formation rule, so it holds of all wffs by induction[9].

That last argument illustrates proof by induction on formulas: to show that every wff has a property, show that the atoms have it and that each formation rule preserves it[9,11]. Its companion is definition by recursion on formulas, used throughout semantics. Recursion is legitimate only because of the unique readability theorem: every wff is either atomic or is of exactly one of the forms (¬φ), (φ ∧ ψ), (φ ∨ ψ), (φ → ψ), (φ ↔ ψ), and the immediate components φ and ψ are uniquely determined[9,11]. The parentheses required by Definition 4.1 are what guarantee this; without them a string like P ∧ Q ∨ R could be parsed in two ways.

4.2 Main connective

By unique readability, every non-atomic wff has exactly one connective that was applied last in its construction. This is its main connective (or principal operator), and it determines what kind of formula the wff is: a negation, conjunction, disjunction, conditional or biconditional[1,8]. The structure is displayed by the formula's parse tree (or formation tree), whose root is labelled by the main connective and whose leaves are atoms[11,14].

The main connective decides how a formula is evaluated and how it can be used in a proof. ¬(P ∧ Q) is a negation, while ¬P ∧ Q is a conjunction, and the two are not equivalent; only the first is subject to De Morgan's law as a whole.

4.3 Scope

The scope of an occurrence of a connective is the subformula of which it is the main connective: the smallest wff containing that occurrence and its components[1,8]. In the parse tree, the scope is the subtree rooted at that connective. The subformulas of a wff are defined recursively: φ is a subformula of itself, and the subformulas of φ's immediate components are subformulas of φ[11].

Example 4.2 (scope)

In ¬(P → Q) ∨ R, the scope of ¬ is ¬(P → Q), the scope of → is P → Q, and the scope of ∨ is the whole formula, so ∨ is the main connective. Moving the parenthesis changes the scope of the negation: ¬((P → Q) ∨ R) is a negation whose scope is the whole formula, and it is not equivalent to the original.

Scope ambiguities are a standard source of translation errors. “Not both A and B” is ¬(A ∧ B), whereas “both not A and not B” (equivalently, “neither A nor B”) is ¬A ∧ ¬B[7,8].

4.4 Parentheses and precedence

Fully parenthesised formulas are unambiguous but hard to read, so texts adopt conventions for omitting parentheses[9,10,14]. The usual conventions are:

  1. Outer parentheses may be dropped: P ∧ Q abbreviates (P ∧ Q)[1,9].
  2. Precedence. Connectives bind with decreasing strength in the order ¬, ∧, ∨, →, ↔; parentheses are restored around the most tightly binding connectives first[10]. Some authors give ∧ and ∨ equal strength and require explicit parentheses between them[14].
  3. Grouping of repeated connectives. Because ∧ and ∨ are associative (section 7), P ∧ Q ∧ R is harmless either way. For → the choice matters; Huth and Ryan, for example, take → to be right-associative, so that P → Q → R means P → (Q → R)[14]. Since conventions differ, careful writers parenthesise iterated conditionals explicitly.

Example 4.3 (restoring parentheses)

Under the precedence order above:

  • ¬P ∧ Q → R ∨ S  reads as  (((¬P) ∧ Q) → (R ∨ S)), a conditional.
  • P ∨ Q ∧ R  reads as  (P ∨ (Q ∧ R)), a disjunction, which is not equivalent to ((P ∨ Q) ∧ R).
  • P ↔ Q → R  reads as  (P ↔ (Q → R)), a biconditional.

An alternative is to eliminate parentheses altogether by writing connectives before their arguments (Polish, or prefix, notation), so that (P ∧ Q) → ¬R becomes →∧PQ¬R. Unique readability then holds with no parentheses at all, and Enderton discusses this notation alongside the parenthesised one[9].

5. Semantics

Semantics assigns meanings, here truth values, to formulas. Classical semantics has two ingredients: a way of giving values to the atoms, and a rule for computing the value of every compound from the values of its parts[3,9,11].

5.1 Truth assignments

Definition 5.1 (truth assignment)

A truth assignment (or valuation) is a function v from a set of propositional variables to the set of truth values {T, F}[9,11].

If a formula contains n distinct variables, there are exactly 2n assignments to those variables, since each variable independently receives one of two values[8,9]. A formula with 3 variables therefore has 8 relevant assignments; one with 20 variables has 1 048 576.

5.2 Truth functions

An n-ary truth function (or Boolean function) is a function from {T, F}n to {T, F}[9,10]. Because there are 2n possible inputs and each can be sent to either value, there are 22n distinct n-ary truth functions: 4 unary and 16 binary[9]. The four unary functions are the identity, negation, the constant T and the constant F. Among the 16 binary functions, the four connectives of Table 1 are just the most useful; others include exclusive disjunction, NAND and NOR.

Every formula φ whose variables are among P1, …, Pn realises an n-ary truth function: the one that sends each input sequence to the value φ takes when the variables receive those values[9]. Functional completeness (section 3.6) is the statement that every truth function is realised by some formula.

5.3 Truth tables

A truth table lays out the truth function realised by a formula. It has one row for each of the 2n assignments and a column for each subformula, computed from the inside out, the main connective's column coming last[1,7,8]. A standard way of listing the rows so that none is missed is to alternate the rightmost variable T, F, T, F, …, the next one in pairs, the next in fours, and so on[7,8].

Example 5.1 (computing a truth table)

Consider (P → Q) ∧ ¬Q → ¬P, which by the precedence conventions is ((P → Q) ∧ ¬Q) → ¬P, the form of modus tollens. Its main connective is the second →.

Truth tables give a mechanical decision procedure: for any formula one can determine in finitely many steps whether it is true under every assignment[2,5]. The cost, however, is a table whose length doubles with each new variable. When we only need to know whether some assignment makes a formula false, the indirect (or short) truth-table method is often faster: assume the formula is false, work backwards to the values this forces on its components, and see whether a contradiction results[8].

Example 5.2 (indirect method)

Is (P → Q) → ((Q → R) → (P → R)) ever false? Suppose it is. A conditional is false only with a true antecedent and a false consequent, so P → Q is T and (Q → R) → (P → R) is F. The latter forces Q → R = T and P → R = F, which forces P = T and R = F. From P → Q = T and P = T we get Q = T, but then Q → R is F, contradicting our assumption. So no assignment falsifies the formula: it is a tautology (hypothetical syllogism).

5.4 Interpretations

A truth assignment gives values only to atoms. It is extended to all formulas by recursion on their structure, following the truth tables of the connectives[9,11,15]. Writing v̄ for the extension:

Definition 5.2 (valuation of formulas)

  • v̄(P) = v(P) for each variable P;
  • v̄(¬φ) = T iff v̄(φ) = F;
  • v̄(φ ∧ ψ) = T iff v̄(φ) = T and v̄(ψ) = T;
  • v̄(φ ∨ ψ) = T iff v̄(φ) = T or v̄(ψ) = T;
  • v̄(φ → ψ) = T iff v̄(φ) = F or v̄(ψ) = T;
  • v̄(φ ↔ ψ) = T iff v̄(φ) = v̄(ψ).

By unique readability, each assignment has exactly one such extension[9,11]. Moreover, the value of φ depends only on the values of the variables that actually occur in φ: two assignments that agree on those variables give φ the same value[9,15]. This is why a truth table need only list assignments to the formula's own variables.

A truth assignment, together with its extension, is what logicians call an interpretation of the propositional language[3,15]. The term connects propositional logic with first-order logic: in the semantics of first-order logic a zero-place predicate letter is interpreted simply as a truth value, so a propositional interpretation is the special case of a first-order interpretation in which all the non-logical symbols are zero-place[3]. In applied work, an interpretation also has an informal counterpart: the translation key that says which English statement each letter abbreviates, as in Example 2.1. The key fixes the truth values only indirectly, via the facts of the world[8].

5.5 Models

Definition 5.3 (satisfaction and model)

An interpretation v satisfies a formula φ, written v ⊨ φ, if v̄(φ) = T. A satisfying interpretation is called a model of φ. An interpretation is a model of a set Γ of formulas if it satisfies every member of Γ[3,11,15].

Example 5.3 (models)

Let Γ = {P ∨ Q, P → R, ¬R}. A model of Γ must make R false; then P → R forces P false; then P ∨ Q forces Q true. So Γ has exactly one model over {P, Q, R}: v(P) = F, v(Q) = T, v(R) = F. Every model of Γ therefore also satisfies Q, which is to say Γ ⊨ Q (section 6.7).

The double turnstile is overloaded in a standard way: v ⊨ φ relates an interpretation to a formula, while Γ ⊨ φ relates a set of formulas to a formula (logical implication) and ⊨ φ says that φ is a tautology[9,11].

6. Logical properties

The semantic definitions of section 5 classify formulas, and relations between formulas, by how their truth values vary across interpretations[8–10].

6.1 Tautologies

A formula is a tautology (or is valid, or logically true) if it is true under every interpretation, written ⊨ φ[3,9,10]. Examples are the law of excluded middle P ∨ ¬P, the law of non-contradiction ¬(P ∧ ¬P), Peirce's law ((P → Q) → P) → P, and the formula of Table 3. Tautologies are true in virtue of their form: Mendelson proves that if φ is a tautology, then so is every formula obtained by uniformly substituting formulas for its variables[10]. Thus (R ∧ S) ∨ ¬(R ∧ S) is a tautology because it is an instance of P ∨ ¬P.

6.2 Contradictions

A formula is a contradiction (or self-contradictory) if it is false under every interpretation[1,8,10]. P ∧ ¬P and (P ↔ Q) ∧ (P ↔ ¬Q) are contradictions. A formula is a contradiction exactly when its negation is a tautology[10].

6.3 Contingencies

A formula is contingent if it is true under at least one interpretation and false under at least one other[1,8]. Every propositional variable is contingent, as are most formulas met in applications, for instance (P ∨ Q) → P:

Every formula falls into exactly one of the three classes tautology, contradiction and contingency, since its main column is either all T, all F, or mixed[7,8].

6.4 Satisfiability

A formula is satisfiable if at least one interpretation makes it true, that is, if it has a model; a set Γ is satisfiable if some single interpretation makes all its members true at once[3,9,15]. Tautologies and contingent formulas are satisfiable. Note that a set can fail to be satisfiable even though each of its members is: {P, P → Q, ¬Q} is such a set.

Deciding satisfiability (the problem SAT) is the central computational problem of the subject. Truth tables solve it in time exponential in the number of variables. Cook proved in 1971 that every problem solvable by a nondeterministic Turing machine in polynomial time can be reduced in polynomial time to the problem of recognising tautologies in disjunctive normal form, which is equivalent to the satisfiability problem for conjunctive normal form[16]. In later terminology, SAT was the first problem shown to be NP-complete, so no polynomial-time algorithm for it is known, and one exists if and only if P = NP[16,17]. Modern SAT solvers nevertheless routinely decide large industrial instances arising in hardware and software verification, planning and scheduling[17].

A further basic fact is the compactness theorem: a set of formulas, even an infinite one, is satisfiable if and only if each of its finite subsets is satisfiable[2,9].

6.5 Unsatisfiability

A formula or set is unsatisfiable if no interpretation makes it (all of it) true[9,15]. For a single formula, unsatisfiability is the same as being a contradiction. The concepts are linked by negation[10,15]:

φ is a tautology  iff  ¬φ is unsatisfiable;   φ is satisfiable  iff  ¬φ is not a tautology.

This duality is what lets a satisfiability procedure decide validity, and it underlies refutation methods such as resolution (section 8.4), which establish that φ is valid by deriving a contradiction from ¬φ[15,18].

6.6 Logical equivalence

Formulas φ and ψ are logically equivalent, written φ ≡ ψ, if they receive the same truth value under every interpretation[1,9,10]. Note that ≡ is a symbol of the metalanguage, a relation between formulas, not a connective inside them. The bridge between the two is[10]:

φ ≡ ψ  iff  ⊨ φ ↔ ψ.

Logical equivalence is an equivalence relation (reflexive, symmetric and transitive), and it is a congruence: replacing a subformula by an equivalent one yields an equivalent formula[10,11]. This replacement theorem is what licenses the step-by-step algebraic simplifications in sections 7 and 8.

6.7 Logical implication

A set Γ of formulas logically implies (or semantically entails) a formula φ, written Γ ⊨ φ, if every interpretation that makes all members of Γ true also makes φ true; in other words, no interpretation makes the premises true and the conclusion false[3,9,19]. An argument is valid precisely when its premises logically imply its conclusion[3,19]. Three standard facts connect implication with the other notions[9,10,15]:

  1. φ ⊨ ψ iff ⊨ φ → ψ; more generally, Γ ∪ {φ} ⊨ ψ iff Γ ⊨ φ → ψ.
  2. Γ ⊨ φ iff Γ ∪ {¬φ} is unsatisfiable.
  3. φ ≡ ψ iff φ ⊨ ψ and ψ ⊨ φ.

Fact 2 has a striking consequence, sometimes called explosion: if Γ is unsatisfiable, then Γ ⊨ φ for every φ, since no interpretation makes the premises true at all[9,19]. Dually, a tautology is implied by every set, including the empty set.

Example 6.1 (valid and invalid argument forms)

Modus ponens {P → Q, P} ⊨ Q and disjunctive syllogism {P ∨ Q, ¬P} ⊨ Q are valid. Affirming the consequent, from P → Q and Q to P, is not: the assignment P = F, Q = T makes both premises true and the conclusion false[7,8].

Semantic consequence ⊨ should be distinguished from derivability ⊢ in a proof system. The soundness and completeness theorems for classical propositional logic state that the two coincide for standard axiom systems and natural-deduction systems: Γ ⊢ φ iff Γ ⊨ φ[9–11].

The second column and third column of the first seven rows are duals: each is obtained from the other by interchanging ∧ with ∨. This reflects the fact that the laws of {¬, ∧, ∨} form a Boolean algebra, as first systematised by Boole[2,20].

7.1 Double negation

¬¬φ ≡ φ: denying a denial affirms[8,10]. “It is not the case that the door is not locked” is equivalent to “The door is locked.” This law is characteristic of classical logic; in intuitionistic logic φ ⊨ ¬¬φ holds but the converse fails[2,11].

7.2 De Morgan's laws

Named after Augustus De Morgan, who stated them in his 1847 Formal Logic, the laws say how negation distributes over conjunction and disjunction: the negation of a conjunction is the disjunction of the negations, and the negation of a disjunction is the conjunction of the negations[7,8,21]. The truth table verifies the first law:

In English: “not both rain and wind” means “no rain or no wind”, and “neither rain nor wind” means “no rain and no wind”[7,8]. The laws generalise to any number of terms: ¬(φ1 ∧ … ∧ φn) ≡ ¬φ1 ∨ … ∨ ¬φn, and dually[9,15].

7.3 Commutativity

The order of conjuncts or disjuncts does not matter: φ ∧ ψ ≡ ψ ∧ φ and φ ∨ ψ ≡ ψ ∨ φ[8,10]. The biconditional is commutative too, but the conditional is not (section 3.4).

7.4 Associativity

Grouping within a chain of conjunctions, or of disjunctions, does not matter: (φ ∧ ψ) ∧ χ ≡ φ ∧ (ψ ∧ χ) and (φ ∨ ψ) ∨ χ ≡ φ ∨ (ψ ∨ χ)[8,10]. Together with commutativity, this is what justifies writing φ1 ∧ … ∧ φn without parentheses and treating a conjunction or disjunction as a set of its components, as clausal form does (section 8.4). Associativity fails for mixed connectives: (P ∧ Q) ∨ R is not equivalent to P ∧ (Q ∨ R).

7.5 Distributivity

Each of ∧ and ∨ distributes over the other[8,10,20]:

φ ∧ (ψ ∨ χ) ≡ (φ ∧ ψ) ∨ (φ ∧ χ)    φ ∨ (ψ ∧ χ) ≡ (φ ∨ ψ) ∧ (φ ∨ χ)

The first mirrors the arithmetical law a(b + c) = ab + ac; the second has no arithmetical counterpart, since a + bc ≠ (a + b)(a + c) in general. Distributivity is the engine of conversion to normal form (section 8), and the source of its potential exponential cost.

7.6 Idempotence

Repeating a conjunct or disjunct changes nothing: φ ∧ φ ≡ φ and φ ∨ φ ≡ φ[8,10]. Boole expressed the conjunctive form as the algebraic law x2 = x, which he regarded as the distinctive law of logic[20]. Hurley and Copi call this rule “Tautology” [Taut], a potentially confusing name that refers to the rule, not to the semantic property of section 6.1[7,8].

7.7 Absorption

φ ∧ (φ ∨ ψ) ≡ φ and φ ∨ (φ ∧ ψ) ≡ φ[10,14]. Informally, once φ is required, adding the weaker alternative φ ∨ ψ as a further requirement adds nothing. Absorption is used to delete redundant clauses during simplification: in a CNF, a clause that contains another clause as a subset can be dropped[15,17].

Terminological caution: in the natural-deduction system of Copi, Cohen and Rodych, “Absorption” [Abs] names a different principle, the valid one-way inference from p → q to p → (p ∧ q), not the equivalence above[7].

7.8 Contraposition

A conditional is equivalent to its contrapositive: φ → ψ ≡ ¬ψ → ¬φ; the rule is also called transposition [Trans][7,8,10]. “If it is a square, it has four sides” is equivalent to “if it does not have four sides, it is not a square.” The conditional is not equivalent to its converse ψ → φ or its inverse ¬φ → ¬ψ, though these two are equivalent to each other (each being the other's contrapositive)[7,8]:

Confusing a conditional with its converse is the root of the fallacy of affirming the consequent (Example 6.1); confusing it with its inverse is the fallacy of denying the antecedent[7,8].

7.9 Implication elimination

φ → ψ ≡ ¬φ ∨ ψ: a conditional is true just when its antecedent is false or its consequent true[8,10,14]. Hurley calls this rule material implication [Impl]. Together with biconditional elimination, φ ↔ ψ ≡ (φ → ψ) ∧ (ψ → φ) [Equiv], it allows every formula to be rewritten using only ¬, ∧, ∨, which is the first step of every normal-form algorithm[14,15]. Two further equivalences often grouped with these are exportation, (φ ∧ ψ) → χ ≡ φ → (ψ → χ), and the conditional form of disjunction, φ ∨ ψ ≡ ¬φ → ψ[7,8].

Example 7.1 (an algebraic proof of equivalence)

We show ¬(P → Q) ∨ (P ∧ Q) ≡ P without a truth table, using the replacement theorem at each step:

  1. ¬(P → Q) ∨ (P ∧ Q) given
  2. ¬(¬P ∨ Q) ∨ (P ∧ Q) implication elimination
  3. (¬¬P ∧ ¬Q) ∨ (P ∧ Q) De Morgan
  4. (P ∧ ¬Q) ∨ (P ∧ Q) double negation
  5. P ∧ (¬Q ∨ Q) distributivity (right to left)
  6. P ¬Q ∨ Q is a tautology, and φ ∧ ψ ≡ φ when ψ is a tautology

8. Normal forms

A normal form is a restricted syntactic shape into which every formula can be transformed without changing its meaning. Normal forms make certain properties easy to read off, and they are the input format of most automated reasoning tools[14,15,17]. They are stated in terms of literals:

Definition 8.1 (literal, clause, term)

A literal is a propositional variable P (a positive literal) or its negation ¬P (a negative literal); P and ¬P are complementary. A clause is a disjunction of literals, and a term (or conjunctive clause) is a conjunction of literals[14,15,17].

Throughout this section we use one running example:

φ  =  ¬((P → Q) ∧ ¬(Q ∧ R))

8.1 Negation normal form

A formula is in negation normal form (NNF) if it is built from literals using only ∧ and ∨; that is, it contains no → or ↔, and negation is applied only to variables[14,15]. Every formula is equivalent to one in NNF, obtained in two stages[14,15]:

  1. eliminate ↔ and → by biconditional and implication elimination;
  2. push negations inwards with De Morgan's laws, cancelling double negations as they appear.

Example 8.1 (NNF of φ)

  1. ¬((P → Q) ∧ ¬(Q ∧ R)) φ
  2. ¬((¬P ∨ Q) ∧ ¬(Q ∧ R)) implication elimination
  3. ¬(¬P ∨ Q) ∨ ¬¬(Q ∧ R) De Morgan
  4. (¬¬P ∧ ¬Q) ∨ (Q ∧ R) De Morgan; double negation
  5. (P ∧ ¬Q) ∨ (Q ∧ R) double negation

Line 5 is in NNF.

Pushing negations inward never increases the number of connectives beyond a constant factor, but eliminating ↔ duplicates both of its arguments, so nested biconditionals can make the NNF exponentially longer than the original formula[17]. NNF is the common first stage of CNF and DNF conversion.

8.2 Disjunctive normal form

A formula is in disjunctive normal form (DNF) if it is a disjunction of terms, that is, a disjunction of conjunctions of literals[2,9,15]. Line 5 of Example 8.1, (P ∧ ¬Q) ∨ (Q ∧ R), is already in DNF.

Theorem 8.1 (DNF theorem)

Every formula is logically equivalent to a formula in disjunctive normal form[2,9].

The proof is constructive and reads a DNF straight off the truth table. For each row in which the formula is true, form the term that conjoins, for each variable, the variable itself if it is T in that row and its negation if it is F. That term is true in exactly that row. The disjunction of all such terms is true in exactly the rows where the formula is true[9,10]. (If the formula is true in no row, a contradiction such as P ∧ ¬P serves.) The result, in which every term mentions every variable, is the full (or canonical) DNF. Because the construction works for any truth function, it also proves that {¬, ∧, ∨} is functionally complete[2,9].

Example 8.2 (full DNF of φ from its truth table)

φ is true in rows 1, 3, 4 and 5 (counting from the top), giving the full DNF

(P ∧ Q ∧ R) ∨ (P ∧ ¬Q ∧ R) ∨ (P ∧ ¬Q ∧ ¬R) ∨ (¬P ∧ Q ∧ R),

which is equivalent to the much shorter DNF (P ∧ ¬Q) ∨ (Q ∧ R) found algebraically. DNFs are not unique; the full DNF is unique up to the order of terms and literals.

A DNF is satisfiable if and only if at least one of its terms contains no complementary pair of literals, which can be checked in time linear in the length of the formula[15,17]. This does not make SAT easy, because converting an arbitrary formula to DNF can require exponentially many terms[15,17].

8.3 Conjunctive normal form

A formula is in conjunctive normal form (CNF) if it is a conjunction of clauses, that is, a conjunction of disjunctions of literals[9,14,15]. Every formula is equivalent to one in CNF[9,14,15]. One construction is dual to the DNF construction: take the conjunction, over the rows in which the formula is false, of the clause that is false in exactly that row[9,10]. Another, more practical, starts from NNF and distributes ∨ over ∧ until no disjunction has a conjunction inside it[14,15].

Example 8.3 (CNF of φ by distribution)

  1. (P ∧ ¬Q) ∨ (Q ∧ R) NNF from Example 8.1
  2. (P ∨ (Q ∧ R)) ∧ (¬Q ∨ (Q ∧ R)) distribute ∨ over ∧
  3. (P ∨ Q) ∧ (P ∨ R) ∧ (¬Q ∨ Q) ∧ (¬Q ∨ R) distribute again
  4. (P ∨ Q) ∧ (P ∨ R) ∧ (¬Q ∨ R) drop the tautologous clause ¬Q ∨ Q

Line 4 is a CNF equivalent to φ. Line 3 is also a CNF; a clause containing a complementary pair is always true and can be deleted from a conjunction without changing its value.

Dually to DNF, a CNF is a tautology if and only if every one of its clauses contains a complementary pair of literals, which is again a linear-time test[14,15]. Satisfiability of CNF, by contrast, is the NP-complete problem of section 6.4[16,17]. CNF and DNF are also linked by negation: pushing a negation through a DNF of φ with De Morgan's laws yields a CNF of ¬φ, and vice versa[9,15].

Conversion by distribution can be very expensive. The formula (P1 ∧ Q1) ∨ (P2 ∧ Q2) ∨ … ∨ (Pn ∧ Qn) has length proportional to n, but distributing it produces 2n clauses, one for each way of choosing Pi or Qi from every disjunct[17].

8.4 Clausal form

Because conjunction and disjunction are commutative, associative and idempotent, a CNF can be represented without loss as a set of clauses, each clause being a set of literals. This set-theoretic representation is called clausal form[15,18]. The CNF of Example 8.3 becomes

{ {P, Q}, {P, R}, {¬Q, R} }.

Two boundary cases follow from the semantics of the empty conjunction and the empty disjunction[15]:

  • the empty clause { } (often written □) is a disjunction with no true disjunct, so it is unsatisfiable; any clause set containing it is unsatisfiable;
  • the empty set of clauses is a conjunction with no false conjunct, so it is valid.

Clausal form is the input language of Robinson's resolution method, whose single rule infers, from clauses C ∪ {P} and D ∪ {¬P}, the resolvent C ∪ D. A clause set is unsatisfiable if and only if the empty clause can be derived by resolution[15,18]. It is also the standard input format of SAT solvers[17].

Example 8.4 (a resolution refutation)

To show {P ∨ Q, P → R, ¬R} ⊨ Q (Example 5.3), refute the premises together with ¬Q. In clausal form: {P, Q}, {¬P, R}, {¬R}, {¬Q}.

  1. {P, Q}, {¬Q}  ⟹  {P} resolve on Q
  2. {P}, {¬P, R}  ⟹  {R} resolve on P
  3. {R}, {¬R}  ⟹  □ resolve on R

The empty clause has been derived, so the premises imply Q.

To avoid the exponential blow-up of conversion by distribution, practical systems use the Tseitin transformation. It introduces a fresh variable for each compound subformula, together with short clauses stating that the new variable is equivalent to that subformula[17,22]. The result is not logically equivalent to the original, because it contains new variables, but it is equisatisfiable: it is satisfiable if and only if the original is, and every model of it restricts to a model of the original. Its size is linear in the size of the original formula[17,22].

Example 8.5 (Tseitin encoding)

For (P ∧ Q) ∨ (R ∧ S), introduce X ↔ P ∧ Q, Y ↔ R ∧ S and Z ↔ X ∨ Y, and assert Z. In clausal form:

{¬X, P}, {¬X, Q}, {X, ¬P, ¬Q},  {¬Y, R}, {¬Y, S}, {Y, ¬R, ¬S},  {¬Z, X, Y}, {Z, ¬X}, {Z, ¬Y},  {Z}

These ten clauses are satisfied by exactly the assignments that satisfy the original formula, extended by the forced values of X, Y and Z; for n disjuncts the encoding grows linearly rather than as 2n.
