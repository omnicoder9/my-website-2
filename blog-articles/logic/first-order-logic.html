1. Introduction

First-order logic, also called predicate logic, quantificational logic or the first-order predicate calculus, extends propositional logic by analysing the internal structure of atomic statements into names, variables, predicates and function symbols, and by adding the quantifiers “for all” and “there exists”[1,2,3]. It is called first-order because its variables range only over individuals in a domain of discourse; quantifying over properties, relations or sets of individuals is the business of second- and higher-order logics[1,2].

The need for this richer language is easy to see. Consider the classic argument below.

Example 1.1

All humans are mortal. Socrates is human. Therefore Socrates is mortal.

In propositional logic the three sentences share no atomic components, so the best available form is p, q ∴ r, which is invalid. First-order logic exposes the shared structure: ∀x(Hx → Mx), Hs ∴ Ms, an argument that is valid in every interpretation[4,5].

Validity in first-order logic therefore depends on the pattern in which the same predicates and names recur across premises and conclusion, not only on how whole sentences are connected. This is why the propositional article in this series treated “Every prime greater than 2 is odd” as an unanalysed atom (see Classical Propositional Logic, section 2.1); first-order logic is the tool that analyses it.

Modern quantification theory was created independently by Frege, in his Begriffsschrift of 1879, and by Charles S. Peirce and his student Oscar Howard Mitchell, whose quantifier notation appears in Peirce's 1885 paper on the algebra of logic[6,7,8,9]. Frege's language was the first formal language equipped with quantifier symbols binding variables[9]. The model-theoretic semantics used today descends from Tarski's 1933 definition of truth and satisfaction for formalised languages[10,11]. Two landmark results fix the logic's place in mathematics: Gödel proved in 1930 that a standard proof system for it is complete, so that every valid argument is provable[1,12], and Church showed in 1936 that there is no algorithm that decides validity for it[13,14].

The article proceeds from vocabulary to laws. Section 2 introduces the basic elements; section 3 the quantifiers, scope and binding; section 4 the formal grammar of terms and formulas; section 5 the semantics on which every later claim rests; section 6 the translation of English; section 7 the logical relations among quantifiers; section 8 identity; and section 9 briefly surveys the main metatheorems.

2. Basic elements

A first-order language is fixed by its logical symbols, which are the same in every language, and its non-logical symbols (the signature, vocabulary or similarity type), which vary with the subject matter[1,2,3]. The logical symbols are the connectives, the quantifiers ∀ and ∃, an infinite supply of variables, parentheses, and usually the identity sign =[1,2]. The non-logical symbols are constant symbols, predicate (relation) symbols, and function symbols, each with a fixed number of argument places called its arity[2,3,15].

Definition 2.1 (signature)

A signature σ is a set of constant symbols c, d, …, predicate symbols P, Q, R, … and function symbols f, g, …, where each predicate symbol and each function symbol is assigned a positive integer, its arity[2,3].

2.1 Individuals

The individuals are the objects the language talks about. They are collected in a domain of discourse (or universe), the set over which the variables range[1,2]. A domain might be the natural numbers, the people in a room, or the vertices of a graph. Classical first-order logic requires the domain to be non-empty[1,16]. This is a substantive choice: it makes ∃x(Px ∨ ¬Px) a logical truth, and logics that drop the requirement (one variety of free logic) validate fewer formulas[9,16]. Section 7.4 shows where the assumption does work.

Individuals are not symbols. The number two is an individual; the numeral “2” and the term S(S(0)) are symbols that may denote it. Keeping the object level (individuals) separate from the symbol level (constants, variables, terms) is the key to the semantics in section 5[2,11].

2.2 Constants

An individual constant is a name: in each interpretation it denotes exactly one individual of the domain[1,2]. Classical logic assumes that every constant denotes something, so there are no empty names; this is the other existence assumption that free logic gives up[16]. Two different constants may denote the same individual (as “Hesperus” and “Phosphorus” both denote Venus), and some individuals may have no name at all[1,2]. That is why the semantics of the quantifiers cannot simply be defined by substituting names for variables, and instead uses variable assignments (section 5)[2,11].

2.3 Variables

An individual variable is a placeholder that ranges over the whole domain[1,2]. Variables have two jobs. Occurring free, as in Hx, a variable acts like a pronoun whose referent has not been fixed, so Hx is neither true nor false until a value is supplied; occurring bound by a quantifier, as in ∀x Hx, it serves to express generality[1,11]. The language supplies infinitely many variables, so that formulas of any complexity can always find a fresh one[2,3].

2.4 Predicates

A predicate symbol of arity n combines with n terms to form an atomic formula[1,2]. One-place (monadic) predicates express properties: Hx, “x is human”. Semantically an n-place predicate is interpreted as a set of n-tuples drawn from the domain, its extension; a one-place predicate is interpreted as a subset of the domain[1,2]. The extensional treatment means that two predicates with the same extension in an interpretation are indistinguishable there, whatever their meanings: if, in some domain, the creatures with hearts are exactly the creatures with kidneys, then “has a heart” and “has kidneys” receive the same interpretation[1]. Some presentations also allow 0-place predicates, which behave like the sentence letters of propositional logic[1].

The monadic fragment, in which every predicate is one-place and there are no function symbols, is the part of first-order logic that most closely corresponds to Aristotle's categorical logic, and unlike full first-order logic it is decidable[9,14].

2.5 Relations

Predicates of arity two or more express relations: Lxy, “x loves y”; Bxyz, “x is between y and z”[2,5]. Argument order matters, because the extension is a set of ordered tuples: Lab and Lba say different things[4,5]. It is relations, together with multiple quantifiers, that give first-order logic its expressive power beyond syllogistic, and a single two-place relation is already enough to make the logic undecidable[14].

The standard properties of a binary relation R are themselves expressible as first-order sentences[2,3]:

Example 2.2 (a small theorem about relations)

A relation that is symmetric, transitive and irreflexive must be empty. Suppose Rab. By symmetry Rba; by transitivity applied to Rab and Rba, Raa; this contradicts irreflexivity. Hence no pair is in R. In first-order terms, the three sentences above for symmetry, transitivity and irreflexivity together entail ∀x∀y ¬Rxy. (Checked by computation for every relation on domains of size 1 to 3.)

2.6 Functions

An n-place function symbol combines with n terms to form a new term, and is interpreted as a total function from n-tuples of the domain into the domain[2,3,15]. Totality is built in: every function symbol must yield a value for every argument, so “the father of” works naturally on a domain of people, while division on the real numbers (undefined at zero) needs special handling[2,15]. Constants can be regarded as 0-place function symbols, which is how some textbooks treat them[15].

Function symbols are a convenience, not a necessity. Any n-place function can be replaced by an (n+1)-place relation F(x₁, …, xₙ, y), “y is the value of f at x₁, …, xₙ”, together with an axiom saying that for every input there is exactly one such y[2,17]. The uniqueness clause in that axiom is a first use of identity (section 8.4). Some presentations, such as the SEP's survey of classical logic, omit function symbols to simplify the metatheory[1].

3. Quantifiers

A quantifier turns a formula with a free variable into a statement about how many individuals satisfy it. First-order logic has two primitive quantifiers[1,2,9].

3.1 Universal quantifier: ∀

∀x φ is read “for all x, φ” or “for every x, φ”. It is true in an interpretation just in case φ is satisfied by every individual in the domain when that individual is taken as the value of x[1,2]. Over a finite domain {d₁, …, dₙ} in which each individual has a name a₁, …, aₙ, ∀x Px has the same truth value as the conjunction Pa₁ ∧ … ∧ Paₙ; this is a useful heuristic, but the quantifier is not defined that way, since domains may be infinite or contain unnamed individuals[2,5].

3.2 Existential quantifier: ∃

∃x φ is read “there exists an x such that φ” or “for some x, φ”. It is true just in case at least one individual in the domain satisfies φ[1,2]. “Some” in logic always means “at least one”, not “several” and not “some but not all”[4,18]. Over a finite, fully named domain ∃x Px behaves like the disjunction Pa₁ ∨ … ∨ Paₙ[5].

Either quantifier can be defined from the other with negation, since ∃x φ is equivalent to ¬∀x¬φ and ∀x φ to ¬∃x¬φ[2,9]. Enderton, for instance, takes ∀ as primitive and introduces ∃ as an abbreviation[2]. Section 7.1 develops these dualities.

3.3 Quantifier scope

In a formula ∀x φ or ∃x φ, the subformula φ is the scope of that occurrence of the quantifier[2,4,17]. Parentheses fix the scope, and the convention in most texts is that a quantifier binds as tightly as negation, so its scope extends only over the smallest complete formula that follows it[4,5].

Example 3.1 (scope changes meaning)

∀x(Px → Qx): the scope of ∀x is the whole conditional. Read: everything that is P is Q.

∀x Px → Qx: by the convention, the scope of ∀x is only Px, so this means (∀x Px) → Qx. The final x lies outside every quantifier, and the whole formula says: if everything is P, then x is Q, where x is not yet specified.

Scope interacts with negation in the same way. ¬∀x Px (“not everything is P”) and ∀x ¬Px (“nothing is P”) differ only in whether the negation lies inside or outside the scope of the quantifier, and they are not equivalent[4,18]. Scope distinctions also explain ambiguities in natural language, as with “Everyone loves someone” (section 6.4) and “The present King of France is not bald” (section 8.4)[5,19].

3.4 Bound variables

An occurrence of a variable x is bound if it lies within the scope of a quantifier ∀x or ∃x on that same variable (counting the occurrence immediately after the quantifier symbol); it is bound by the innermost such quantifier[1,2,17]. A bound variable is a dummy: renaming it consistently, to a variable not already in use there, does not change the meaning. ∀x Px and ∀y Py say the same thing, just as Σᵢ aᵢ and Σⱼ aⱼ do in algebra[2,3]. Formulas that differ only by such a renaming are called alphabetic variants, and they are logically equivalent[2].

The renaming must avoid capture. In ∀x Rxy, renaming x to y gives ∀y Ryy, in which the formerly free y has been captured, and the meaning has changed[2,3]. The same hazard governs substitution of terms (section 8.3).

3.5 Free variables

An occurrence of a variable that is not bound is free[1,2]. The set of variables occurring free in a formula is defined by recursion on the construction of formulas[1,2,3]:

Definition 3.1 (free variables)

For an atomic formula φ, FV(φ) is the set of all variables occurring in φ.

FV(¬φ) = FV(φ);   FV(φ ∘ ψ) = FV(φ) ∪ FV(ψ) for each binary connective ∘.

FV(∀x φ) = FV(∃x φ) = FV(φ) ∖ {x}.

A single variable can have both free and bound occurrences in the same formula[2,4].

Example 3.2

∀x(Rxy → ∃y Syx) ∧ Px

The first two occurrences of x (in ∀x and Rxy) and the one in Syx are bound by ∀x. The x in the final Px is free, since it lies outside the scope of ∀x. The y in Rxy is free; the y in Syx is bound by ∃y. So FV = {x, y}, and the formula is not a sentence. Rewriting it as the alphabetic variant ∀z(Rzy → ∃w Swz) ∧ Px makes the bindings visible.

Free variables are what separate open formulas from sentences (section 4.4). Semantically, a formula's truth in an interpretation depends on the values assigned to its free variables and on nothing else about the assignment[1,2].

4. Atomic and complex formulas

The syntax of a first-order language is given by two inductive definitions: first of terms, the expressions that name individuals, then of formulas, the expressions that say something about them[1,2,3].

4.1 Terms

Definition 4.1 (terms)

(i) Every variable is a term. (ii) Every constant symbol is a term. (iii) If f is an n-place function symbol and t₁, …, tₙ are terms, then f(t₁, …, tₙ) is a term. (iv) Nothing else is a term[2,3,15].

A term containing no variables is a closed term (or ground term)[1,2]. In the language of arithmetic with constant 0, one-place successor S, and two-place + and ·, the expressions 0, S(S(0)) and S(0) + S(S(0)) are closed terms; x · S(y) is a term with variables[2,17]. In a structure, a closed term denotes a single individual, so S(0) + S(S(0)) denotes the number 3 in the standard model of arithmetic. Function symbols allow terms to be nested to any depth, as in m(m(a)), “Ann's maternal grandmother”[15].

Terms never have truth values. “The mother of Ann” is not true or false; it picks out a person[2,5].

4.2 Atomic formulas

Definition 4.2 (atomic formulas)

If P is an n-place predicate symbol and t₁, …, tₙ are terms, then P(t₁, …, tₙ), often written Pt₁…tₙ, is an atomic formula. If identity is in the language, t₁ = t₂ is also an atomic formula[1,2].

Examples: Hs (Socrates is human), Lxy, S(0) < x, m(a) = b. Atomic formulas are the only formulas that contain no connectives or quantifiers; they play the role that sentence letters played in propositional logic, but they now have internal structure[1,5]. An atomic formula containing no variables is an atomic sentence[1].

4.3 Well-formed formulas

Definition 4.3 (well-formed formulas)

(i) Every atomic formula is a formula. (ii) If φ and ψ are formulas, so are ¬φ, (φ ∧ ψ), (φ ∨ ψ), (φ → ψ) and (φ ↔ ψ). (iii) If φ is a formula and x a variable, then ∀x φ and ∃x φ are formulas. (iv) Nothing else is a formula[1,2,3].

The clause for the quantifiers does not require x to occur free in φ; this permits vacuous quantification such as ∀x Pa, discussed in section 7.4[1,2]. Like the propositional language, the first-order language enjoys unique readability: every formula has exactly one decomposition into immediate subformulas, so each formula has a unique parse tree and the recursive definitions of free variables and of satisfaction are well defined[1,2].

4.4 Sentences

A formula with no free variables is a sentence (or closed formula)[1,2]. Only sentences have a truth value in an interpretation by itself; a formula with free variables, such as Lxy, has a truth value only relative to an assignment of individuals to its free variables[1,11]. Theories, premises and conclusions in first-order logic are normally sentences[2].

Example 4.1

∀x∃y Lxy and Hs → Ms are sentences. ∃y Lxy is not: x is free, and the formula expresses the property “x loves someone”. Binding x with a quantifier, or replacing it with a constant as in ∃y Lay, produces a sentence.

5. Semantics: structures and satisfaction

The equivalences and translations later in this article are claims about truth in all interpretations, so the notion of interpretation needs to be precise. The definitions below follow Tarski's method, in which truth is defined via the auxiliary notion of satisfaction of a formula by an assignment of objects to variables[10,11].

Definition 5.1 (structure)

A structure (model, interpretation) 𝔐 for a signature consists of a non-empty set D, the domain, and an interpretation function assigning to each constant c an element c𝔐 ∈ D, to each n-place predicate P a set P𝔐 ⊆ Dⁿ, and to each n-place function symbol f a function f𝔐 : Dⁿ → D[1,2,3].

A variable assignment is a function s from the variables into D. The term value ⟦t⟧s is s(x) for a variable, c𝔐 for a constant, and f𝔐(⟦t₁⟧s, …, ⟦tₙ⟧s) for a compound term[1,2].

Definition 5.2 (satisfaction)

𝔐 ⊨ P t₁…tₙ [s] iff (⟦t₁⟧s, …, ⟦tₙ⟧s) ∈ P𝔐;   𝔐 ⊨ t₁ = t₂ [s] iff ⟦t₁⟧s = ⟦t₂⟧s.

The connectives receive their truth-table clauses, e.g. 𝔐 ⊨ ¬φ [s] iff not 𝔐 ⊨ φ [s].

𝔐 ⊨ ∀x φ [s] iff 𝔐 ⊨ φ [s(x↦d)] for every d ∈ D.

𝔐 ⊨ ∃x φ [s] iff 𝔐 ⊨ φ [s(x↦d)] for some d ∈ D.

Here s(x↦d) is the assignment that agrees with s except that it sends x to d[1,2,10].

Whether 𝔐 ⊨ φ [s] depends only on the values s gives to the free variables of φ; so a sentence is either satisfied by every assignment or by none, and in the first case it is true in 𝔐, written 𝔐 ⊨ φ[1,2,11]. A sentence is valid (logically true) if it is true in every structure; a set of sentences Γ logically implies φ, written Γ ⊨ φ, if φ is true in every structure in which all of Γ is true; and two formulas are logically equivalent if each implies the other[1,2]. To show that φ does not imply ψ, it suffices to give a single countermodel: a structure in which φ is true and ψ false[2,5]. That technique is used repeatedly in section 7.

Example 5.1 (evaluating sentences in a structure)

Let D = {0, 1, 2} and interpret the two-place predicate L as L𝔐 = {(0,1), (1,2), (2,0)}, a three-cycle.

  • ∀x∃y Lxy is true: for x = 0, 1, 2 take y = 1, 2, 0 respectively.
  • ∃y∀x Lxy is false: no y is L-related to by all three elements (for instance, (1,1) ∉ L).
  • ∃x Lxx is false: no pair (d,d) is in the extension.
  • ∀x∀y(Lxy → ¬Lyx) is true: the relation is asymmetric.

(All four values were confirmed by computation.)

6. Translation

6.1 Natural language to predicate logic

Translating (or symbolising) an English sentence into first-order logic means finding a sentence of a first-order language that is true in exactly the same circumstances, relative to a stated translation key: a domain of discourse plus a gloss for each constant, predicate and function symbol[4,5]. A reliable procedure is to rewrite the English in a regimented “logician's English” that makes quantifiers and variables explicit, and then to replace each part with its symbol[5,18].

Example 6.1 (a translation key)

Domain: people. a: Ann; b: Ben. Sx: x is a student. Tx: x is a teacher. Lxy: x likes y. m(x): the mother of x.

  • “Ann likes Ben.” Lab
  • “Ben likes his mother.” L b m(b)
  • “Ann likes herself.” Laa
  • “Ann's mother is a teacher, but Ann is not.” T m(a) ∧ ¬Ta

Translation is judged by truth conditions, not word-for-word correspondence. “But”, “although” and “and” are all rendered as ∧, losing their rhetorical contrast but preserving their truth conditions[4,18]. Choosing the domain matters too: with the domain restricted to people, “everyone” is simply ∀x; with an unrestricted domain, it must be rendered with a predicate for “person”, as in section 6.5[4,5].

6.2 Universal statements

“All A are B” is translated as ∀x(Ax → Bx)[4,5,18]. The conditional is essential: ∀x(Ax ∧ Bx) says that everything is both A and B, which is far stronger. “All whales are mammals” does not say that everything is a whale[4,5].

“No A are B” is ∀x(Ax → ¬Bx), or equivalently ¬∃x(Ax ∧ Bx)[4,18]. Many English forms express universal quantification: “every”, “each”, “any” (in most positive contexts), “whoever”, bare plurals such as “Whales are mammals”, and conditionals with indefinite articles such as “If something is a whale, it is a mammal”[4,5]. “Only” reverses the direction of the conditional: “Only members are admitted” means ∀x(Admitted x → Member x)[4,18].

Example 6.2 (“any” in different positions)

“If anyone cheated, the test is void” is ∃x Cx → V, which by section 7.2 is equivalent to ∀x(Cx → V). “If everyone cheated, the test is void” is ∀x Cx → V, a different and weaker claim. Here “anyone” takes wide scope over the conditional, which is why it behaves like a universal quantifier outside it[5].

6.3 Existential statements

“Some A are B” is translated as ∃x(Ax ∧ Bx), and “Some A are not B” as ∃x(Ax ∧ ¬Bx)[4,5,18]. Here the conjunction is essential. ∃x(Ax → Bx) is a common mistake: it is true as soon as there is anything that is not A, because a conditional with a false antecedent is true[4,5].

Example 6.3 (why ∃x(Ax → Bx) fails)

Take a domain with one object, a rock, and let A (“is a unicorn”) and B (“is blue”) both be empty. Then ∃x(Ax → Bx) is true (the rock makes the antecedent false) while “Some unicorns are blue”, ∃x(Ax ∧ Bx), is false. The first does not imply the second. (The converse implication does hold.)

English signals existential quantification with “some”, “there is”, “at least one”, “a” or “an” in many contexts (“A dog barked”), and “someone” or “something”[4,5]. The four Aristotelian categorical forms translate as follows[4,18]:

FormEnglishFirst-order translation
A (universal affirmative)All S are P∀x(Sx → Px)
E (universal negative)No S are P∀x(Sx → ¬Px)
I (particular affirmative)Some S are P∃x(Sx ∧ Px)
O (particular negative)Some S are not P∃x(Sx ∧ ¬Px)

These translations adopt what Hurley calls the Boolean standpoint: universal statements have no existential import[4]. In first-order logic, ∀x(Sx → Px) does not imply ∃x(Sx ∧ Px); in a structure where nothing is S, the universal is vacuously true and the particular false[4,18]. So the traditional inference from an A statement to the corresponding I statement (subalternation) is invalid unless one adds the premise ∃x Sx[4]. The A and O forms remain contradictories, and so do E and I, as section 7.1 confirms.

6.4 Multiple quantifiers

With relational predicates, a sentence may need several quantifiers, and their order and scope become significant[4,5]. A useful method is to translate from the outside in, treating the inner part as a formula with a free variable[5].

Example 6.4 (step-by-step translation)

“Every student likes some teacher.” (Key as in Example 6.1.)

  1. For every x, if x is a student then x likes some teacher.outer quantifier
  2. ∀x(Sx → x likes some teacher)universal pattern, 6.2
  3. “x likes some teacher”: ∃y(Ty ∧ Lxy)existential pattern, 6.3
  4. ∀x(Sx → ∃y(Ty ∧ Lxy))substitute

The relative order of different quantifiers changes the meaning. With Lxy for “x loves y” over a domain of people[4,5]:

English sentences such as “Everyone loves someone” are often ambiguous between the first two readings, and a first-order translation forces the choice[5]. The logical relation between the readings is examined in section 7.3.

Example 6.5 (more complex patterns)

  • “Every teacher who likes a student is liked by that student.” ∀x∀y((Tx ∧ Sy ∧ Lxy) → Lyx). The indefinite “a student” in the relative clause, picked up by the anaphoric “that student”, becomes a universal quantifier with wide scope[5].
  • “Some student likes no teacher.” ∃x(Sx ∧ ¬∃y(Ty ∧ Lxy)).
  • “Every natural number has a successor greater than it.” Over the natural numbers, ∀x(x < S(x)), using a function symbol in place of a quantifier.
  • “There is no largest number.” ¬∃x∀y(y ≤ x), equivalently ∀x∃y(x < y) in the language of the natural numbers with their standard ordering.

6.5 Restricted quantification

Natural-language quantifiers are almost always restricted: “every student”, “some apples”, not “everything”[9]. First-order logic has only unrestricted quantifiers ranging over the whole domain, and expresses restriction by combining a quantifier with a connective: the restrictor goes into the antecedent of a conditional under ∀ and into a conjunct under ∃[4,5,9]. Some authors introduce restricted-quantifier notation as an abbreviation[9]:

(∀x : Ax) φ := ∀x(Ax → φ) (∃x : Ax) φ := ∃x(Ax ∧ φ)

The asymmetry between → and ∧ is exactly what makes the dualities of section 7.1 carry over to restricted quantifiers: ¬(∀x : Ax)φ is equivalent to (∃x : Ax)¬φ, because ¬∀x(Ax → φ) is equivalent to ∃x(Ax ∧ ¬φ). (Verified for φ = Bx over all structures of size 1 to 3.)

An alternative is to choose the domain itself as the restriction (for example, “domain: people”), or to use a many-sorted logic in which each variable has a sort, such as one sort of variables for students and another for books; many-sorted logic can be reduced to ordinary one-sorted first-order logic by exactly the relativisation shown above[2]. Restriction by the conditional has one counterintuitive consequence already noted in section 6.3: when the restricting predicate is empty, every universal claim restricted to it is vacuously true[4,9].

7. Quantifier relations

This section collects the standard logical relations among quantified formulas[2,3,17]. Each listed equivalence is a textbook theorem; each listed non-equivalence is accompanied by a countermodel. As an independent check, every schema below was instantiated with one-place predicates P, Q, a two-place predicate R, or a sentence letter q, and both sides were evaluated in every structure with a domain of one, two or three elements; all equivalences held in every case and every non-equivalence produced the countermodel shown.

7.1 Negation of quantifiers

Negating a quantified formula switches the quantifier and moves the negation inside[2,3,4,18]:

LawLeft sideEquivalent right side
Quantifier negation 1¬∀x φ∃x ¬φ
Quantifier negation 2¬∃x φ∀x ¬φ
Definability 1∀x φ¬∃x ¬φ
Definability 2∃x φ¬∀x ¬φ
Negated A form¬∀x(Px → Qx)∃x(Px ∧ ¬Qx)
Negated I form¬∃x(Px ∧ Qx)∀x(Px → ¬Qx)

These are the quantifier analogues of De Morgan's laws: over a finite named domain, ¬∀x Px corresponds to ¬(Pa₁ ∧ … ∧ Paₙ), which De Morgan's law turns into ¬Pa₁ ∨ … ∨ ¬Paₙ, the expansion of ∃x ¬Px[5]. The proof is direct from Definition 5.2: ∀x φ fails under s exactly when some d makes φ fail under s(x↦d), which is exactly when ∃x ¬φ holds[2]. The last two rows show that the A and O forms, and the I and E forms, are contradictories, as in the traditional square of opposition[4].

Example 7.1 (pushing negations inward)

  1. ¬∀x∃y(Ty ∧ Lxy)“Not everyone likes some teacher”
  2. ∃x¬∃y(Ty ∧ Lxy)QN 1
  3. ∃x∀y¬(Ty ∧ Lxy)QN 2
  4. ∃x∀y(Ty → ¬Lxy)propositional equivalence

Result: “Someone likes no teacher.”

7.2 Quantifier equivalences

Distribution. The universal quantifier distributes over conjunction and the existential over disjunction[2,3,5]:

∀x(φ ∧ ψ) ≡ ∀x φ ∧ ∀x ψ ∃x(φ ∨ ψ) ≡ ∃x φ ∨ ∃x ψ

The other two distributions hold in one direction only[3,5]:

Valid directionInvalid converseCountermodel to the converse
∀x Px ∨ ∀x Qx ⊨ ∀x(Px ∨ Qx)∀x(Px ∨ Qx) ⊭ ∀x Px ∨ ∀x QxD = {0,1}, P = {0}, Q = {1}: everything is P or Q, but not everything is P and not everything is Q.
∃x(Px ∧ Qx) ⊨ ∃x Px ∧ ∃x Qx∃x Px ∧ ∃x Qx ⊭ ∃x(Px ∧ Qx)D = {0,1}, P = {0}, Q = {1}: something is P and something is Q, but nothing is both.
∀x(Px → Qx) ⊨ ∀x Px → ∀x Qx∀x Px → ∀x Qx ⊭ ∀x(Px → Qx)D = {0,1}, P = {0}, Q = ∅: the antecedent ∀x Px is false, so the conditional is true; but 0 is P and not Q.
∀x φ ⊨ ∃x φ∃x Px ⊭ ∀x PxD = {0,1}, P = {0}. (The valid direction depends on the domain being non-empty.)

Prenex laws (quantifier movement). When x does not occur free in ψ, a quantifier on x can be moved across a connective joining ψ[2,3,17]:

#FormulaEquivalent (x not free in ψ)
1∀x(φ ∧ ψ)∀x φ ∧ ψ
2∃x(φ ∧ ψ)∃x φ ∧ ψ
3∀x(φ ∨ ψ)∀x φ ∨ ψ
4∃x(φ ∨ ψ)∃x φ ∨ ψ
5∀x(ψ → φ)ψ → ∀x φ
6∃x(ψ → φ)ψ → ∃x φ
7∀x(φ → ψ)∃x φ → ψ
8∃x(φ → ψ)∀x φ → ψ

Rows 7 and 8 are the ones most often got wrong: a quantifier moved out of the antecedent of a conditional flips from universal to existential and back, because φ → ψ is equivalent to ¬φ ∨ ψ and the negation flips the quantifier[2,3]. For example, “For every x, if x cheated then the test is void” is equivalent to “If someone cheated, the test is void” (Example 6.2). The plausible-looking ∀x(Px → q) ≡ ∀x Px → q is false: with D = {0,1}, P = {0} and q false, the right side is true (its antecedent is false) and the left is false (at x = 0). Rows 1, 4, 6 and 8 depend on the domain being non-empty (in an empty domain each fails for one truth value of ψ), while rows 2, 3, 5 and 7 hold even in an empty domain; section 7.4 explains why. Repeated use of these laws together with renaming of bound variables shows that every formula is equivalent to one in prenex normal form, with all quantifiers in a block at the front followed by a quantifier-free matrix[2,3,17].

Example 7.2 (conversion to prenex form)

  1. ∀x Px → ∃x Qx
  2. ∀x Px → ∃y Qyrename bound variable
  3. ∃x(Px → ∃y Qy)row 8
  4. ∃x∃y(Px → Qy)row 6

7.3 Quantifier order

Adjacent quantifiers of the same kind commute[2,3,5]:

∀x∀y φ ≡ ∀y∀x φ ∃x∃y φ ≡ ∃y∃x φ

Adjacent quantifiers of different kinds do not. An existential–universal sentence implies the corresponding universal–existential one, but not conversely[3,4,5]:

∃y∀x Rxy ⊨ ∀x∃y Rxy ∀x∃y Rxy ⊭ ∃y∀x Rxy

Proof of the valid direction. Suppose ∃y∀x Rxy is true in 𝔐; then some b ∈ D satisfies (d, b) ∈ R𝔐 for every d. Given any d, that same b witnesses ∃y Rdy, so ∀x∃y Rxy is true. Countermodel to the converse. Let D = {0, 1} and let R be identity, {(0,0), (1,1)}. Each element is R-related to something (itself), so ∀x∃y Rxy is true; but no single element is R-related to by both 0 and 1, so ∃y∀x Rxy is false.

Example 7.3 (a famous order distinction)

In analysis, a function f is continuous on a set A when

∀x∈A ∀ε>0 ∃δ>0 ∀y∈A (|x − y| < δ → |f(x) − f(y)| < ε)

and uniformly continuous on A when

∀ε>0 ∃δ>0 ∀x∈A ∀y∈A (|x − y| < δ → |f(x) − f(y)| < ε)

The only difference is that in the second, ∃δ precedes ∀x, so one δ must work for every x. By the principle above, uniform continuity implies continuity; the converse fails, for instance for f(x) = 1/x on the open interval (0, 1).

The intuitive reason for the asymmetry is that in ∀x∃y the choice of y may depend on x, whereas in ∃y∀x one y must serve for all x[5]. This dependence of an inner existential on outer universals is made explicit in Skolem normal form, where ∀x∃y Rxy is replaced (for satisfiability purposes) by ∀x R x f(x) with a new function symbol f choosing a witness for each x[14,15].

7.4 Vacuous quantification

A quantifier ∀x or ∃x is vacuous when its variable does not occur free in its scope, as in ∀x Pa, ∃x q, or the inner quantifier of ∀x∃x Px[1,2]. The formation rules (Definition 4.3) allow such formulas, and the semantics handles them without special clauses: because the truth of φ under an assignment depends only on its free variables, changing the value of x makes no difference, so[1,2]

∀x φ ≡ φ and ∃x φ ≡ φ whenever x is not free in φ.

In ∀x∃x Px, the outer ∀x is vacuous, because every occurrence of x in its scope is already bound by ∃x; so the formula is equivalent to ∃x Px. Such formulas are legal but confusing, and well-written translations avoid them by using distinct variables for distinct quantifiers[2,5].

The equivalences rely on the domain being non-empty. In an empty domain, ∀x φ would be true and ∃x φ false whatever φ is; so if q were false, ∀x q would be true, and if q were true, ∃x q would be false[9,16]. This is one reason classical logic excludes empty domains, and why logics that admit them (sometimes called inclusive logics) must adjust the prenex laws and the rules for quantifiers[9,16].

8. Identity

8.1 Equality

The identity (or equality) symbol = is a two-place predicate with a fixed meaning: t₁ = t₂ is true in a structure under an assignment exactly when t₁ and t₂ denote the very same element of the domain[1,2]. Identity is “the relation everything has to itself and to nothing else”[20]. It is therefore reflexive, symmetric and transitive, and it is the finest equivalence relation on any domain[2,20]. Its negation is usually abbreviated t₁ ≠ t₂.

Identity statements are informative when the two terms differ. a = a is trivially true, but “Hesperus = Phosphorus” records an astronomical discovery, and S(S(0)) + S(S(0)) = S(S(S(S(0)))) records an arithmetical fact[19,20].

8.2 Identity predicates

Most presentations treat = as a logical symbol whose interpretation is fixed in every structure; the result is called first-order logic with identity (or with equality)[1,2,17]. Alternatively, = can be treated as an ordinary two-place predicate governed by axioms. The standard ones are[2,17,20]:

Identity axioms

Reflexivity: ∀x (x = x).

Substitutivity (schema): ∀x∀y (x = y → (φ(x) → φ(y))), for each formula φ, where φ(y) results from replacing some free occurrences of x by y (with y substitutable for x).

Symmetry and transitivity follow from these[3,17]. For symmetry, apply substitutivity with φ(u) := (u = x): from x = y and φ(x), which is the reflexivity instance x = x, infer φ(y), that is, y = x. For transitivity, suppose x = y and y = z. By symmetry y = x; applying substitutivity with φ(u) := (u = z) to y = x and φ(y) yields φ(x), that is, x = z.

These axioms do not force a predicate to mean identity. Any structure in which = is interpreted as a congruence relation (an equivalence relation respected by all the other symbols) satisfies them, and it can be collapsed into a normal structure, in which the predicate is true identity, by identifying equivalent elements[2,17]. Philosophically, the point is that the first-order schemata ensure only that the predicate holds between objects indiscernible by the language's own predicates: “Identity is thus not first-order, but only second-order definable”[20].

Identity also adds expressive power: it makes numerical statements possible[4,5].

ClaimFirst-order sentence
There is at least one P∃x Px
There are at least two Ps∃x∃y(Px ∧ Py ∧ x ≠ y)
There is at most one P∀x∀y((Px ∧ Py) → x = y)
There is exactly one P∃x(Px ∧ ∀y(Py → y = x))
There are exactly two Ps∃x∃y(Px ∧ Py ∧ x ≠ y ∧ ∀z(Pz → (z = x ∨ z = y)))

Everyone except Ann is happy∀x(x ≠ a → Hx) (on the usual reading, also ¬Ha)

(The first five rows were checked against the cardinality of P in every structure of size 1 to 3.) Without identity, first-order logic cannot express “at least two”: a structure can always be enlarged by duplicating an element, and no identity-free sentence can tell the copies apart[2].

8.3 Substitution

The substitutivity axiom is a formal version of Leibniz's Law, or the indiscernibility of identicals: if x is identical with y, then everything true of x is true of y[20]. Its contrapositive is the standard way to prove distinctness: if a has a property b lacks, then a ≠ b[20]. The converse principle, the identity of indiscernibles (if everything true of x is true of y, then x is y), is philosophically controversial when restricted to qualitative properties, as the example of two indistinguishable spheres in an otherwise empty universe illustrates[20].

In natural deduction, Leibniz's Law appears as an elimination rule[1,5]:

Rules for identity

= Introduction: infer t = t for any term t, from no premises.

= Elimination (substitution): from φ(t₁) and t₁ = t₂, infer φ(t₂), where φ(t₂) results from replacing one or more occurrences of t₁ by t₂.

Example 8.1 (a substitution proof)

  1. m(a) = bpremise: Ann's mother is Beth
  2. T m(a)premise: Ann's mother is a teacher
  3. T b= Elim, 1, 2: replace m(a) by b

Substitution and capture. Both the identity rule and the quantifier rules involve substituting a term t for a variable x, written φ(x := t) or φxt. The substitution must replace only free occurrences of x, and t must be substitutable (free) for x: no variable of t may become bound by a quantifier in φ[2,3,17].

Example 8.2 (why the substitutability condition is needed)

Over the natural numbers, φ(x) := ∃y(x < y), “something is bigger than x”, is true for every x, so ∀x∃y(x < y) is true. Universal instantiation should yield φ(t) for any term t. Instantiating with t = S(z) correctly gives ∃y(S(z) < y). But instantiating naively with t = y gives ∃y(y < y), which is false: the y in t has been captured by ∃y. Because y is not substitutable for x in φ, the rule forbids this step; the remedy is first to rename the bound variable, giving ∃w(x < w), and then substitute to get ∃w(y < w).

Limits of substitution. Leibniz's Law is valid in first-order logic because its language is extensional: it has no “opaque” contexts[1]. Natural language does. From “Lois believes that Superman can fly” and “Superman = Clark Kent” one cannot safely infer “Lois believes that Clark Kent can fly”. Such sentences, with belief and other intensional operators, therefore cannot be represented with “believes that” as an ordinary predicate of individuals, and they lie outside first-order logic proper[1].

8.4 Uniqueness

“There is exactly one x such that φ” is abbreviated ∃!x φ. With identity it can be defined in several equivalent ways[3,5,19]:

∃!x Px := ∃x(Px ∧ ∀y(Py → y = x))
≡ ∃x∀y(Py ↔ y = x)
≡ ∃x Px ∧ ∀x∀y((Px ∧ Py) → x = y)

The last form splits uniqueness into an existence claim and an at-most-one claim. (All three were checked equivalent to “P has exactly one element” in every structure of size 1 to 3.) Uniqueness claims are pervasive in mathematics: “every non-zero real number has a unique multiplicative inverse” is ∀x(x ≠ 0 → ∃!y(x · y = 1)).

Definite descriptions. Uniqueness is the core of Russell's analysis of definite descriptions in “On Denoting” (1905)[19,21]. A sentence of the form “The F is G” is analysed not as predicating G of a named object, but as the conjunction of three claims: there is an F, at most one thing is F, and it is G[19,21]:

The F is G := ∃x(Fx ∧ ∀y(Fy → y = x) ∧ Gx)

This is equivalent to ∃!x Fx ∧ ∀x(Fx → Gx) (checked by computation). On this analysis “the” is a quantifier, not a name, and a description that denotes nothing does not make the sentence meaningless, only false[19,21].

Example 8.3 (the present King of France)

Let Kx: x is at present King of France, Bx: x is bald. “The present King of France is not bald” has two readings, depending on the scope of negation relative to the description[19,21]:

  • Narrow-scope negation (the description takes wide scope): ∃x(Kx ∧ ∀y(Ky → y = x) ∧ ¬Bx). There is exactly one present King of France and he is not bald. Since France has no king, this is false.
  • Wide-scope negation: ¬∃x(Kx ∧ ∀y(Ky → y = x) ∧ Bx). It is not the case that there is exactly one present King of France who is bald. This is true.

The first reading implies the second, but not conversely: in any structure where nothing satisfies K (for example, a one-element domain with K = B = ∅), the second is true and the first false. This is how Russell's theory preserves the law of excluded middle (one of “The King of France is bald” and its wide-scope negation must be true) without positing a non-existent king[19,21].

Russell's theory was later criticised, notably by Strawson, who argued that a sentence with a non-denoting description is neither true nor false rather than false; the debate is surveyed in the SEP article on descriptions[19]. Within classical first-order logic, however, the Russellian translation is the standard way to formalise definite descriptions[5,19].

9. Metalogical properties

Although not part of the outline, four results explain why first-order logic is the standard logic of mathematics, and where its limits lie.

  • Soundness and completeness. For standard deductive systems, Γ ⊢ φ if and only if Γ ⊨ φ: an argument is deducible exactly when it is valid. Completeness was first proved by Gödel in 1930[1,2,12].
  • Compactness. A set of sentences is satisfiable if and only if every finite subset is satisfiable[1,2]. One consequence is that no first-order sentence (or set of sentences) is true in exactly the finite structures[2].
  • Löwenheim–Skolem. If a countable set of sentences has a model, it has a countable model[1,2].
  • Undecidability. There is no algorithm that determines, for every first-order sentence, whether it is valid; this was shown by Church and, independently, by Turing in 1936[13,14]. Validity is, however, semi-decidable: the valid sentences can be effectively listed, because they are exactly the provable ones[2,14]. The monadic fragment (section 2.4) is decidable, while adding a single two-place predicate already yields an undecidable logic[14].
