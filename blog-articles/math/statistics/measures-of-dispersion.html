1. Why dispersion matters

Dispersion (also called spread, scatter or variability) is the extent to which observations differ from one another or from a central value.1 Two data sets can share the same mean and median yet behave very differently: a drug whose effect averages 10 units but ranges from −20 to 40 is a different proposition from one that reliably delivers 9 to 11. Location without spread is half a description.

Measures of dispersion fall into three families. Distance-between-values measures (range, IQR, other quantile spreads) are differences between two order statistics. Average-deviation measures (variance, standard deviation, mean absolute deviation) summarise how far observations lie from a centre. Robust measures (median absolute deviation, Sn, Qn, biweight midvariance) are designed to remain stable when part of the data is contaminated.2,3 A fourth idea, the standard error, is not a measure of the data's spread at all but of an estimator's, and it is included here because it is so often confused with the standard deviation.

The running example

Throughout, we use ten reaction times in milliseconds (a deliberately small sample with one slow response):

Data set D (n = 10)12, 15, 17, 18, 20, 21, 22, 24, 25, 58

The mean is 23.2 ms and the median is 20.5 ms. The single value 58 pulls the mean well above the median, which is the first hint that measures built on the mean will also be pulled.

2. Range

DefinitionR = x(n) − x(1) = max(x) − min(x)

The range is the difference between the largest and smallest observations, where x(i) denotes the i-th order statistic.1 For D, R = 58 − 12 = 46 ms.

Properties

  • Uses two values only. The range ignores everything between the extremes, so it says nothing about how the bulk of the data is spread.2
  • Grows with sample size. The more observations you draw from an unbounded distribution, the more extreme the minimum and maximum tend to become, so ranges from samples of different sizes are not comparable. The NIST handbook explicitly advises caution when using the range for large n.2
  • Zero breakdown. A single corrupted value can make the range arbitrarily large (Section 11).
  • Still useful. For small subgroups of fixed size, as in quality-control charts, the range is simple and efficient enough, which is why it survives in industrial practice.2
data = [12, 15, 17, 18, 20, 21, 22, 24, 25, 58]
print(max(data) - min(data))       # 46
import numpy as np
print(np.ptp(data))                # 46  ("peak to peak")

3. Interquartile range (IQR)

DefinitionIQR = Q3 − Q1 = Q(0.75) − Q(0.25)

The IQR is the width of the interval containing the middle half of the data.1 Because it discards the top and bottom quarter, up to 25% of the observations can be replaced by arbitrary values without the IQR becoming unbounded; it is therefore resistant to outliers.2,3

Sample quantiles are not unique

For a finite sample there is no single agreed definition of the p-th quantile. Hyndman and Fan catalogued nine definitions used by statistical packages, all of the form a weighted average of two adjacent order statistics, and they differ most in small samples.5 NumPy's default (method="linear") and R's default are Hyndman–Fan type 7,6 while Python's statistics.quantiles defaults to the "exclusive" method (type 6).7

Type 7 by hand. For sorted data x(1),…,x(n), set h = (n − 1)p + 1. Then Q(p) = x(⌊h⌋) + (h − ⌊h⌋)(x(⌊h⌋+1) − x(⌊h⌋)).5 For D with p = 0.25: h = 9(0.25) + 1 = 3.25, so Q1 = 17 + 0.25(18 − 17) = 17.25. For p = 0.75: h = 7.75, so Q3 = 22 + 0.75(24 − 22) = 23.5. Hence IQR = 6.25.

Practical point. When you report an IQR from a small sample, say which quantile definition you used, or the number may not be reproducible in another package.5

Tukey's fences

Tukey's box plot flags as potential outliers any values below Q1 − 1.5·IQR or above Q3 + 1.5·IQR.4 For D the upper fence is 23.5 + 1.5(6.25) = 32.875, so 58 is flagged (Figure 1).

IQR as an estimate of σ

For a normal distribution the quartiles lie at μ ± 0.6745σ, so IQR = 1.349σ and IQR / 1.349 is a consistent estimator of σ under normality (see Figure 3).3 For D that gives 6.25 / 1.349 ≈ 4.63 ms, much closer to the outlier-free SD (4.24) than the raw SD (12.87).

import numpy as np
from scipy import stats
q1, q3 = np.percentile(data, [25, 75])         # 17.25, 23.5  (type 7)
print(q3 - q1, stats.iqr(data))                # 6.25 6.25
print(stats.iqr(data, scale="normal"))          # 4.633  (IQR / 1.349)

4. Variance

Population varianceσ2 = E[(X − μ)2]   or, for a finite population of size N,  σ2 = 1N Σ (xi − μ)2
Sample variances2 = 1n − 1 Σi=1n (xi − x̄)2

Variance is the mean squared deviation from the mean. Squaring makes every deviation positive and gives large deviations disproportionate weight. The divisor n − 1 (Bessel's correction) makes s2 an unbiased estimator of σ2 for independent observations from any distribution with finite variance: one degree of freedom is "used up" by estimating μ with x̄, since the deviations from x̄ must sum to zero.8

Worked example on D

Deviations from x̄ = 23.2 are −11.2, −8.2, −6.2, −5.2, −3.2, −2.2, −1.2, 0.8, 1.8 and 34.8. Their squares sum to 1489.6, so s2 = 1489.6 / 9 = 165.51 ms². The outlier alone contributes 34.8² = 1211.04, or 81% of the total sum of squares.

Key properties

  • Units are squared (ms², kg², $²), which makes variance hard to interpret directly; take the square root to return to the original units (Section 5).
  • Linear transformations: Var(aX + b) = a2 Var(X). Shifting data does not change spread; rescaling multiplies variance by the square of the factor.8
  • Additivity: for independent random variables, Var(X + Y) = Var(X) + Var(Y). This is the property that makes variance the workhorse of ANOVA, regression and error propagation, and it is not shared by the standard deviation or absolute-deviation measures.8

Computing variance safely

The algebraically equivalent "textbook shortcut" s2 = (Σx2 − nx̄2) / (n − 1) subtracts two large, nearly equal numbers and can lose all significant digits in floating-point arithmetic when the mean is large relative to the spread. Chan, Golub and LeVeque analysed this failure and recommended the two-pass algorithm (compute x̄ first, then sum squared deviations) or a stable updating scheme.9 Welford's one-pass method updates the mean and the sum of squared deviations as each value arrives, which suits streaming data.10

z = [1e9 + 4, 1e9 + 7, 1e9 + 13, 1e9 + 16]       # true sample variance = 30
n, m = len(z), sum(z) / len(z)
naive   = (sum(v * v for v in z) - n * m * m) / (n - 1)
twopass = sum((v - m) ** 2 for v in z) / (n - 1)
print(naive, twopass)                         # 0.0  30.0   (naive formula fails)

def welford(stream):
    n, mean, m2 = 0, 0.0, 0.0
    for v in stream:
        n += 1
        d = v - mean
        mean += d / n
        m2 += d * (v - mean)       # uses the *updated* mean
    return mean, m2 / (n - 1)
print(welford(z))                             # (1000000010.0, 30.0)
Library defaults differ. numpy.var and numpy.std divide by n unless you pass ddof=1; pandas and Python's statistics.variance/stdev divide by n − 1, while statistics.pvariance/pstdev divide by n.7

5. Standard deviation

Definitionσ = √σ2      s = √s2 = √[ Σ(xi − x̄)2 / (n − 1) ]

The standard deviation is the square root of the variance and is expressed in the same units as the data. The term was introduced by Karl Pearson in 1894.11 For D, s = √165.51 = 12.87 ms; without the outlier it is 4.24 ms.

Although s2 is unbiased for σ2, s itself slightly underestimates σ on average, because the square root is concave (Jensen's inequality).8 The bias is small except for very small samples and is usually ignored.

Interpretation under normality

If the data are approximately normal, about 68%, 95% and 99.7% of observations fall within 1, 2 and 3 standard deviations of the mean.8 This "empirical rule" is what makes the SD intuitive, and also why it misleads for skewed or heavy-tailed data: the NIST handbook notes that the SD is the best estimator of scale when data are normal, but lacks robustness of validity otherwise.2

import statistics, numpy as np
statistics.stdev(data)          # 12.865  (n - 1)
statistics.pstdev(data)         # 12.205  (n)
np.std(data, ddof=1)            # 12.865  -- NumPy needs ddof=1 for the sample SD

6. Mean absolute deviation

DefinitionMeanAD = 1n Σ |xi − x̄|

The mean absolute deviation (also called the average absolute deviation, or simply the mean deviation) averages distances rather than squared distances.1,2 Some authors centre it on the median instead of the mean, which minimises the average absolute deviation; always state which centre you used.1

For D: the absolute deviations from 23.2 sum to 74.8, so MeanAD = 7.48 ms. The outlier contributes 34.8 / 74.8 = 47% of this sum, versus 81% of the sum of squares for the variance: absolute deviations are less sensitive than squared ones, but they are still unbounded, so MeanAD is not robust in the breakdown sense (Section 11).

Gorard revisited the early 20th-century debate between Fisher and Eddington over whether the mean deviation or the SD is preferable. He argued that the mean deviation is easier to understand and degrades less when data contain small errors, conceding that the SD is more efficient for perfectly normal data.12 Under normality, E|X − μ| = σ√(2/π) ≈ 0.798σ, so MeanAD / 0.798 estimates σ.12

m = sum(data) / len(data)
mean_ad = sum(abs(v - m) for v in data) / len(data)    # 7.48
import pandas as pd
# note: Series.mad() was removed in pandas 2.0; compute directly:
s = pd.Series(data); print((s - s.mean()).abs().mean())   # 7.48

7. Median absolute deviation (MAD)

DefinitionMAD = mediani |xi − medianj(xj)|      MADN = 1.4826 × MAD

The MAD replaces both averaging steps of the MeanAD with medians: take the median, compute absolute deviations from it, and take their median. Hampel popularised it as a robust scale estimator; it has a breakdown point of 50%, the highest possible, meaning almost half the data can be arbitrarily corrupted before the estimate becomes unbounded.13,14

Normal consistency. Because the MAD of a normal distribution is Φ−1(0.75)·σ ≈ 0.6745σ, multiplying by b = 1/Φ−1(0.75) ≈ 1.4826 makes MADN a consistent estimator of σ for normal data.13 SciPy applies this factor when you pass scale="normal"; its default is the raw, unscaled MAD.15 (R's mad(), by contrast, applies 1.4826 by default.)

Worked example on D

  1. Median of D = (20 + 21)/2 = 20.5.
  2. Absolute deviations: 8.5, 5.5, 3.5, 2.5, 0.5, 0.5, 1.5, 3.5, 4.5, 37.5.
  3. Sorted: 0.5, 0.5, 1.5, 2.5, 3.5, 3.5, 4.5, 5.5, 8.5, 37.5 → median = 3.5.
  4. MADN = 1.4826 × 3.5 = 5.19 ms.

The outlier occupies only the last position of the sorted deviations; whether it is 58 or 58,000, the MAD is unchanged.

Outlier detection with robust z-scores

Leys and colleagues argue that the common rule "flag points more than 2 or 3 SDs from the mean" is self-defeating, because the outliers inflate the very mean and SD used to detect them. They recommend flagging values whose distance from the median exceeds a multiple of MADN, suggesting 2.5 as a reasonable default threshold (3 being very conservative and 2 poorly conservative).16

from scipy import stats
import numpy as np
x = np.asarray(data, float)
madn = stats.median_abs_deviation(x, scale="normal")   # 5.189
robust_z = (x - np.median(x)) / madn
print(x[np.abs(robust_z) > 2.5])                      # [58.]   (robust z = 7.23)

classic_z = (x - x.mean()) / x.std(ddof=1)
print(classic_z.max().round(2))                         # 2.7  -- masked by its own influence
Masking. With the classical rule and a threshold of 3, the outlier in D would not be flagged at all (its z-score is only 2.70), because it inflated the SD from 4.24 to 12.87. This is the masking effect that robust scale estimators avoid.16

Limitations. The MAD's Gaussian efficiency is only about 37%: for clean normal data it is a far noisier estimate of σ than the SD.13 It also implicitly assumes symmetry, since it measures distance from the median equally in both directions; for strongly skewed data, consider Sn or Qn (Section 11), which do not need a symmetric centre.13 And when more than half the values are identical, the MAD is zero.

8. Coefficient of variation (CV)

DefinitionCV = σμ   estimated by   sx̄   (often reported × 100%)

The CV expresses the SD relative to the mean, producing a unitless number that allows the variability of quantities measured on different scales, or with very different means, to be compared.1 For D, CV = 12.87 / 23.2 = 0.555 (55%); without the outlier, 4.24 / 19.33 = 22%.

When the CV is meaningful

  • Ratio scale only. The CV requires a true zero, so it is meaningful for lengths, weights, concentrations and durations but not for interval-scale quantities such as temperature in °C or °F, where the "mean" depends on an arbitrary origin (see Exercise 4).1
  • Positive data. As the mean approaches zero the CV explodes, and it is undefined or meaningless when the mean is zero or negative.
  • Not robust. It inherits the sensitivity of both the mean and the SD. A robust analogue is the quartile coefficient of dispersion (Section 10).17
from scipy import stats
stats.variation(data, ddof=1)     # 0.5545  (SciPy's default ddof is 0; pass ddof=1 for s/x̄)
Typical uses. Assay precision in laboratory medicine (intra- and inter-assay CV), comparing the volatility of assets with different price levels, and comparing variability of measurements recorded in different units.

9. Standard error

Standard error of the meanSE(x̄) = σ√n   estimated by   SEM = s√n

The standard error of a statistic is the standard deviation of its sampling distribution: how much the statistic would vary across repeated samples of the same size. For the mean of n independent observations, Var(x̄) = σ2/n, which gives the formula above.8

Altman and Bland summarise the distinction: the SD describes the variability of individual observations, while the SE describes the uncertainty in an estimate of the mean; the SE shrinks as the sample grows, whereas the SD does not systematically change. Using the SEM in place of the SD to describe a sample makes the data look less variable than they are.18

For D, SEM = 12.87 / √10 = 4.07 ms. An approximate 95% confidence interval for the population mean is x̄ ± t0.975, 9·SEM = 23.2 ± 2.262 × 4.07 = (14.0, 32.4) ms; the t quantile replaces 1.96 because σ is estimated from only 10 observations.8

Standard errors of other statistics

Every estimator has a standard error. For the median of a large normal sample, SE ≈ 1.2533·σ/√n, which reflects the median's lower efficiency (about 64%) under normality.8 When no formula is available, or its assumptions are doubtful, the bootstrap estimates the SE as the SD of the statistic recomputed on many resamples drawn with replacement from the data.19

import numpy as np
from scipy import stats
x = np.asarray(data, float)
print(stats.sem(x))                               # 4.068  (ddof=1 by default)

rng = np.random.default_rng(2026)
boot = rng.choice(x, size=(10_000, x.size), replace=True)
print(np.median(boot, axis=1).std(ddof=1))        # bootstrap SE of the median, about 2.2
print(boot.mean(axis=1).std(ddof=1))              # bootstrap SE of the mean,   about 3.9

10. Quantile-based dispersion measures

The IQR is one member of a family of measures built from the distance between two quantiles. Choosing the quantiles trades off robustness against the amount of the distribution described.3,5

The normal equivalents follow from the standard normal quantiles (for example Φ−1(0.90) = 1.2816, so the interdecile range is 2 × 1.2816σ). Dividing any of these spreads by its normal equivalent gives a robust estimate of σ when the centre of the distribution is approximately normal.

Quartile coefficient of dispersion. The QCD is a robust, unit-free alternative to the CV for positive ratio-scale data; Bonett derived a confidence interval for it and noted that it is preferable to the CV for non-normal data.17

Asymmetric spreads. Reporting the lower and upper half-spreads separately (median − Q1 and Q3 − median) reveals skewness that any single symmetric number hides. In D they are 3.25 and 3.0, so the middle half is roughly symmetric even though the full sample is not.

import numpy as np
x = np.asarray(data, float)
p = np.percentile(x, [2.5, 10, 25, 50, 75, 90, 97.5])
q025, q10, q25, q50, q75, q90, q975 = p
print("interdecile", q90 - q10)                  # 13.6
print("central 95%", q975 - q025)               # 37.9
print("QCD", (q75 - q25) / (q75 + q25))         # 0.153
print("half-spreads", q50 - q25, q75 - q50)     # 3.25 3.0

11. Robust measures of scale

A scale estimator is robust if a small fraction of bad data cannot distort it much. Two tools make this precise.3,14

  • Breakdown point: the smallest fraction of observations that, when replaced by arbitrary values, can drive the estimate to infinity (or to zero, for a scale estimator). The SD, variance, range and MeanAD have breakdown point 0 (one bad point suffices); the IQR has 25%; the MAD, Sn and Qn have 50%.13
  • Influence function: the effect on the estimate of an infinitesimal contamination at a point x. A bounded influence function means no single observation can have unbounded effect. Hampel introduced this concept.14

Robustness has a price: a robust estimator is typically less efficient (has higher variance) than the SD when the data really are normal. The design problem is to gain high breakdown with as little loss of efficiency as possible.3,13

Rousseeuw–Croux Sn and Qn

Rousseeuw and Croux proposed two estimators that keep the MAD's 50% breakdown point but do not depend on a location estimate and are more efficient:13

SnSn = c · medi { medj |xi − xj| },   c = 1.1926
QnQn = d · { |xi − xj| ; i < j }(k),   k = C(h, 2), h = ⌊n/2⌋ + 1,   d = 2.2219

Qn is (a constant times) roughly the first quartile of all pairwise distances. Its Gaussian efficiency is about 82%, compared with 58% for Sn and 37% for the MAD.13 The constants make both consistent for σ at the normal; in small samples Rousseeuw and Croux also apply finite-sample correction factors, which our simple implementations below omit, so they overstate σ for very small n (as visible in Table 1). Efficient O(n log n) algorithms exist; the versions below are O(n2) for clarity.13

Other robust scale estimators

  • Biweight midvariance. An M-type estimator that down-weights observations smoothly according to their distance from the median in units of MAD, giving zero weight beyond a cut-off (conventionally 9 MADs). It combines high breakdown with good efficiency across a range of distributions.20 For D its square root is 4.47 ms.
  • Winsorized and trimmed variances. Replace (Winsorize) or remove (trim) a fixed fraction of the most extreme values in each tail before computing the variance. The 20% Winsorized variance is the usual companion to the 20% trimmed mean in robust hypothesis testing.21
  • Gini's mean difference. The average absolute difference between all pairs of observations, Σi<j|xi − xj| / C(n, 2). Like the SD it has breakdown point 0, but Yitzhaki shows that it has properties that make it preferable to the variance for non-normal distributions, and it underlies the Gini coefficient of inequality.22
  • M-estimators of scale. Huber's general framework solves an estimating equation that bounds the contribution of each residual; the MAD is a special case.3

13. Complete Python module

The module below implements every measure in this article using only the Python standard library, so each formula is visible. It was run with Python 3 and cross-checked against NumPy 2.5 and SciPy 1.18, which agree to floating-point precision for range, IQR, variance, SD, MAD, CV and SEM.

"""dispersion.py - measures of dispersion from first principles (standard library only)."""
import math
from statistics import NormalDist

def _sorted(x):
    xs = sorted(float(v) for v in x)
    if not xs:
        raise ValueError("need at least one observation")
    return xs

def mean(x):
    return math.fsum(x) / len(x)

def median(x):
    xs = _sorted(x); n = len(xs); m = n // 2
    return xs[m] if n % 2 else (xs[m - 1] + xs[m]) / 2

def quantile(x, p):
    """Hyndman-Fan type 7 (linear interpolation; NumPy/R default)."""
    xs = _sorted(x); h = (len(xs) - 1) * p
    lo = math.floor(h); hi = min(lo + 1, len(xs) - 1)
    return xs[lo] + (h - lo) * (xs[hi] - xs[lo])

def data_range(x):
    xs = _sorted(x)
    return xs[-1] - xs[0]

def iqr(x):
    return quantile(x, 0.75) - quantile(x, 0.25)

def variance(x, ddof=1):
    """Two-pass algorithm: numerically stable, unlike sum(x^2) - n*mean^2."""
    m = mean(x)
    return math.fsum((v - m) ** 2 for v in x) / (len(x) - ddof)

def std(x, ddof=1):
    return math.sqrt(variance(x, ddof))

def welford(stream):
    """One-pass (online) mean and sample variance (Welford, 1962)."""
    n, m, m2 = 0, 0.0, 0.0
    for v in stream:
        n += 1
        d = v - m
        m += d / n
        m2 += d * (v - m)
    return m, (m2 / (n - 1) if n > 1 else float("nan"))

def mean_abs_dev(x, center=None):
    c = mean(x) if center is None else center
    return mean([abs(v - c) for v in x])

MAD_K = 1 / NormalDist().inv_cdf(0.75)          # 1.482602...

def mad(x, normal=True):
    med = median(x)
    raw = median([abs(v - med) for v in x])
    return MAD_K * raw if normal else raw

def coef_var(x):
    m = mean(x)
    if m <= 0:
        raise ValueError("CV is only meaningful for positive, ratio-scale data")
    return std(x) / m

def sem(x):
    return std(x) / math.sqrt(len(x))

def quantile_spread(x, lo=0.10, hi=0.90):
    return quantile(x, hi) - quantile(x, lo)

def quartile_coef_dispersion(x):
    q1, q3 = quantile(x, 0.25), quantile(x, 0.75)
    return (q3 - q1) / (q3 + q1)

def sn(x, c=1.1926):
    """Rousseeuw-Croux Sn (no small-sample correction), O(n^2)."""
    return c * median([median([abs(xi - xj) for xj in x]) for xi in x])

def qn(x, d=2.2219):
    """Rousseeuw-Croux Qn (no small-sample correction), O(n^2)."""
    n = len(x); h = n // 2 + 1; k = h * (h - 1) // 2
    diffs = sorted(abs(x[i] - x[j]) for i in range(n) for j in range(i + 1, n))
    return d * diffs[k - 1]

def biweight_midvariance(x, c=9.0):
    """Tukey biweight midvariance (Hoaglin, Mosteller & Tukey, 1983)."""
    med, raw = median(x), mad(x, normal=False)
    u = [(v - med) / (c * raw) for v in x]
    num = sum((v - med) ** 2 * (1 - ui * ui) ** 4 for v, ui in zip(x, u) if abs(ui) < 1)
    den = sum((1 - ui * ui) * (1 - 5 * ui * ui) for ui in u if abs(ui) < 1)
    return len(x) * num / den ** 2

if __name__ == "__main__":
    data = [12, 15, 17, 18, 20, 21, 22, 24, 25, 58]
    report = {
        "mean": mean(data), "median": median(data),
        "range": data_range(data), "IQR": iqr(data),
        "variance (n-1)": variance(data), "SD (n-1)": std(data),
        "mean abs dev": mean_abs_dev(data),
        "MAD (raw)": mad(data, normal=False), "MAD (x1.4826)": mad(data),
        "CV": coef_var(data), "SEM": sem(data),
        "P90-P10": quantile_spread(data), "QCD": quartile_coef_dispersion(data),
        "Sn": sn(data), "Qn": qn(data),
        "biweight midSD": math.sqrt(biweight_midvariance(data)),
    }
    for name, value in report.items():
        print(f"{name:>16}: {value:8.3f}")

14. Exercises with solutions

Exercise 1. Computing by hand

For the data 4, 8, 6, 5, 3, 7 compute the range, IQR (type 7), sample variance, sample SD, mean absolute deviation, raw MAD and MADN.

Show solution

Sorted: 3, 4, 5, 6, 7, 8. Mean = 33/6 = 5.5; median = (5 + 6)/2 = 5.5.

  • Range = 8 − 3 = 5.
  • Type 7: h = 5(0.25) + 1 = 2.25 → Q1 = 4 + 0.25(1) = 4.25; h = 5(0.75) + 1 = 4.75 → Q3 = 6 + 0.75(1) = 6.75. IQR = 2.5.
  • Deviations ±2.5, ±1.5, ±0.5; squares sum to 2(6.25 + 2.25 + 0.25) = 17.5. s2 = 17.5/5 = 3.5; s = 1.871.
  • MeanAD = 2(2.5 + 1.5 + 0.5)/6 = 1.5.
  • Absolute deviations from the median: 0.5, 0.5, 1.5, 1.5, 2.5, 2.5 → MAD = 1.5; MADN = 1.4826 × 1.5 = 2.224.

Exercise 2. Population versus sample

A class of 6 students is the whole population of interest, with the scores above. Which divisor should you use, and what is σ? If instead the 6 are a random sample from a school, which divisor applies?

Show solution

For the complete population use N: σ2 = 17.5/6 = 2.917, σ = 1.708. For a sample used to estimate the school's variance, use n − 1 to obtain an unbiased estimate: s2 = 3.5, s = 1.871.8 In Python, statistics.pstdev versus statistics.stdev.7

Exercise 3. Comparing variability with the CV

Machine A fills 500 g bags with SD 10 g. Machine B fills 50 g sachets with SD 2 g. Which machine is relatively more consistent?

Show solution

CVA = 10/500 = 2%; CVB = 2/50 = 4%. Machine B has the smaller absolute SD but is relatively twice as variable. Mass is a ratio-scale quantity, so the CV is appropriate.1

Exercise 4. When the CV fails

Daily temperatures have mean 10 °C and SD 5 °C. Compute the CV in Celsius, then convert to Fahrenheit (F = 1.8C + 32) and compute it again. What do you conclude?

Show solution

Celsius: CV = 5/10 = 0.50. Fahrenheit: mean = 1.8(10) + 32 = 50 °F, SD = 1.8(5) = 9 °F (the shift does not affect the SD, since Var(aX + b) = a2Var(X)), so CV = 9/50 = 0.18. The same weather gives two different CVs because neither scale has a true zero. The CV is meaningless for interval-scale data; on the Kelvin scale (mean 283.15 K, SD 5 K) it would be 0.018.1,8

Exercise 5. Standard error and sample size

A pilot study of 25 patients finds systolic blood pressure SD = 15 mmHg. (a) What is the SEM? (b) How many patients are needed to halve it? (c) A paper reports "mean 132 ± 3 mmHg" for these data. What is wrong?

Show solution

(a) SEM = 15/√25 = 3 mmHg. (b) The SE is proportional to 1/√n, so halving it needs 4× the sample: 100 patients. (c) "± 3" is the SEM, which suggests that individual pressures vary by only a few mmHg when in fact they vary with SD 15. To describe the patients, report the SD; to describe precision of the mean, report a confidence interval.18

Exercise 6. Estimating σ from quantiles

A report gives only the median (120) and the IQR (27) of a roughly normal variable. Estimate σ. If the MAD were reported as 13.5, what estimate would that give?

Show solution

σ ≈ IQR/1.349 = 27/1.349 = 20.0. From the MAD: σ ≈ 1.4826 × 13.5 = 20.0. The two agree, as they must for symmetric data, since for a symmetric distribution the quartiles are exactly median ± MAD and so IQR = 2·MAD.3,13

Exercise 7. Breakdown points

You have n = 21 observations. What is the largest number that can be replaced by arbitrarily large values while (a) the SD stays bounded, (b) the IQR stays bounded, (c) the MAD stays bounded?

Show solution

(a) 0: a single arbitrarily large value makes the SD arbitrarily large. (b) The IQR depends on the 25th and 75th percentiles; with type 7 these are x(6) and x(16), so up to 5 values in the upper tail (the top five order statistics) can be moved without affecting Q3. That is about 25%. (c) The median of 21 values is x(11), and the median of the 21 absolute deviations is likewise the 11th smallest; replacing 10 values (just under 50%) leaves at least 11 clean deviations, so the MAD stays bounded.13

Exercise 8. Robust outlier screen (coding)

Write a function flag_outliers(x, k=2.5) that returns the values whose robust z-score, (x − median)/MADN, exceeds k in absolute value. Test it on 52, 55, 57, 58, 60, 61, 63, 95, and compare with the classical rule |z| > 2.5 using mean and SD.

Show solution 
import numpy as np
from scipy import stats

def flag_outliers(x, k=2.5):
    x = np.asarray(x, float)
    madn = stats.median_abs_deviation(x, scale="normal")
    if madn == 0:
        raise ValueError("MAD is zero: more than half the values are identical")
    z = (x - np.median(x)) / madn
    return x[np.abs(z) > k]

x = [52, 55, 57, 58, 60, 61, 63, 95]
print(flag_outliers(x))                           # [95.]
xa = np.asarray(x, float)
z = (xa - xa.mean()) / xa.std(ddof=1)
print(xa[np.abs(z) > 2.5], z.max().round(2))    # []  2.39

The median is 59 and MADN = 4.448, so the value 95 has robust z = 8.09 and is flagged. The classical z-score of 95 is only 2.39, because 95 itself inflates the SD to 13.5; the classical rule misses it. This is the masking effect described by Leys et al.16

Exercise 9. Numerical stability (coding)

Explain why sum(x*x)/n - mean(x)**2 can return a negative "variance", and give a data set where it happens in double precision.

Show solution

Both terms are of order 1018 for values near 109, but their difference is of order 10, smaller than the spacing between adjacent doubles at 1018 (about 128). Rounding errors in either term swamp the true difference, which can come out as zero or negative. With z = [1e9+4, 1e9+7, 1e9+13, 1e9+16] the shortcut gives 0.0 in pure Python and −170.7 in NumPy, while the true sample variance is 30. Use the two-pass or Welford algorithm.9,10
