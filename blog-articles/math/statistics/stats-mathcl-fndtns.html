Statistics is applied mathematics with uncertainty attached. A sample space is a set, a random variable is a function, an expectation is an integral, a regression is a projection, an estimator is usually the solution of an optimisation problem, and a computed answer is only as good as the floating-point arithmetic behind it. Standard graduate texts in statistical inference assume this material and use it on nearly every page [2]. This article collects it in one place, in the order in which the ideas depend on each other.

Each section gives definitions, the key results (with a reference for each one), a worked statistical example, a short runnable Python listing, and exercises with hidden solutions. Notation follows the international standard for mathematical signs and symbols, ISO 80000-2, where a convention exists [3].

1Sets, functions and relations

A set is a collection of distinct objects, its elements; we write \(x \in A\) when \(x\) is an element of \(A\). Two sets are equal exactly when they have the same elements (the axiom of extensionality) [4,5]. Sets are described by listing, \(A = \{2, 4, 6\}\), or by a property, \(A\) \(= \{x \in \mathbb{Z} : x \text{ is even},\ 0 \lt x \lt 8\}\). The standard number sets are \(\mathbb{N}\) (natural numbers), \(\mathbb{Z}\) (integers), \(\mathbb{Q}\) (rationals) and \(\mathbb{R}\) (reals) [3].

Definition 1.1 · Set operations

For subsets \(A, B\) of a universal set \(\Omega\): union \(A\) \(\cup B\) \(= \{x : x \in A \text{ or } x \in B\}\); intersection \(A \cap B\) \(= \{x : x \in A \text{ and } x \in B\}\); difference \(A \setminus B\) \(= \{x \in A : x \notin B\}\); complement \(A^{c} = \Omega \setminus A\). \(A \subseteq B\) means every element of \(A\) is in \(B\). The power set \(\mathcal{P}(A)\) is the set of all subsets of \(A\); if \(A\) has \(n\) elements, \(\mathcal{P}(A)\) has \(2^n\) [4].

In probability the universal set is the sample space \(\Omega\) of possible outcomes, and events are subsets of it [2]. "A or B" is \(A \cup B\), "A and B" is \(A \cap B\), "not A" is \(A^c\). Events are disjoint (mutually exclusive) when \(A \cap B = \varnothing\).

Theorem 1.2 · De Morgan's laws

For any family of sets \(\{A_i\}_{i \in I}\), \(\left(\bigcup_{i} A_i\right)^c\) \(= \bigcap_{i} A_i^c\) and \(\left(\bigcap_{i} A_i\right)^c\) \(= \bigcup_{i} A_i^c\) [4,6].

Cartesian products and relations

The Cartesian product \(A \times B\) is the set of ordered pairs \((a, b)\) with \(a \in A\), \(b \in B\). A relation from \(A\) to \(B\) is any subset \(R \subseteq A \times B\); we write \(a\,R\,b\) for \((a,b) \in R\) [5]. A relation on \(A\) is an equivalence relation if it is reflexive (\(a R a\)), symmetric (\(a R b \Rightarrow b R a\)) and transitive (\(a R b,\ b R c \Rightarrow a R c\)). An equivalence relation splits \(A\) into disjoint equivalence classes, that is, a partition of \(A\) [6]. Partitions are what the law of total probability, \(P(B) = \sum_i P(B \mid A_i) P(A_i)\), is stated over [2]. A relation that is reflexive, antisymmetric and transitive is a partial order, such as \(\subseteq\) on \(\mathcal{P}(A)\) or \(\le\) on \(\mathbb{R}\).

Functions

Definition 1.3 · Function

A function \(f : X \to Y\) is a relation \(f \subseteq X \times Y\) such that every \(x \in X\) is paired with exactly one \(y \in Y\), written \(y = f(x)\). \(X\) is the domain, \(Y\) the codomain, and \(f(X) = \{f(x) : x \in X\}\) the image or range. \(f\) is injective (one-to-one) if \(f(x_1) = f(x_2) \Rightarrow x_1 = x_2\), surjective (onto) if \(f(X) = Y\), and bijective if both; a bijection has an inverse \(f^{-1}: Y \to X\) [5,6].

The preimage of \(B \subseteq Y\) is \(f^{-1}(B) = \{x \in X : f(x) \in B\}\), defined whether or not \(f\) is invertible. Preimages are central to probability: a random variable is a function \(X : \Omega \to \mathbb{R}\), and the probability that \(X\) lands in a set \(B\) is \(P(X \in B) = P(X^{-1}(B))\) [2,7]. Preimages respect set operations, \(f^{-1}(B_1\) \(\cup B_2)\) \(= f^{-1}(B_1)\) \(\cup f^{-1}(B_2)\) and \(f^{-1}(B^c) = (f^{-1}(B))^c\), which is why the distribution of a random variable inherits the rules of probability [8].

Cardinality. Two sets have the same cardinality if there is a bijection between them. \(\mathbb{N}\), \(\mathbb{Z}\) and \(\mathbb{Q}\) are countable, but \(\mathbb{R}\) is uncountable (Cantor's diagonal argument) [4,9]. The distinction matters later: probability is additive over countable unions of disjoint events but not over uncountable ones (Section 10).

Exercises 1

  1. Let \(\Omega = \{1,\dots,6\}\) (one die roll), \(A\) = "even", \(B\) = "at least 4". List \(A \cup B\), \(A \cap B\), \(A^c \cap B\) and check \((A\cap B)^c = A^c \cup B^c\).

    Solution

    \(A = \{2,4,6\}\), \(B = \{4,5,6\}\). \(A \cup B = \{2,4,5,6\}\), \(A \cap B = \{4,6\}\), \(A^c \cap B\) \(= \{1,3,5\} \cap \{4,5,6\}\) \(= \{5\}\). \((A \cap B)^c = \{1,2,3,5\}\) and \(A^c\) \(\cup B^c\) \(= \{1,3,5\}\) \(\cup \{1,2,3\}\) \(= \{1,2,3,5\}\), as De Morgan's law requires.

  2. Is \(f : \mathbb{R} \to \mathbb{R}\), \(f(x) = x^2\) injective? Surjective? Find \(f^{-1}([1, 4])\).

    Solution

    Not injective, since \(f(-1) = f(1)\). Not surjective onto \(\mathbb{R}\), since no \(x\) has \(x^2 = -1\). \(f^{-1}([1,4])\) \(= \{x : 1 \le x^2 \le 4\}\) \(= [-2,-1]\) \(\cup [1,2]\). Restricting the domain and codomain to \([0,\infty)\) makes it a bijection with inverse \(\sqrt{y}\).

  3. On \(\mathbb{R}^n\) define \(\mathbf{x} \sim \mathbf{y}\) if \(\mathbf{y}\) is a reordering of \(\mathbf{x}\). Show that \(\sim\) is an equivalence relation and describe its classes. Why does this matter for i.i.d. data?

    Solution

    Reflexive (the identity reordering), symmetric (undo a permutation with its inverse), transitive (compose two permutations). Each class is the set of all orderings of one multiset of values, so it can be represented by the sorted vector, the order statistics \((x_{(1)},\dots,x_{(n)})\). For i.i.d. data the likelihood is the same for every member of a class, so the order statistics are sufficient [2].

Rules for sums and products

Sums are linear: \(\sum (a x_i + b y_i)\) \(= a \sum x_i + b \sum y_i\), and a constant summed \(n\) times gives \(\sum_{i=1}^{n} c = nc\). Double sums can be exchanged when finite, \(\sum_i \sum_j a_{ij}\) \(= \sum_j \sum_i a_{ij}\) [10]. Logarithms turn products into sums, \(\log \prod p_i = \sum \log p_i\), which is why statisticians maximise the log-likelihood \(\ell(\theta)\) \(= \sum_i \log f(x_i;\theta)\) instead of the likelihood itself [2].

Worked example 2.1 · The computational formula for variance

Expand the square and use linearity, with \(\sum x_i = n\bar x\):

\[\sum_{i=1}^{n}(x_i-\bar x)^2=\sum x_i^2-2\bar x\sum x_i+n\bar x^2=\sum x_i^2-2n\bar x^2+n\bar x^2=\sum_{i=1}^{n}x_i^2-n\bar x^2 .\]

The identity is exact algebra, but Section 11 shows that evaluating the right-hand side in floating point can lose every significant digit.

Exponents, logarithms and the exponential function

For \(a \gt 0\): \(a^{x}a^{y} = a^{x+y}\), \((a^x)^y = a^{xy}\), \(\log(xy) = \log x + \log y\), \(\log(x^k) = k\log x\). In statistics "\(\log\)" means the natural logarithm, base \(e \approx 2.71828\), unless stated otherwise. The exponential function and its inverse are defined rigorously through power series and limits (Section 3) [9,11].

Inequalities

Many proofs in statistics are chains of inequalities. Three recur constantly:

  • Triangle inequality. \(|a + b| \le |a| + |b|\) [9].
  • Cauchy–Schwarz. \(\left(\sum a_i b_i\right)^2\) \(\le \left(\sum a_i^2\right)\left(\sum b_i^2\right)\), with equality iff one vector is a multiple of the other [12]. It is why a correlation coefficient lies in \([-1, 1]\).
  • AM–GM. For \(x_i \ge 0\), \(\frac{1}{n}\sum x_i \ge \left(\prod x_i\right)^{1/n}\) [11]; it is a special case of Jensen's inequality (Section 7.1).

import math

x = [2.1, 3.4, 1.9, 5.0, 4.2]
n = len(x)
mean = sum(x) / n                              # x̄ = (1/n) Σ xᵢ
ss = sum((xi - mean) ** 2 for xi in x)         # Σ (xᵢ − x̄)²
s2 = ss / (n - 1)                              # sample variance
# Algebraic identity: Σ (xᵢ − x̄)² = Σ xᵢ² − n x̄²
identity = math.isclose(ss, sum(xi * xi for xi in x) - n * mean**2)
print(f"mean = {mean:.4f}, s² = {s2:.4f}, identity holds: {identity}")

# Products become sums under the logarithm: log Π pᵢ = Σ log pᵢ
p = [0.01] * 400                               # 400 likelihood factors
print("product of factors:", math.prod(p))     # 1e-800 underflows to 0.0
print("sum of log factors:", sum(math.log(pi) for pi in p))

Exercises 2

  1. Show that \(\sum_{i=1}^{n}(x_i - \bar x) = 0\) for any data set.

    Solution

    \(\sum (x_i - \bar x)\) \(= \sum x_i - n\bar x\) \(= n\bar x - n \bar x\) \(= 0\). This is why one degree of freedom is "used up" by estimating the mean: the \(n\) deviations satisfy one linear constraint.

  2. Write the log-likelihood of \(n\) independent Bernoulli(\(p\)) observations \(x_i \in \{0,1\}\) and simplify it using \(s = \sum x_i\).

    Solution

    \(L(p) = \prod p^{x_i}(1-p)^{1-x_i}\), so \(\ell(p)\) \(= \sum [x_i \log p + (1-x_i)\log(1-p)]\) \(= s\log p + (n-s)\log(1-p)\). The data enter only through \(s\), which is therefore sufficient for \(p\) [2].

  3. Use Cauchy–Schwarz to show that the sample correlation \(r\) \(= \frac{\sum (x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum (x_i-\bar x)^2 \sum (y_i-\bar y)^2}}\) satisfies \(|r| \le 1\).

    Solution

    Put \(a_i = x_i - \bar x\), \(b_i = y_i - \bar y\). Cauchy–Schwarz gives \((\sum a_i b_i)^2\) \(\le \sum a_i^2 \sum b_i^2\); divide both sides by the right-hand side and take square roots. Equality, \(|r| = 1\), holds iff \(b = c\,a\) for some constant \(c\), meaning the points lie exactly on a line.

3Sequences, series and limits

Asymptotic statistics (consistency, the central limit theorem, large-sample confidence intervals) is a theory of limits. The \(\varepsilon\)–\(N\) definition makes "gets arbitrarily close" precise.

Definition 3.1 · Limit of a sequence

A sequence \((a_n)\) of real numbers converges to \(L\), written \(a_n \to L\) or \(\lim_{n\to\infty} a_n = L\), if \[\forall \varepsilon \gt 0\ \ \exists N \in \mathbb{N}\ \text{such that}\ n \gt N \implies |a_n - L| \lt \varepsilon .\] A sequence that does not converge diverges [9,13].

Limits obey algebra: if \(a_n \to a\) and \(b_n \to b\), then \(a_n + b_n \to a + b\), \(a_n b_n \to ab\), and \(a_n / b_n \to a/b\) when \(b \ne 0\) [9]. A bounded monotone sequence always converges (the monotone convergence theorem for sequences), which is how \(e = \lim (1 + 1/n)^n\) is shown to exist [9,13].

Series

A series \(\sum_{k=0}^{\infty} a_k\) is the limit of its partial sums \(S_n = \sum_{k=0}^{n} a_k\). Results used constantly:

  • Geometric series. \(\sum_{k=0}^{\infty} r^k\) \(= \frac{1}{1-r}\) for \(|r| \lt 1\), divergent otherwise [9]. The mean of a geometric distribution follows from differentiating it.
  • \(p\)-series. \(\sum 1/k^p\) converges iff \(p \gt 1\); the harmonic series \(\sum 1/k\) diverges [9].
  • Exponential series. \(e^{x} = \sum_{k=0}^{\infty} x^k/k!\) for every real \(x\) [9]. It normalises the Poisson distribution: \(\sum_{k} e^{-\lambda}\lambda^k/k!\) \(= e^{-\lambda}e^{\lambda}\) \(= 1\).
  • Absolute convergence. If \(\sum |a_k|\) converges then so does \(\sum a_k\), and every rearrangement has the same sum; a conditionally convergent series can be rearranged to any sum (Riemann's rearrangement theorem) [9]. This is why an expectation \(E[X] = \sum x\,p(x)\) is defined only when \(\sum |x|\,p(x) \lt \infty\) [7].

Taylor's theorem

Theorem 3.2 · Taylor's theorem with remainder

If \(f\) has \(n+1\) continuous derivatives on an interval containing \(a\) and \(x\), then \[f(x)=\sum_{k=0}^{n}\frac{f^{(k)}(a)}{k!}(x-a)^k+R_n(x),\qquad R_n(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}(x-a)^{n+1}\] for some \(\xi\) between \(a\) and \(x\) [9,14].

The delta method is first-order Taylor expansion applied to an estimator: if \(\sqrt{n}(\hat\theta - \theta) \to N(0,\sigma^2)\) in distribution and \(g'(\theta) \ne 0\), then \(\sqrt{n}(g(\hat\theta) - g(\theta)) \to N(0, \sigma^2 g'(\theta)^2)\) [2].

Limits of functions and continuity

\(\lim_{x \to a} f(x) = L\) means: \(\forall\varepsilon \gt 0\ \exists\delta \gt 0\) with \(0 \lt |x - a| \lt \delta\) \(\Rightarrow |f(x) - L| \lt \varepsilon\). \(f\) is continuous at \(a\) if \(\lim_{x\to a} f(x) = f(a)\); equivalently, \(x_n \to a\) implies \(f(x_n) \to f(a)\) [9,13]. The sequential form is the mathematical core of the continuous mapping theorem: if \(\hat\theta_n \to \theta\) then \(g(\hat\theta_n) \to g(\theta)\) for continuous \(g\) [2].

Exercises 3

  1. Prove from the definition that \(a_n = \frac{3n+1}{n} \to 3\).

    Solution

    \(|a_n - 3| = 1/n\). Given \(\varepsilon \gt 0\), choose an integer \(N \ge 1/\varepsilon\). Then \(n \gt N\) gives \(1/n \lt 1/N \le \varepsilon\).

  2. For \(X \sim \text{Geometric}(p)\) with \(P(X = k) = (1-p)^{k-1}p\), \(k = 1,2,\dots\), show \(E[X] = 1/p\) by differentiating the geometric series.

    Solution

    For \(|q| \lt 1\), \(\sum_{k\ge0} q^k = (1-q)^{-1}\). Power series can be differentiated term by term inside their radius of convergence [9], so \(\sum_{k\ge1} k q^{k-1} = (1-q)^{-2}\). With \(q = 1-p\): \(E[X] = p\sum k q^{k-1} = p/p^2 = 1/p\).

  3. Use the delta method to find the approximate variance of \(\log \bar X\) when \(X_i\) are i.i.d. with mean \(\mu \gt 0\) and variance \(\sigma^2\).

    Solution

    \(g(t) = \log t\), \(g'(\mu) = 1/\mu\). By the CLT \(\sqrt n(\bar X - \mu) \to N(0,\sigma^2)\), so \(\sqrt n (\log\bar X - \log\mu) \to N(0, \sigma^2/\mu^2)\) and \(\operatorname{Var}(\log \bar X)\) \(\approx \sigma^2/(n\mu^2)\), the squared coefficient of variation divided by \(n\).

4Differential and integral calculus

Derivatives

Definition 4.1 · Derivative

\(f\) is differentiable at \(x\) if the limit \[f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}\] exists. Geometrically \(f'(x)\) is the slope of the tangent line; analytically, \(f(x+h) = f(x) + f'(x)h + o(h)\) [11,14].

The working rules are linearity, the product rule \((fg)' = f'g + fg'\), the quotient rule, and the chain rule \((f\circ g)'(x) = f'(g(x))\,g'(x)\) [11,15]. For the standard normal density \(\varphi(z) = (2\pi)^{-1/2}e^{-z^2/2}\), the chain rule gives \(\varphi'(z) = -z\,\varphi(z)\), so \(\varphi\) increases for \(z \lt 0\), decreases for \(z \gt 0\), and has its mode at 0.

Theorem 4.2 · Mean value theorem and first-order conditions

If \(f\) is continuous on \([a,b]\) and differentiable on \((a,b)\), there is \(c \in (a,b)\) with \(f'(c) = \frac{f(b)-f(a)}{b-a}\). Consequently, at an interior local maximum or minimum of a differentiable \(f\), \(f'(x) = 0\); if also \(f''(x) \lt 0\) the point is a strict local maximum [9,11].

Worked example 4.3 · Maximum likelihood for an exponential rate

For \(x_1,\dots,x_n \overset{\text{iid}}{\sim} \text{Exp}(\lambda)\) with density \(\lambda e^{-\lambda x}\), the log-likelihood is \(\ell(\lambda)\) \(= n\log\lambda - \lambda\sum x_i\). Setting the score \(\ell'(\lambda) = n/\lambda - \sum x_i\) to zero gives \(\hat\lambda = 1/\bar x\). Since \(\ell''(\lambda) = -n/\lambda^2 \lt 0\) for all \(\lambda\), this stationary point is the global maximum [2].

Integrals

The Riemann integral \(\int_a^b f(x)\,dx\) is the common limit of sums \(\sum f(t_i)\Delta x_i\) over finer and finer partitions of \([a,b]\), when that limit exists; every continuous function on a closed interval is Riemann integrable [9,14].

Theorem 4.4 · Fundamental theorem of calculus

(i) If \(f\) is continuous on \([a,b]\) and \(F(x) = \int_a^x f(t)\,dt\), then \(F'(x) = f(x)\). (ii) If \(F' = f\) with \(f\) Riemann integrable on \([a,b]\), then \(\int_a^b f(x)\,dx = F(b) - F(a)\) [9,11].

In probability language: a continuous distribution's CDF \(F(x)\) \(= P(X\) \(\le x)\) \(= \int_{-\infty}^{x} f(t)\,dt\) has derivative equal to the density, and \(P(a \lt X \le b) = F(b) - F(a)\) [2]. Integrals over infinite ranges are improper integrals, defined as limits \(\int_{-\infty}^{\infty}\) \(= \lim_{a\to-\infty,\,b\to\infty}\int_a^b\).

Two techniques do most of the work:

  • Substitution (the chain rule in reverse): \(\int f(g(x))g'(x)\,dx = \int f(u)\,du\). It underlies the change-of-variables formula for densities: if \(Y = g(X)\) with \(g\) monotone and differentiable, \(f_Y(y)\) \(= f_X(g^{-1}(y))\,\bigl|\tfrac{d}{dy}g^{-1}(y)\bigr|\) [2].
  • Integration by parts: \(\int u\,dv = uv - \int v\,du\). Example: \(E[X]\) \(= \int_0^\infty x\lambda e^{-\lambda x}dx\) \(= [-xe^{-\lambda x}]_0^\infty + \int_0^\infty e^{-\lambda x}dx\) \(= 1/\lambda\).

The Gaussian integral. \(\int_{-\infty}^{\infty} e^{-x^2/2}\,dx\) \(= \sqrt{2\pi}\), which makes \(\varphi\) a density. It has no elementary antiderivative; the standard proof squares the integral and switches to polar coordinates (Section 5) [15,16]. The gamma function \(\Gamma(\alpha)\) \(= \int_0^\infty x^{\alpha-1}e^{-x}dx\) satisfies \(\Gamma(\alpha+1)\) \(= \alpha\Gamma(\alpha)\), \(\Gamma(n) = (n-1)!\) and \(\Gamma(1/2) = \sqrt\pi\) [16]; it normalises the gamma, chi-squared, \(t\) and beta families.

5Multivariable calculus

Statistical models usually have several parameters, so the log-likelihood is a function \(\ell : \mathbb{R}^p \to \mathbb{R}\). Its first and second derivatives become a vector and a matrix.

Definition 5.1 · Partial derivatives, gradient, Hessian, Jacobian

For \(f:\mathbb{R}^p\to\mathbb{R}\), the partial derivative \(\partial f/\partial x_j\) differentiates in coordinate \(j\) with the others held fixed. The gradient is the column vector \(\nabla f\) \(= (\partial f/\partial x_1,\dots,\partial f/\partial x_p)^{\mathsf T}\) and the Hessian is the \(p\times p\) matrix \(\nabla^2 f\) with entries \(\partial^2 f/\partial x_i\partial x_j\); it is symmetric when the second partials are continuous (Schwarz–Clairaut theorem). For \(\mathbf g:\mathbb{R}^p\to\mathbb{R}^m\) the Jacobian \(J_{\mathbf g}\) is the \(m\times p\) matrix of \(\partial g_i/\partial x_j\) [14,17].

The gradient points in the direction of steepest increase, and \(\|\nabla f\|\) is the rate of increase in that direction: the directional derivative along a unit vector \(\mathbf u\) is \(D_{\mathbf u}f\) \(= \nabla f^{\mathsf T}\mathbf u\), largest when \(\mathbf u\) is parallel to \(\nabla f\) (by Cauchy–Schwarz). The gradient is also perpendicular to the level sets \(\{f = c\}\) [15,17].

Second-order Taylor expansion. Near \(\mathbf a\), \[f(\mathbf a+\mathbf h)=f(\mathbf a)+\nabla f(\mathbf a)^{\mathsf T}\mathbf h+\tfrac12\,\mathbf h^{\mathsf T}\nabla^2 f(\mathbf a)\,\mathbf h+o(\|\mathbf h\|^2).\] At a stationary point (\(\nabla f = \mathbf 0\)), a negative definite Hessian means a strict local maximum and a positive definite one a strict local minimum (Section 6.5) [14,18]. In likelihood theory the negative Hessian of \(\ell\) at \(\hat\theta\) is the observed information, and its inverse estimates the covariance matrix of \(\hat\theta\) [2].

Multivariable chain rule. \(J_{\mathbf f\circ\mathbf g}(\mathbf x)\) \(= J_{\mathbf f}(\mathbf g(\mathbf x))\,J_{\mathbf g}(\mathbf x)\) [17]. Backpropagation in neural networks is this rule applied systematically [19].

Multiple integrals and change of variables

For continuous \(f\) on a rectangle, the double integral can be computed as an iterated integral in either order (Fubini's theorem) [8,17]. For an invertible, continuously differentiable map \(\mathbf x = \mathbf g(\mathbf u)\), \[\int_{\mathbf g(D)} f(\mathbf x)\,d\mathbf x=\int_{D} f(\mathbf g(\mathbf u))\,\bigl|\det J_{\mathbf g}(\mathbf u)\bigr|\,d\mathbf u .\] The factor \(|\det J|\) measures how the map stretches volume [14,17]. For random vectors it gives the multivariate density transformation \(f_{\mathbf Y}(\mathbf y)\) \(= f_{\mathbf X}(\mathbf g^{-1}(\mathbf y))\,|\det J_{\mathbf g^{-1}}(\mathbf y)|\) [2].

Worked example 5.2 · The Gaussian integral in polar coordinates

Let \(I\) \(= \int_{-\infty}^{\infty}e^{-x^2/2}dx\). By Fubini, \(I^2\) \(= \iint_{\mathbb{R}^2} e^{-(x^2+y^2)/2}\,dx\,dy\). With \(x = r\cos\theta,\ y = r\sin\theta\), \(|\det J| = r\), so \(I^2\) \(= \int_0^{2\pi}\!\int_0^\infty e^{-r^2/2}\,r\,dr\,d\theta\) \(= 2\pi\,[-e^{-r^2/2}]_0^\infty\) \(= 2\pi\). Hence \(I = \sqrt{2\pi}\) [15,17]. The same polar map, run backwards, is the Box–Muller method for generating normal variates [20].

Matrix calculus. Two identities cover most of linear-model theory: \(\nabla_{\mathbf x}(\mathbf a^{\mathsf T}\mathbf x)\) \(= \mathbf a\) and \(\nabla_{\mathbf x}(\mathbf x^{\mathsf T}\mathbf A\mathbf x)\) \(= (\mathbf A + \mathbf A^{\mathsf T})\mathbf x\), which is \(2\mathbf A\mathbf x\) for symmetric \(\mathbf A\) [21]. Applying them to \(\|\mathbf y - \mathbf X\boldsymbol\beta\|^2\) gives the gradient \(-2\mathbf X^{\mathsf T}(\mathbf y - \mathbf X\boldsymbol\beta)\), and setting it to zero gives the normal equations of Section 6.2.

6Linear algebra

Data sets are matrices, and most of classical statistics (regression, analysis of variance, principal components, the multivariate normal) is linear algebra with a probabilistic interpretation [22,23].

6.1Vectors and matrices

A vector \(\mathbf x \in \mathbb{R}^n\) is an ordered \(n\)-tuple, written as a column. Vectors add componentwise and scale by real numbers; a vector space is any set closed under these operations that satisfies the usual axioms [24]. Key ideas:

  • Inner product and norm. \(\mathbf x^{\mathsf T}\mathbf y\) \(= \sum x_iy_i\), \(\|\mathbf x\|\) \(= \sqrt{\mathbf x^{\mathsf T}\mathbf x}\). The angle between vectors satisfies \(\cos\theta\) \(= \mathbf x^{\mathsf T}\mathbf y/(\|\mathbf x\|\|\mathbf y\|)\); for centred data vectors this cosine is exactly the sample correlation [22].
  • Linear independence, span, basis, dimension. Vectors are linearly independent if no nontrivial combination is zero; a basis is an independent spanning set, and all bases of a space have the same size, its dimension [24].
  • Rank. The rank of \(\mathbf A\) is the dimension of its column space, which equals the dimension of its row space. For \(\mathbf A\in\mathbb{R}^{m\times n}\), \(\operatorname{rank}\mathbf A + \dim\operatorname{null}\mathbf A\) \(= n\) (rank–nullity) [22,24]. A regression design \(\mathbf X\) with linearly dependent columns (perfect collinearity) has no unique least-squares solution.
  • Special matrices. Identity \(\mathbf I\); diagonal; symmetric (\(\mathbf A = \mathbf A^{\mathsf T}\)); orthogonal (\(\mathbf Q^{\mathsf T}\mathbf Q\) \(= \mathbf I\), preserving lengths and angles); idempotent (\(\mathbf P^2 = \mathbf P\), a projection) [22].
  • Trace and determinant. \(\operatorname{tr}\mathbf A\) \(= \sum a_{ii}\), with \(\operatorname{tr}(\mathbf{AB})\) \(= \operatorname{tr}(\mathbf{BA})\). \(\det\mathbf A\) is the signed volume scaling factor of \(\mathbf x\mapsto\mathbf A\mathbf x\); \(\mathbf A\) is invertible iff \(\det\mathbf A\ne0\), and \(\det(\mathbf{AB})\) \(= \det\mathbf A\det\mathbf B\) [12,22].

A sample of \(n\) observations on \(p\) variables is stored as a data matrix \(\mathbf X\in\mathbb{R}^{n\times p}\), one row per observation. With the centring matrix \(\mathbf C\) \(= \mathbf I - \frac1n\mathbf 1\mathbf 1^{\mathsf T}\), the sample covariance matrix is \(\mathbf S\) \(= \frac{1}{n-1}\mathbf X^{\mathsf T}\mathbf C\mathbf X\) [23].

6.2Matrix multiplication

Definition 6.1 · Matrix product

For \(\mathbf A\in\mathbb{R}^{m\times k}\) and \(\mathbf B\in\mathbb{R}^{k\times n}\), \(\mathbf C\) \(= \mathbf{AB}\in\mathbb{R}^{m\times n}\) has entries \(c_{ij} = \sum_{p=1}^{k}a_{ip}b_{pj}\): row \(i\) of \(\mathbf A\) dotted with column \(j\) of \(\mathbf B\). The product represents composition of the linear maps, first \(\mathbf B\), then \(\mathbf A\) [22,24].

Multiplication is associative and distributive but not commutative; \((\mathbf{AB})^{\mathsf T}\) \(= \mathbf B^{\mathsf T}\mathbf A^{\mathsf T}\) and \((\mathbf{AB})^{-1}\) \(= \mathbf B^{-1}\mathbf A^{-1}\) [22]. Four views of the same product are useful: entries (dot products), columns (\(\mathbf{AB}\)'s columns are \(\mathbf A\) times columns of \(\mathbf B\)), rows, and a sum of rank-one outer products \(\mathbf{AB}\) \(= \sum_p \mathbf a_{:p}\mathbf b_{p:}\) [22]. The direct algorithm costs about \(2mkn\) floating-point operations [25].

Worked example 6.2 · Least squares and the hat matrix

The linear model is \(\mathbf y\) \(= \mathbf X\boldsymbol\beta + \boldsymbol\varepsilon\). Minimising \(\|\mathbf y - \mathbf X\boldsymbol\beta\|^2\) gives the normal equations \(\mathbf X^{\mathsf T}\mathbf X\hat{\boldsymbol\beta}\) \(= \mathbf X^{\mathsf T}\mathbf y\), so \(\hat{\boldsymbol\beta}\) \(= (\mathbf X^{\mathsf T}\mathbf X)^{-1}\mathbf X^{\mathsf T}\mathbf y\) when \(\mathbf X\) has full column rank. The fitted values are \(\hat{\mathbf y} = \mathbf H\mathbf y\) with \(\mathbf H\) \(= \mathbf X(\mathbf X^{\mathsf T}\mathbf X)^{-1}\mathbf X^{\mathsf T}\), the orthogonal projection onto the column space of \(\mathbf X\). \(\mathbf H\) is symmetric and idempotent, and \(\operatorname{tr}\mathbf H\) \(= \operatorname{tr}((\mathbf X^{\mathsf T}\mathbf X)^{-1}\mathbf X^{\mathsf T}\mathbf X)\) \(= p\), the number of parameters [23,26]. In practice one solves via a QR decomposition rather than forming \(\mathbf X^{\mathsf T}\mathbf X\), because forming it squares the condition number [25,27].

6.3Eigenvalues and eigenvectors

Definition 6.3 · Eigenpair

A nonzero \(\mathbf v\) is an eigenvector of a square matrix \(\mathbf A\), with eigenvalue \(\lambda\), if \(\mathbf A\mathbf v = \lambda\mathbf v\). The eigenvalues are the roots of the characteristic polynomial \(\det(\mathbf A - \lambda\mathbf I)\) \(= 0\). Always \(\operatorname{tr}\mathbf A\) \(= \sum\lambda_i\) and \(\det\mathbf A = \prod\lambda_i\), counting multiplicity [12,22].

Theorem 6.4 · Spectral theorem

A real symmetric matrix \(\mathbf A\) has real eigenvalues and an orthonormal basis of eigenvectors: \(\mathbf A\) \(= \mathbf Q\boldsymbol\Lambda\mathbf Q^{\mathsf T}\) with \(\mathbf Q\) orthogonal and \(\boldsymbol\Lambda\) diagonal [12,24].

Principal component analysis. Covariance matrices are symmetric and positive semidefinite, so by the spectral theorem \(\mathbf S\) \(= \mathbf Q\boldsymbol\Lambda\mathbf Q^{\mathsf T}\) with \(\lambda_i\ge0\). The first eigenvector maximises the variance \(\mathbf u^{\mathsf T}\mathbf S\mathbf u\) over unit vectors \(\mathbf u\) (the Rayleigh quotient), with maximum \(\lambda_1\); the \(k\)-th maximises it subject to orthogonality to the first \(k-1\). The proportion of total variance captured by the first \(k\) components is \(\sum_{i\le k}\lambda_i/\operatorname{tr}\mathbf S\) [12,26,28].

Computing eigenvalues. Eigenvalues of matrices larger than \(4\times4\) cannot in general be found by a finite formula, so all eigenvalue algorithms are iterative [27]. The simplest, power iteration, repeatedly multiplies by \(\mathbf A\) and normalises; it converges to the dominant eigenvector at a rate governed by \(|\lambda_2/\lambda_1|\) [25]. Library routines (LAPACK, exposed through numpy.linalg.eigh) use far more efficient QR-type methods [1,25].

6.4Matrix decompositions

A decomposition factors a matrix into pieces with simple structure. Each standard one has a characteristic statistical job [25,27]:

Existence and uniqueness conditions follow Golub and Van Loan [25] and Horn and Johnson [12].

The Cholesky factor is cheap, roughly \(n^3/3\) flops, half the cost of LU [25]. If \(\mathbf z\sim N(\mathbf 0,\mathbf I)\) then \(\mathbf x\) \(= \boldsymbol\mu + \mathbf L\mathbf z\) has covariance \(\mathbf L\mathbf I\mathbf L^{\mathsf T}\) \(= \boldsymbol\Sigma\), which is how multivariate normal samples are generated.

Theorem 6.5 · Eckart–Young

Let \(\mathbf A\) \(= \sum_{i}\sigma_i\mathbf u_i\mathbf v_i^{\mathsf T}\) be an SVD. The truncation \(\mathbf A_k\) \(= \sum_{i\le k}\sigma_i\mathbf u_i\mathbf v_i^{\mathsf T}\) is a best rank-\(k\) approximation in both the spectral and Frobenius norms, with \(\|\mathbf A - \mathbf A_k\|_2\) \(= \sigma_{k+1}\) and \(\|\mathbf A-\mathbf A_k\|_F\) \(= (\sum_{i\gt k}\sigma_i^2)^{1/2}\) [25,29].

For a centred data matrix, the right singular vectors are the principal component directions and \(\sigma_i^2/(n-1)\) are the eigenvalues of \(\mathbf S\); computing PCA by SVD avoids forming \(\mathbf X^{\mathsf T}\mathbf X\) [26,27].

6.5Quadratic forms

Definition 6.6 · Quadratic form and definiteness

A quadratic form is \(q(\mathbf x)\) \(= \mathbf x^{\mathsf T}\mathbf A\mathbf x\) \(= \sum_{i,j}a_{ij}x_ix_j\), where \(\mathbf A\) can be taken symmetric without loss of generality. A symmetric \(\mathbf A\) is positive definite (PD) if \(q(\mathbf x)\gt0\) for all \(\mathbf x\ne\mathbf 0\), and positive semidefinite (PSD) if \(q(\mathbf x)\ge0\). Equivalent PD tests: all eigenvalues are positive; all leading principal minors are positive (Sylvester's criterion); a Cholesky factorisation exists [12,22].

Every covariance matrix is PSD, because \(\mathbf a^{\mathsf T}\boldsymbol\Sigma\mathbf a\) \(= \operatorname{Var}(\mathbf a^{\mathsf T}\mathbf X)\ge0\) [23]. Writing \(\mathbf A\) \(= \mathbf Q\boldsymbol\Lambda\mathbf Q^{\mathsf T}\) and \(\mathbf y\) \(= \mathbf Q^{\mathsf T}\mathbf x\) gives \(q = \sum\lambda_iy_i^2\): in eigenvector coordinates a quadratic form is a weighted sum of squares, and the level sets are ellipsoids exactly when \(\mathbf A\) is PD.

Quadratic forms in statistics.

  • The squared Mahalanobis distance \(d^2\) \(= (\mathbf x-\boldsymbol\mu)^{\mathsf T}\boldsymbol\Sigma^{-1}(\mathbf x-\boldsymbol\mu)\) appears in the exponent of the \(N_p(\boldsymbol\mu,\boldsymbol\Sigma)\) density; if \(\mathbf x\sim N_p(\boldsymbol\mu,\boldsymbol\Sigma)\) then \(d^2\sim\chi^2_p\) [23].
  • For any random vector with mean \(\boldsymbol\mu\) and covariance \(\boldsymbol\Sigma\), \(E[\mathbf x^{\mathsf T}\mathbf A\mathbf x]\) \(= \operatorname{tr}(\mathbf A\boldsymbol\Sigma)+\boldsymbol\mu^{\mathsf T}\mathbf A\boldsymbol\mu\) [23]. With \(\mathbf A = \mathbf I - \mathbf H\) it shows that the residual sum of squares in regression has expectation \((n-p)\sigma^2\).
  • Sums of squares in ANOVA are quadratic forms \(\mathbf y^{\mathsf T}\mathbf A_i\mathbf y\) in idempotent matrices; Cochran's theorem gives conditions under which they are independent \(\chi^2\) variables [23,30].

7Optimisation

Maximum likelihood, least squares, penalised regression, M-estimation and the training of machine-learning models are all optimisation problems: minimise an objective \(f(\boldsymbol\theta)\), possibly subject to constraints [18,31].

7.1Convexity

Definition 7.1 · Convex set and convex function

A set \(C\) is convex if \(\theta\mathbf x+(1-\theta)\mathbf y\in C\) for all \(\mathbf x,\mathbf y\in C\) and \(\theta\in[0,1]\). A function \(f\) on a convex set is convex if \[f(\theta\mathbf x+(1-\theta)\mathbf y)\le\theta f(\mathbf x)+(1-\theta)f(\mathbf y),\] that is, the chord lies above the graph; strictly convex if the inequality is strict for \(\mathbf x\ne\mathbf y,\ 0\lt\theta\lt1\) [31].

For differentiable \(f\), convexity is equivalent to the first-order condition in Figure 8, and for twice-differentiable \(f\) to a positive semidefinite Hessian everywhere [31]. The property that makes convexity so valuable is this:

Theorem 7.2 · Local is global

For a convex function on a convex set, every local minimum is a global minimum; if \(f\) is differentiable, \(\nabla f(\mathbf x^*) = \mathbf 0\) is sufficient as well as necessary for an unconstrained global minimum. A strictly convex function has at most one minimiser [31,32].

Convex objectives in statistics include least squares, ridge and lasso penalties, and the negative log-likelihood of every generalised linear model with canonical link, such as logistic and Poisson regression [26,31]. Sums and nonnegative multiples of convex functions are convex, as are norms and compositions of convex functions with affine maps [31].

Theorem 7.3 · Jensen's inequality

If \(f\) is convex and \(X\) is a random variable with finite mean, then \(f(E[X])\le E[f(X)]\) [2,31].

Consequences: \(E[X^2]\ge(E[X])^2\), so variance is nonnegative; \(E[\log X]\le\log E[X]\); and the Kullback–Leibler divergence is nonnegative, which is the basis of the consistency argument for maximum likelihood [2].

7.2Constrained optimisation

The general problem is \[\min_{\mathbf x}\ f(\mathbf x)\quad\text{subject to}\quad g_i(\mathbf x)\le0\ (i = 1..m),\qquad h_j(\mathbf x)=0\ (j = 1..r).\] It is a convex program when \(f\) and the \(g_i\) are convex and the \(h_j\) are affine [31]. Statistical examples: probabilities must be nonnegative and sum to one; variance components must be nonnegative; the lasso can be written as least squares subject to \(\|\boldsymbol\beta\|_1\le t\) [26]; isotonic regression imposes \(\beta_1\le\beta_2\le\dots\).

Theorem 7.4 · Karush–Kuhn–Tucker (KKT) conditions

Let \(L(\mathbf x,\boldsymbol\mu,\boldsymbol\lambda)\) \(= f(\mathbf x)+\sum\mu_ig_i(\mathbf x)+\sum\lambda_jh_j(\mathbf x)\). If \(\mathbf x^*\) is a local minimum and a constraint qualification holds (for example, linear independence of the active constraint gradients), there exist multipliers with (i) stationarity \(\nabla_{\mathbf x}L = \mathbf 0\); (ii) primal feasibility; (iii) dual feasibility \(\mu_i\ge0\); (iv) complementary slackness \(\mu_ig_i(\mathbf x^*) = 0\). For a convex program the KKT conditions are also sufficient, and under Slater's condition (a strictly feasible point exists) they are necessary [18,31,33,34].

Complementary slackness says each inequality constraint is either active (\(g_i = 0\)) or has a zero multiplier. In the lasso, the KKT conditions explain exactly why some coefficients are set to zero [26].

7.3Lagrange multipliers

With only equality constraints the KKT conditions reduce to the method of Lagrange multipliers: at a constrained extremum of \(f\) subject to \(h(\mathbf x) = 0\) (with \(\nabla h\ne\mathbf 0\)), the gradients are parallel, \[\nabla f(\mathbf x^*)+\lambda\nabla h(\mathbf x^*) = \mathbf 0,\qquad h(\mathbf x^*) = 0 .\] Geometrically, moving along the constraint surface cannot change \(f\) to first order, so the level set of \(f\) is tangent to the constraint surface [17,32]. The multiplier measures sensitivity: if the constraint is changed to \(h(\mathbf x) = u\), the optimal value changes at rate \(-\lambda\) as \(u\) moves away from 0 [31].

Worked example 7.5 · Inverse-variance weighting

Independent unbiased estimators \(T_1,\dots,T_k\) of \(\theta\) have variances \(\sigma_i^2\). Any combination \(\sum w_iT_i\) with \(\sum w_i = 1\) is unbiased. Minimise \(\sum w_i^2\sigma_i^2\) subject to \(\sum w_i = 1\). With \(L\) \(= \sum w_i^2\sigma_i^2+\lambda(\sum w_i-1)\), stationarity gives \(2w_i\sigma_i^2+\lambda = 0\), so \(w_i\propto1/\sigma_i^2\): \[w_i^* = \frac{1/\sigma_i^2}{\sum_j1/\sigma_j^2},\qquad\operatorname{Var}\Bigl(\sum w_i^*T_i\Bigr) = \frac{1}{\sum_j1/\sigma_j^2}.\] This is the fixed-effect meta-analysis estimator [35], and the objective is strictly convex, so the solution is the unique global minimum [31]. The same Lagrangian argument with a constraint on total sample size yields Neyman allocation in stratified sampling [36].

7.4Gradient descent

When the stationarity equations have no closed form, as in logistic regression, we iterate. Gradient descent, proposed by Cauchy in 1847 [37], steps against the gradient: \[\mathbf x_{t+1} = \mathbf x_t-\eta_t\nabla f(\mathbf x_t).\]

Theorem 7.6 · Convergence of gradient descent

Suppose \(f\) is convex and differentiable with \(L\)-Lipschitz gradient (\(\|\nabla f(\mathbf x)-\nabla f(\mathbf y)\|\) \(\le L\|\mathbf x-\mathbf y\|\)). With fixed step \(\eta = 1/L\), \(f(\mathbf x_t)-f^*\le\frac{L\|\mathbf x_0-\mathbf x^*\|^2}{2t}\), a sublinear \(O(1/t)\) rate. If \(f\) is also \(m\)-strongly convex, the error decreases geometrically, by a factor of at most \(1-m/L\) per step; the ratio \(\kappa = L/m\) is the condition number [18,31,38].

Practical points:

  • Step size. On a quadratic with Hessian eigenvalues in \([m,L]\), a fixed step converges iff \(0\lt\eta\lt2/L\) [18]. Line searches that satisfy the Armijo or Wolfe conditions pick \(\eta_t\) adaptively [18].
  • Newton's method uses curvature: \(\mathbf x_{t+1}\) \(= \mathbf x_t-[\nabla^2f(\mathbf x_t)]^{-1}\nabla f(\mathbf x_t)\), converging quadratically near a minimum with positive definite Hessian [18]. For GLMs Newton's method with the expected Hessian is Fisher scoring, also known as iteratively reweighted least squares [26].
  • Stochastic gradient descent replaces \(\nabla f\) with an unbiased estimate from a random mini-batch. It descends from the stochastic approximation method of Robbins and Monro, which converges under step sizes with \(\sum\eta_t = \infty\) and \(\sum\eta_t^2\lt\infty\) [38,39]. Adaptive variants such as Adam rescale each coordinate by running moment estimates [40].

8Combinatorics

When outcomes are equally likely, \(P(A) = |A|/|\Omega|\), and probability becomes counting [41]. Combinatorics also supplies the exact null distributions of permutation and rank tests.

Theorem 8.1 · Basic counting rules

Multiplication principle: a procedure of \(k\) stages with \(n_1,\dots,n_k\) choices has \(n_1n_2\cdots n_k\) outcomes. Permutations: the number of ordered arrangements of \(k\) of \(n\) distinct objects is \(n^{\underline k} = n!/(n-k)!\). Combinations: the number of \(k\)-element subsets of an \(n\)-set is \(\binom nk = \frac{n!}{k!\,(n-k)!}\). Multisets ("stars and bars"): the number of ways to choose \(k\) items from \(n\) types with repetition is \(\binom{n+k-1}{k}\). Multinomial: the number of ways to split \(n\) objects into labelled groups of sizes \(k_1,\dots,k_r\) is \(\frac{n!}{k_1!\cdots k_r!}\) [41,42].

Binomial theorem. \((x+y)^n\) \(= \sum_{k=0}^n\binom nkx^ky^{n-k}\) [10]. With \(x = p,\ y = 1-p\) it proves that the binomial probabilities \(\binom nkp^k(1-p)^{n-k}\) sum to 1; with \(x = y = 1\) it gives \(\sum_k\binom nk = 2^n\), the size of the power set. Pascal's rule \(\binom nk\) \(= \binom{n-1}{k-1}+\binom{n-1}{k}\) generates the triangle in Figure 11, and Vandermonde's identity \(\sum_j\binom mj\binom n{k-j}\) \(= \binom{m+n}k\) normalises the hypergeometric distribution [10].

Inclusion–exclusion. For finite sets [42], \[|A_1\cup\dots\cup A_n| = \sum_i|A_i|-\sum_{i\lt j}|A_i\cap A_j|+\dots+(-1)^{n+1}|A_1\cap\dots\cap A_n| .\] It solves the matching problem: the probability that a random permutation of \(n\) items has no fixed point tends to \(1/e\) [41].

Stirling's formula. \(n!\sim\sqrt{2\pi n}\,(n/e)^n\), meaning the ratio tends to 1 [16,41]. It gives the normal approximation to the binomial and the asymptotics of the multinomial likelihood.

Worked example 8.2 · Exact permutation test

Two groups of 10 units each. Under the null hypothesis that treatment has no effect, all \(\binom{20}{10} = 184\,756\) assignments of the observed responses to "treatment" are equally likely. The exact \(p\)-value is the fraction of those assignments whose difference in means is at least as extreme as the one observed. This is Fisher's randomisation argument, and it is exact because of counting alone, without any distributional assumption [43].

9Real analysis

Real analysis supplies the rigorous version of calculus. Statistics needs it whenever an argument involves infinitely many steps: limits of estimators, interchange of limit and integral, existence of maxima, and convergence of functions such as empirical CDFs [9,13].

Completeness of the real numbers

Axiom 9.1 · Least-upper-bound property

Every nonempty subset of \(\mathbb R\) that is bounded above has a least upper bound, its supremum \(\sup S\). This property distinguishes \(\mathbb R\) from \(\mathbb Q\): the set \(\{q\in\mathbb Q:q^2\lt2\}\) has no supremum in \(\mathbb Q\) [9,45].

From completeness follow the results calculus relies on [9,13]:

  • Cauchy criterion. A real sequence converges iff it is Cauchy: \(\forall\varepsilon\gt0\ \exists N:\ m,n\gt N\) \(\Rightarrow|a_m-a_n|\lt\varepsilon\).
  • Bolzano–Weierstrass. Every bounded sequence in \(\mathbb R^p\) has a convergent subsequence.
  • Extreme value theorem. A continuous function on a closed, bounded (compact) set attains its maximum and minimum. It guarantees that a continuous likelihood on a compact parameter space has an MLE.
  • Intermediate value theorem. A continuous function on \([a,b]\) takes every value between \(f(a)\) and \(f(b)\). It guarantees that a continuous, strictly increasing CDF has a unique quantile for every \(p\in(0,1)\), and it is the reason bisection works (Section 11).

A set \(K\subseteq\mathbb R^p\) is compact iff it is closed and bounded (Heine–Borel theorem); continuous images of compact sets are compact [9].

Sequences of functions

Definition 9.2 · Pointwise and uniform convergence

\(f_n\to f\) pointwise on \(D\) if \(f_n(x)\to f(x)\) for each \(x\in D\). \(f_n\to f\) uniformly if \(\sup_{x\in D}|f_n(x)-f(x)|\to0\): one \(N\) works for every \(x\) at once [9,13].

Theorem 9.3 · Uniform limits

A uniform limit of continuous functions is continuous. If \(f_n\to f\) uniformly on \([a,b]\) and each \(f_n\) is Riemann integrable, then \(\int_a^bf_n\to\int_a^bf\) [9].

Uniform convergence is the right notion in empirical-process theory: the Glivenko–Cantelli theorem states that the empirical CDF converges to the true CDF uniformly, \(\sup_t|\hat F_n(t)-F(t)|\to0\) almost surely [7,46]. The Kolmogorov–Smirnov statistic is exactly this supremum.

Interchanging limits. Differentiating under the integral sign, \(\frac{d}{d\theta}\int f(x,\theta)dx\) \(= \int\frac{\partial f}{\partial\theta}dx\), is used to prove that the score has mean zero and to derive the Cramér–Rao bound [2]. It is valid under domination conditions, which are cleanest in the Lebesgue theory of Section 10 [8].

Exercises 9

  1. Find \(\sup\) and \(\inf\) of \(S = \{1-1/n:n\in\mathbb N,\ n\ge1\}\). Are they attained?

    Solution

    \(\inf S = 0\), attained at \(n = 1\). \(\sup S = 1\): every element is below 1, and for any \(b\lt1\) some \(1-1/n\gt b\). It is not attained, which is why "supremum" rather than "maximum" is needed.

  2. Does \(g_n(x) = \frac{x}{1+nx^2}\) converge uniformly on \(\mathbb R\)?

    Solution

    Pointwise \(g_n\to0\). For \(x\gt0\), \(1+nx^2\ge2\sqrt n\,|x|\) by AM–GM, with equality at \(x = 1/\sqrt n\), so \(\sup_x|g_n(x)|\) \(= \frac{1}{2\sqrt n}\to0\). Yes, the convergence is uniform.

  3. Let \(\ell(\theta)\) be continuous on \(\Theta = [0,1]\). Explain why an MLE exists. Give an example on \(\Theta = (0,1)\) where it does not.

    Solution

    \([0,1]\) is compact, so by the extreme value theorem \(\ell\) attains its maximum. On \((0,1)\), take one Bernoulli observation \(x = 1\): \(\ell(p) = \log p\) increases towards \(p = 1\) but never attains its supremum on the open interval.

10Measure theory

Since Kolmogorov's 1933 monograph, probability has been formally defined as a measure of total mass one [47]. Measure theory unifies discrete and continuous distributions, justifies the limit theorems, and makes conditional expectation precise [7,46].

Why it is needed

One cannot consistently assign a "length" to every subset of \(\mathbb R\): Vitali constructed a subset of \([0,1]\) for which no translation-invariant, countably additive length exists [8,48]. The resolution is to define measures only on a well-behaved collection of sets, a \(\sigma\)-algebra.

Definition 10.1 · σ-algebra, measure, probability space

A \(\sigma\)-algebra \(\mathcal F\) on \(\Omega\) is a collection of subsets that contains \(\Omega\) and is closed under complements and countable unions. A measure is a function \(\mu:\mathcal F\to[0,\infty]\) with \(\mu(\varnothing) = 0\) and countable additivity: \(\mu(\bigcup_iA_i) = \sum_i\mu(A_i)\) for pairwise disjoint \(A_i\in\mathcal F\). A probability space \((\Omega,\mathcal F,P)\) is a measure space with \(P(\Omega) = 1\) [7,8].

The Borel \(\sigma\)-algebra \(\mathcal B(\mathbb R)\) is the smallest \(\sigma\)-algebra containing all open intervals; Lebesgue measure \(\lambda\) is the unique measure on it with \(\lambda((a,b]) = b-a\) [8]. Sets of measure zero are null sets; a property holding outside a null set holds almost everywhere (almost surely, in probability). Every countable set is Lebesgue-null, and so is the uncountable Cantor set, whose remaining length after \(k\) middle-third removals is \((2/3)^k\to0\) [8,13].

A random variable is a measurable function \(X:(\Omega,\mathcal F)\to(\mathbb R,\mathcal B)\), meaning \(X^{-1}(B)\in\mathcal F\) for every Borel \(B\). This is the preimage condition of Section 1, now required so that \(P(X\in B)\) is defined. The distribution of \(X\) is the push-forward measure \(P_X(B) = P(X^{-1}(B))\) [7,46].

The Lebesgue integral

Lebesgue's 1902 thesis [49] built the integral by partitioning the range of \(f\) instead of its domain. For a nonnegative simple function \(\varphi = \sum_ja_j\mathbb 1_{A_j}\), \(\int\varphi\,d\mu = \sum_ja_j\mu(A_j)\). For measurable \(f\ge0\), \(\int f\,d\mu\) \(= \sup\{\int\varphi\,d\mu:0\le\varphi\le f,\ \varphi\text{ simple}\}\), and in general \(\int f = \int f^+-\int f^-\) when at least one part is finite [7,8].

The expectation is a Lebesgue integral, \(E[X] = \int_\Omega X\,dP\). One definition covers discrete, continuous and mixed distributions: with counting measure it is a sum, and with Lebesgue measure it is \(\int x f(x)\,dx\) [7]. The Radon–Nikodym theorem makes "density" precise: if \(P_X\) is absolutely continuous with respect to a \(\sigma\)-finite measure \(\nu\) (\(\nu(A) = 0\Rightarrow P_X(A) = 0\)), there is a density \(f = dP_X/d\nu\) with \(P_X(A) = \int_Af\,d\nu\) [7,8]. A probability mass function is a density with respect to counting measure, which is why likelihood theory treats discrete and continuous models with the same formulas.

Theorem 10.2 · Convergence theorems

Monotone convergence. If \(0\le f_n\uparrow f\) a.e., then \(\int f_n\,d\mu\uparrow\int f\,d\mu\). Fatou's lemma. For \(f_n\ge0\), \(\int\liminf f_n\le\liminf\int f_n\). Dominated convergence. If \(f_n\to f\) a.e. and \(|f_n|\le g\) with \(\int g\lt\infty\), then \(\int f_n\to\int f\) [7,8,46].

Dominated convergence is the workhorse of mathematical statistics: it justifies differentiating under the integral sign, passing limits through expectations, and many steps in the asymptotics of maximum likelihood [2,46]. Applied to \(f(x)\mathbb 1\{x\le t\}\) it shows that every CDF is right-continuous.

Modes of convergence. For random variables: almost surely (\(P(X_n\to X) = 1\)) implies in probability (\(P(|X_n-X|\gt\varepsilon)\to0\) for every \(\varepsilon\)), which implies in distribution (\(F_{X_n}(t)\to F_X(t)\) at continuity points of \(F_X\)); convergence in \(L^p\) (\(E|X_n-X|^p\to0\)) also implies convergence in probability. The converses fail in general [7,46]. The strong law of large numbers is an almost-sure statement; the central limit theorem is a statement about convergence in distribution [46].

Exercises 10

  1. Show that a \(\sigma\)-algebra is closed under countable intersections.

    Solution

    If \(A_i\in\mathcal F\), then \(A_i^c\in\mathcal F\), so \(\bigcup A_i^c\in\mathcal F\), and by De Morgan \(\bigcap A_i\) \(= (\bigcup A_i^c)^c\in\mathcal F\).

  2. Let \(X\sim\text{Uniform}(0,1)\) and \(f_n = n\,\mathbb 1_{(0,1/n)}\). Find \(\lim f_n(X)\) and \(\lim E[f_n(X)]\). Why does dominated convergence not apply?

    Solution

    For each fixed \(x\in(0,1)\), \(f_n(x) = 0\) once \(n\gt1/x\), so \(f_n(X)\to0\) almost surely and \(E[\lim f_n(X)] = 0\). But \(E[f_n(X)] = n\cdot\frac1n = 1\) for every \(n\). No integrable \(g\) dominates all the \(f_n\): \(\sup_nf_n(x)\) is of order \(1/x\), which is not integrable on \((0,1)\). Fatou's inequality \(0\le1\) holds strictly.

  3. A random variable has \(P(X = 0) = 0.3\) and, on \((0,\infty)\), density \(0.7e^{-x}\). Write \(E[X]\) as a single Lebesgue integral and evaluate it.

    Solution

    With respect to \(\nu = \delta_0+\lambda\) the density is \(f(0) = 0.3\), \(f(x) = 0.7e^{-x}\) for \(x\gt0\). \(E[X]\) \(= \int x\,f\,d\nu\) \(= 0\cdot0.3+\int_0^\infty x\,0.7e^{-x}dx\) \(= 0.7\). Zero-inflated models have exactly this structure.

11Numerical methods

Statistical software turns formulas into floating-point arithmetic. Formulas that are equal in exact arithmetic can give very different answers on a computer, so a statistician needs to know where accuracy is lost [50,51].

Floating-point arithmetic

Nearly all hardware implements the IEEE 754 standard. In binary64 ("double precision") a number has a sign, an 11-bit exponent and a 52-bit fraction; the unit roundoff is \(u = 2^{-53}\approx1.1\times10^{-16}\) and machine epsilon is \(2^{-52}\approx2.2\times10^{-16}\). The largest finite value is about \(1.8\times10^{308}\) and the smallest normalised positive one about \(2.2\times10^{-308}\) [50,52]. Each basic operation is correctly rounded: \(\operatorname{fl}(x\circ y)\) \(= (x\circ y)(1+\delta)\) with \(|\delta|\le u\) [50]. Decimal fractions such as 0.1 have no finite binary expansion, so 0.1 + 0.2 == 0.3 is false [51].

Three failure modes recur in statistical computing:

  • Catastrophic cancellation. Subtracting nearly equal numbers leaves only their rounding errors. The one-pass variance formula \(\sum x_i^2-n\bar x^2\) fails badly when the mean is large relative to the spread; the two-pass formula, or Welford's updating algorithm, is accurate [50,53].
  • Overflow and underflow. Likelihoods of large samples underflow to 0, and \(e^{1000}\) overflows. Work on the log scale and use the log-sum-exp identity \(\log\sum e^{a_i}\) \(= m+\log\sum e^{a_i-m}\) with \(m = \max a_i\) [50].
  • Ill-conditioning. The condition number \(\kappa(\mathbf A)\) \(= \|\mathbf A\|\|\mathbf A^{-1}\|\) bounds how much relative input error is amplified when solving \(\mathbf A\mathbf x = \mathbf b\); one can expect to lose about \(\log_{10}\kappa\) significant digits. Since \(\kappa_2(\mathbf X^{\mathsf T}\mathbf X)\) \(= \kappa_2(\mathbf X)^2\), the normal equations lose twice as many digits as QR [25,27].

Numerical differentiation

The forward difference \((f(x+h)-f(x))/h\) has truncation error \(O(h)\); the central difference \((f(x+h)-f(x-h))/(2h)\) has \(O(h^2)\). Rounding error grows like \(u/h\), so there is an optimal step: roughly \(h\approx\sqrt u\approx10^{-8}\) for forward and \(h\approx u^{1/3}\approx10^{-5}\) for central differences [18,50].

Root finding

Quantiles, MLEs and score equations are roots of \(g(x) = 0\).

  • Bisection needs only continuity and a sign change (intermediate value theorem). It halves the bracket each step, so reaching width \(\epsilon\) from width \(w\) takes \(\lceil\log_2(w/\epsilon)\rceil\) steps; it is slow but always converges [54].
  • Newton–Raphson iterates \(x_{k+1} = x_k-g(x_k)/g'(x_k)\). Near a simple root with \(g''\) continuous it converges quadratically, roughly doubling the number of correct digits per step, but it can diverge from a poor start [18,54]. Applied to the score, it is Newton's method for the MLE (Section 7.4).

Numerical integration

Composite rules on \(n\) subintervals of width \(h\) have error \(O(h^2)\) for the trapezoid rule and \(O(h^4)\) for Simpson's rule when \(f\) is smooth [54]. Gaussian quadrature with \(n\) nodes integrates polynomials of degree up to \(2n-1\) exactly; Gauss–Hermite quadrature is used for integrals against a normal density, as in generalised linear mixed models [16,54]. In high dimensions deterministic rules become impractical, and Monte Carlo integration, \(\int g\,dP\approx\frac1n\sum g(X_i)\), takes over: by the CLT its error is \(O_p(n^{-1/2})\) whatever the dimension [46].

Numerical linear algebra in practice

Do not form an inverse explicitly to solve a system: use a factorisation (solve, cholesky, lstsq). Exploit structure: SPD matrices use Cholesky, least squares uses QR or SVD [25,27]. NumPy delegates these operations to the LAPACK and BLAS libraries [1]; SciPy adds optimisation, quadrature and special functions on top [55].

Exercises 11

  1. Explain why computing \(\log(1+x)\) as log(1 + x) is inaccurate for \(|x|\approx10^{-12}\), and name the fix.

    Solution

    Forming \(1+x\) rounds away all but about 4 significant digits of \(x\) (since \(u\approx10^{-16}\)), and the logarithm cannot recover them. Use log1p(x), which computes \(\log(1+x)\) accurately for small \(x\) [50]. The same applies to expm1 for \(e^x-1\).

  2. How many bisection steps are needed to locate a quantile in \([0, 5]\) to within \(10^{-12}\)?

    Solution

    \(\lceil\log_2(5/10^{-12})\rceil\) \(= \lceil\log_2(5\times10^{12})\rceil\) \(= \lceil42.19\rceil\) \(= 43\), which matches the listing's output.

  3. Write Newton's method for the MLE of a Poisson mean. Does it reach \(\bar x\) in one step from any start \(\mu_0\gt0\)?

    Solution

    Score \(s(\mu) = \sum x_i/\mu-n\), derivative \(s'(\mu) = -\sum x_i/\mu^2\). Writing \(S = \sum x_i\): \(\mu_1\) \(= \mu_0+\frac{S/\mu_0-n}{S/\mu_0^2}\) \(= 2\mu_0-n\mu_0^2/S\). This is not \(\bar x\) after one step. With \(r = \mu/\bar x\), the iteration is \(r_1 = 2r_0-r_0^2 = 1-(1-r_0)^2\), so the error \(1-r\) is squared each step (quadratic convergence), and it converges iff \(0\lt r_0\lt2\). Starting above \(2\bar x\) gives a negative iterate. Newton is fast but needs a sensible start.
