1. Why visualize, and how graphs are read

Summary statistics compress a data set into a few numbers, and that compression can hide almost everything that matters. Anscombe made the point in 1973 with four small data sets that share the same means, variances, correlation and least-squares line, yet look nothing alike when plotted [1]. The quartet is reproduced in Section 18; the lesson is that a graph should come before, not after, the summary. Tukey built a whole approach to data analysis, exploratory data analysis, on this idea, and several of the displays below (the stem-and-leaf plot and the box plot among them) were invented or popularised in his 1977 book [2].

A graph works only if the reader can decode it accurately. Cleveland and McGill ran experiments in which people judged the ratio of two values shown with different visual encodings. They ranked the elementary perceptual tasks from most to least accurate: position along a common scale; position along identical but non-aligned scales; length, direction and angle; area; volume and curvature; shading and colour saturation [3]. A crowdsourced replication on Amazon Mechanical Turk reproduced the main ordering [4].

The ranking explains most of the advice in this article. Dot plots and scatter plots use position, so they are read accurately. Bar charts use position (of the bar end) and length, which is why their axis must start at zero. Pie charts use angle and area, which is why they are hard to compare. Heatmaps use colour, the least accurate channel, so they suit patterns rather than exact values. Cleveland's books The Elements of Graphing Data [5] and Visualizing Data [6], Tufte's The Visual Display of Quantitative Information [7] and Wilke's Fundamentals of Data Visualization [8] develop these principles at length.

3. Bar charts

A bar chart shows one numeric value for each of several categories, encoding the value as the length of a bar that starts at a common baseline. William Playfair published bar charts in his Commercial and Political Atlas of 1786 [21,22]. Because the reader compares bar lengths, the value axis must include zero; a bar that starts at 75 makes 80 look like a fifth of 95 (see Section 18) [7,5].

Good practice for bar charts:

  • Sort the bars by value unless the categories have a natural order (months, age groups). Sorting turns a lookup task into a ranking the eye reads at once [5].
  • Use horizontal bars when the labels are long, so the names read left to right without rotation.
  • Show counts and totals with bars, not summaries of distributions. A bar for a group mean hides the spread, the sample size and any outliers. Weissgerber and colleagues found bar graphs of continuous data in most of the physiology papers they reviewed, showed that very different distributions can produce identical bar graphs, and recommend dot plots, box plots or showing the raw points instead [23].
  • Grouped vs stacked. Grouped bars compare subgroups on a common baseline. Stacked bars show totals well, but every segment above the first sits on a moving baseline, so it is read by length on non-aligned scales, a less accurate task [3].

4. Histograms

A histogram estimates the shape of a distribution of one continuous variable. The range is cut into adjacent intervals (bins), and over each bin a bar is drawn whose area is proportional to the number of observations in it. Karl Pearson introduced the term in 1895 [24]. With equal-width bins the heights are proportional to counts; to compare histograms with different bin widths or sample sizes, use the density scale, on which the total area is 1:

Histogram densityf̂(x) = nkn · h   for x in bin k,   where nk = count in bin k, h = bin width

The bin width h controls everything. Too narrow and the histogram shows sampling noise; too wide and it hides real features. Three classical rules give a starting point:

RuleFormulaAssumption / property
Sturges (1926) [25]k = ⌈log₂ n⌉ + 1 binsDerived from a binomial (approximately normal) shape; too few bins for large n.
Scott (1979) [26]h = 3.49 s n−1/3Minimises the asymptotic integrated mean squared error for normal data.
Freedman–Diaconis (1981) [27]h = 2 · IQR · n−1/3Same n−1/3 rate, but uses the IQR, so it is robust to outliers and heavy tails.

For the 100 Nile flows the formulas give Scott h = 127.2 and Freedman–Diaconis h = 100.8. NumPy rounds each to a whole number of equal bins across the observed range of 914, so its 'scott' option uses 8 bins of width 114.2 and its 'fd' option uses 10 bins of width 91.4 [17].

import numpy as np
import statsmodels.api as sm

flow = sm.datasets.nile.load_pandas().data["volume"].to_numpy()   # 10^8 m^3/yr
n = flow.size
iqr = np.subtract(*np.percentile(flow, [75, 25]))
print(f"n = {n}, sd = {flow.std(ddof=1):.1f}, IQR = {iqr:.1f}")

    edges = np.histogram_bin_edges(flow, bins=rule)

          f"  tallest bin = {counts.max()}")

5. Stem-and-leaf plots

Tukey's stem-and-leaf plot is a histogram made of digits [2]. Each value is split into a stem (the leading digits) and a leaf (the next digit). Stems are written once in a column; each observation adds its leaf to its stem's row. The row lengths form a sideways histogram, yet the data can still be read back to the leaf's precision, and medians and quartiles can be found by counting. It suits samples of roughly 15 to 150 values and is easy to draw by hand.

A back-to-back stem-and-leaf plot puts two groups on either side of a shared column of stems. Cobb studied the Nile series as a change-point problem and found that the mean flow drops after 1898 [12]. The plot below splits the series at that point; the leaves on the left are written in reverse so that both sides grow outwards from the stems.

import numpy as np
import statsmodels.api as sm

nile = sm.datasets.nile.load_pandas().data
before = nile.loc[nile.year < 1899, "volume"].to_numpy()   # 1871-1898
after = nile.loc[nile.year >= 1899, "volume"].to_numpy()   # 1899-1970

def stems(x, unit=100):
    """Map each stem (hundreds) to a sorted string of leaves (tens digit)."""
    x = np.sort(np.floor(x / 10).astype(int))               # truncate to tens
    out = {}
    for v in x:
        out.setdefault(v // 10, []).append(str(v % 10))
    return out

def back_to_back(a, b):
    sa, sb = stems(a), stems(b)
    lo, hi = min(sa | sb), max(sa | sb)
    width = max(len(v) for v in sa.values())
    for s in range(lo, hi + 1):
        left = "".join(reversed(sa.get(s, [])))
        print(f"{left:>{width}} | {s:2d} | {''.join(sb.get(s, []))}")

6. Dot plots

"Dot plot" names two different displays.

The Wilkinson dot plot shows the distribution of one small sample. Each observation is a dot; dots with equal (or nearly equal) values stack vertically, so the stacks form a histogram in which every observation stays visible [29]. It is the best single display for samples of about 10 to 50 values.

The Cleveland dot plot (dot chart) replaces the bars of a bar chart with dots on light horizontal guide lines, one row per category [30]. Because it uses position rather than length, the axis need not start at zero. That makes it the right choice when values are far from zero, or when a log scale is needed. Rows should be sorted by value.

import numpy as np

7. Box plots

The box plot (box-and-whisker plot) summarises a distribution with five numbers and flags unusual values. It was introduced by Tukey [2] and refined by McGill, Tukey and Larsen [31]. Its parts are:

  • a box from the first quartile Q1 to the third quartile Q3, so its length is the interquartile range IQR = Q3 − Q1;
  • a line at the median;
  • whiskers from the box to the most extreme observations that lie within the inner fences Q1 − 1.5·IQR and Q3 + 1.5·IQR;
  • every point beyond the fences drawn individually as a possible outlier.

For normal data the quartiles sit at ±0.674σ, so the fences sit at ±2.698σ and about 0.7% of observations fall outside them by chance alone. A flagged point is a reason to look, not proof of an error [32]. Quartiles can be computed in several ways; Hyndman and Fan list nine definitions used by statistical software [33]. NumPy's default is their type 7 (linear interpolation). Different software can therefore draw slightly different boxes from the same data, especially for small samples.

Notches. McGill and colleagues proposed notching the box at median ± 1.58·IQR/√n. If the notches of two boxes do not overlap, that is "strong evidence" (roughly 95% confidence) that the medians differ [31]. They also suggested making box width proportional to √n when groups differ in size.

import numpy as np
import pandas as pd
from sklearn.datasets import load_iris

iris = load_iris(as_frame=True)
df = iris.frame.assign(species=iris.target_names[iris.target])
df.columns = ["sepal_length", "sepal_width", "petal_length",
              "petal_width", "target", "species"]

for sp, g in df.groupby("species"):
    x = g["sepal_width"].to_numpy()
    q1, med, q3 = np.percentile(x, [25, 50, 75])    # numpy default = type 7
    iqr = q3 - q1
    lo_f, hi_f = q1 - 1.5 * iqr, q3 + 1.5 * iqr     # Tukey's inner fences
    inside = x[(x >= lo_f) & (x <= hi_f)]
    out = np.sort(x[(x < lo_f) | (x > hi_f)])
    notch = 1.58 * iqr / np.sqrt(x.size)             # McGill et al. notch
    print(f"{sp:10s} Q1={q1:.3f} med={med:.2f} Q3={q3:.3f} "
          f"whiskers=[{inside.min():.1f}, {inside.max():.1f}] "
          f"outliers={out.tolist()} notch=±{notch:.3f}")

8. Violin plots

A box plot cannot show the shape of a distribution: a bimodal sample and a flat one can have identical boxes. Hintze and Nelson's violin plot combines a box plot with a kernel density estimate mirrored on both sides of the axis [34]. The width of the violin at each height is proportional to the estimated density there, and a miniature box plot (here a thick bar for the IQR and a dot for the median) is drawn inside.

Violins inherit the strengths and weaknesses of density estimates (next section). They depend on a bandwidth, they extend smoothly past the data unless trimmed (the ones above are cut at the smallest and largest observations), and they can suggest smoothness in small samples that do not support it. For fewer than about 30 points per group, show the points themselves, for example with a dot plot or a box plot with jittered points.

9. Density plots

A kernel density estimate (KDE) is a smooth alternative to the histogram, introduced by Rosenblatt [35] and Parzen [36]. Each observation contributes a small bump, the kernel K, of width h; the estimate is the average of the bumps:

Kernel density estimatorf̂h(x) = 1n h ∑i=1n K(x − xih),   with the Gaussian kernel K(u) = (2π)−1/2 e−u²/2

The choice of kernel matters little; the bandwidth h matters a great deal [28]. Silverman's rule of thumb is a widely used default:

Silverman's rule of thumbh = 0.9 · min(s, IQR/1.34) · n−1/5

Like the histogram rules, it is tuned for roughly normal data and tends to over-smooth multimodal data [28]. The figure shows what happens at half and double the rule's value for the bimodal petal-length data.

import numpy as np
from scipy import stats
from sklearn.datasets import load_iris

petal = load_iris().data[:, 2]                       # petal length, cm
n, s = petal.size, petal.std(ddof=1)
iqr = np.subtract(*np.percentile(petal, [75, 25]))
h_silverman = 0.9 * min(s, iqr / 1.34) * n ** (-1/5)
h_scott = 1.06 * s * n ** (-1/5)
print(f"Silverman h = {h_silverman:.3f} cm, normal-reference h = {h_scott:.3f} cm")

grid = np.linspace(0, 8, 801)
for label, h in [("0.5 x Silverman", h_silverman / 2),
                 ("Silverman", h_silverman),
                 ("2 x Silverman", h_silverman * 2)]:
    kde = stats.gaussian_kde(petal, bw_method=h / s)  # scipy scales by sd
    f = kde(grid)
    peaks = grid[1:-1][(f[1:-1] > f[:-2]) & (f[1:-1] > f[2:])]
    print(f"{label:16s} modes at {np.round(peaks, 2).tolist()}  "
          f"area = {np.trapezoid(f, grid):.3f}")

Two practical notes. First, scipy.stats.gaussian_kde takes a bandwidth factor that it multiplies by the sample standard deviation, so an absolute h has to be divided by s, as in the listing [18]. Second, a KDE leaks probability outside the data. The 2 × Silverman curve puts 4.6% of its mass outside the plotted 0–8 cm range, and some of that lies below zero, where petal lengths cannot be. For bounded variables, consider a boundary correction, a transformation, or simply showing the histogram.

10. Scatter plots

A scatter plot shows the relationship between two numeric variables by placing one point per observation at (x, y). Both values are encoded by position on a common scale, the most accurate channel [3]. Scatter plots reveal the form of a relationship (linear, curved, clustered), its strength, and any outliers, none of which a correlation coefficient can show by itself [1].

import numpy as np
from sklearn.datasets import load_iris

iris = load_iris()
pl, pw = iris.data[:, 2], iris.data[:, 3]
pairs = set(zip(pl, pw))
print(f"{pl.size} flowers but only {len(pairs)} distinct (length, width) points")

print(f"overall r = {np.corrcoef(pl, pw)[0, 1]:.3f}")
for k, name in enumerate(iris.target_names):
    m = iris.target == k
    print(f"{name:10s} r = {np.corrcoef(pl[m], pw[m])[0, 1]:.3f}")

rng = np.random.default_rng(1)
jx = pl + rng.uniform(-0.04, 0.04, pl.size)
jy = pw + rng.uniform(-0.04, 0.04, pw.size)

The output contains a warning about pooled correlations. Across all flowers r = 0.963, but within setosa and virginica it is only about 0.33. The strong overall correlation comes mostly from the differences between species. Colouring points by group is the simplest guard against this kind of misreading.

Overplotting is the main practical problem. Remedies, roughly in order of data size [5,8]:

  • Jitter: add a little random noise, much smaller than the measurement resolution, to separate tied points (as above).
  • Transparency: draw points partly transparent so that dense regions look darker.
  • Smaller or hollow markers.
  • 2-D binning (hexagonal or rectangular bins coloured by count) or 2-D density contours for thousands of points or more.

Add a smoother (such as a LOESS curve) or a fitted line when the trend is the message, and use a log scale when a variable spans several orders of magnitude [6].

11. Line charts

A line chart connects observations ordered by an interval-scaled variable, almost always time. The line asserts that values between the observations can be interpolated, so it is appropriate for continuous processes measured at regular intervals and wrong for unordered categories, which need bars or dots [5,8]. Playfair's 1786 atlas also contains the first published time-series line charts [21,22].

import numpy as np
import statsmodels.api as sm

co2 = sm.datasets.co2.load_pandas().data["co2"]          # weekly, ppm
monthly = co2.resample("MS").mean().interpolate()         # fill 59 gaps
annual = monthly.groupby(monthly.index.year).mean()
print("first/last months:", monthly.index[0].date(), monthly.index[-1].date())
print(f"1959 mean = {annual[1959]:.2f} ppm, 2001 mean = {annual[2001]:.2f} ppm")
growth = annual.diff()
print(f"mean growth 1960s = {growth.loc[1960:1969].mean():.2f} ppm/yr, "
      f"1990s = {growth.loc[1990:1999].mean():.2f} ppm/yr")

# Seasonal cycle: monthly deviation from a 12-month centred moving average
trend = monthly.rolling(12, center=True).mean()
cycle = (monthly - trend).groupby(monthly.index.month).mean()
print("seasonal peak month:", cycle.idxmax(), " trough month:", cycle.idxmin(),
      f" peak-to-trough = {cycle.max() - cycle.min():.2f} ppm")

The figure carries two messages that one series alone would mix together: a rise from 316.0 ppm (1959 mean) to 370.85 ppm (2001 mean), with the growth rate itself increasing from 0.86 to 1.54 ppm per year; and a seasonal cycle that peaks in May and bottoms out in October, with a peak-to-trough range of about 6 ppm. Decomposing a series into trend and seasonal parts and plotting them separately is a standard technique [6].

Aspect ratio. The slopes we perceive in a line chart depend on its width-to-height ratio. Cleveland, McGill and McGill showed that slopes are judged most accurately when the important line segments are oriented near ±45°, and proposed "banking to 45°" to choose the aspect ratio [37]. The classic example is the sunspot series [6].

Line chart checklist. Use a zero baseline only when zero is meaningful for the comparison (unlike bars, lines do not encode length) [5]. Label lines directly at their ends rather than using a distant legend when there are only a few. Do not use two different y-axes on one chart: the apparent relationship between the series depends entirely on how the two scales were chosen. Plot two charts, or index both series to a common base [8].

12. Heatmaps

A heatmap shows a matrix of values as a grid of coloured cells. It encodes magnitude by colour, the least accurate channel in Figure 1, so it is suited to seeing patterns (blocks, gradients, outlying cells) across many values rather than to reading exact numbers [3]. Wilkinson and Friendly trace the display back to nineteenth-century shaded tables and describe the "cluster heat map", in which rows and columns are reordered by hierarchical clustering so that similar ones sit together [38].

The colour scale must match the data [39,40]:

  • Sequential scales (one hue, light to dark) for magnitudes that run from low to high.
  • Diverging scales (two hues meeting at a neutral midpoint) for data with a meaningful centre, such as anomalies, differences or correlations.
  • Never a rainbow for ordered data. Rainbow scales are not perceptually uniform: they create visible boundaries where the data have none, and they are unreadable for colour-vision-deficient readers [40].

The heatmap of a correlation matrix, sometimes called a corrgram, is a compact companion to the pair plot of the next section [41]. The Longley data were published to test the numerical accuracy of regression programs: their predictors are so highly correlated that early software gave wrong answers [16]. The heatmap makes the near-collinearity visible at a glance.

import numpy as np
import statsmodels.api as sm

13. Pair plots

A pair plot (scatter-plot matrix, SPLOM) arranges the scatter plots of every pair of p variables in a p × p grid, with the same variable on the same axis across each row and down each column [42,6]. The cells above the diagonal mirror those below, so either half alone holds all the information; the full matrix makes scanning along a row easier.

14. Q–Q plots

For a normal Q–Q plot, the i-th smallest observation x(i) is plotted against the standard normal quantile at a plotting position pi. Blom's positions are a common choice [44]:

Normal Q–Q plotpoints (Φ−1(pi), x(i)),   pi = i − 3/8n + 1/4,   i = 1, …, n

15. Empirical cumulative distribution functions

The empirical CDF of a sample is the proportion of observations less than or equal to each value:

Empirical CDFFn(x) = 1n ∑i=1n 𝟙(xi ≤ x)

Its graph is a step function that jumps by 1/n at each observation (by k/n at a value shared by k observations). Unlike a histogram or KDE, it has no tuning parameter and loses no information: every quantile can be read off the vertical axis, and the median is where the curve crosses 0.5 [46]. Overlaid ECDFs are an excellent way to compare several groups, because the curves rarely hide one another.

The Dvoretzky–Kiefer–Wolfowitz (DKW) inequality, with the tight constant proved by Massart, gives a confidence band that contains the whole true CDF with probability at least 1 − α [47,48]:

DKW confidence bandFn(x) ± ε,   ε = √( ln(2/α) / (2n) )

The largest vertical distance between two ECDFs is the two-sample Kolmogorov–Smirnov statistic D, so the ECDF plot is also the picture of that test [46].

16. Error bars and confidence intervals

An error bar is a line through a point estimate that shows uncertainty or variability. The same-looking bar can represent quite different quantities, and readers often misread them [49,50]:

Bar showsHalf-widthDescribesShrinks with n?
Standard deviation (SD)sSpread of individual observationsNo
Standard error (SE)s/√nSampling variability of the meanYes
95% confidence intervalt0.975, n−1 · s/√nPlausible range for the population meanYes

The rule is to always state in the caption what the bars represent and give n [49,50]. For inference about means, the 95% CI is usually the most useful. An SE bar is only about half as long as a 95% CI, so it makes differences look more convincing than they are.

Reading overlap. Cumming and Finch give rules of thumb for two independent means with 95% CIs, when n ≥ 10 in each group and the arms are of similar length [49]:

  • if the intervals overlap by about half the average arm length, p ≈ 0.05;
  • if they just touch (no overlap, no gap), p ≈ 0.01.

Two common errors follow. Overlapping 95% CIs do not imply a non-significant difference: intervals can overlap by up to about a quarter of their total length and the difference can still be significant at 5%. And the rules do not apply to repeated measures on the same subjects, where the relevant interval is the CI of the paired differences [49].

Bar-plus-error-bar ("dynamite plunger") charts hide the data. A bar from zero to the mean, topped with an SE whisker, conceals the sample size, the distribution and any outliers. Show the points with the mean and CI, as in Figure 18, or use a box or violin plot [23].

17. Multivariate visualization

Screens and paper have two dimensions; most data sets have more. Strategies for showing more than two variables include [6,8]:

  • Extra visual channels: colour, marker shape and size added to a scatter plot. Shape and colour suit categories (as for species throughout this article); size (a bubble chart) suits a third numeric variable, scaled by area, not radius (see Figure 22).
  • Small multiples (faceting, trellis displays): the same chart repeated for each level of a conditioning variable, on shared axes, so differences can be compared by position [7,6]. Figures 3, 9 and 23 are small multiples.
  • Pair plots and correlation heatmaps (Sections 12 and 13).
  • Parallel coordinates: one vertical axis per variable, with each observation drawn as a polyline across the axes [52,53].
  • Projections: principal component analysis (PCA) and other dimension-reduction methods, shown as score plots or biplots [54,55].
  • Glyphs: star plots, or Chernoff faces, which map variables to facial features [56]. These are memorable but hard to read precisely, because they rely on low-ranked channels.

PCA finds orthogonal directions of maximal variance. With standardised variables, the components are the eigenvectors of the correlation matrix and each eigenvalue is the variance it explains [55]. Gabriel's biplot draws the observation scores for the first two components as points and the variable loadings as arrows on the same axes [54]. Points far along an arrow have high values of that variable, and arrows pointing the same way indicate positively correlated variables.

18. Visualization ethics and misleading graphs

A graph can mislead without containing a single false number. Huff's How to Lie with Statistics [57], Wainer's "How to display data badly" [58] and Cairo's How Charts Lie [59] catalogue the techniques. In a controlled experiment, Pandey and colleagues showed that truncated axes, area-as-quantity encodings and inverted axes measurably changed what viewers concluded from charts [60]. The American Statistical Association's ethical guidelines ask statisticians to communicate results honestly and in a way that does not mislead, including stating the limitations of the data and methods [61].

The lie factor

Tufte proposed a simple measure of graphical distortion [7]:

Tufte's lie factorLie factor = size of effect shown in graphicsize of effect in data,   where effect = |second value − first value|first value

A faithful graph has a lie factor near 1. Tufte suggested that values outside 0.95–1.05 indicate substantial distortion [7].

Truncation is legitimate for position-based displays such as dot plots and line charts, where no length is being compared. There, an axis that hugs the data is often better because it uses the space for the variation. The rule "start at zero" applies to bars and areas [5,8].

Exercise 6 — Which dot plot?

Exercise 7 — Lie factor

Exercise 8 — Error bars

Exercise 9 — Overlapping confidence intervals

Two independent groups, each large, have 95% CIs with arms of 2.0 units. The means differ by 3.0. Use Cumming and Finch's rule to estimate p, then compute it with a z-test.

Show solution

The overlap is 2.0 + 2.0 − 3.0 = 1.0 unit, half the average arm, so the rule gives p ≈ 0.05 [49]. Exactly: each SE = 2.0/1.96 = 1.020, so the SE of the difference is 1.020 × √2 = 1.443, z = 3.0/1.443 = 2.08 and two-sided p = 0.038. The rule is approximate but in the right range, and it shows that overlapping CIs can still mean a significant difference.

import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from scipy import stats
from sklearn.datasets import load_iris

def plot_ecdfs(groups, ax=None, xlabel=""):
    """Overlay the ECDF of each group (dict: name -> 1-D array)."""
    ax = ax or plt.gca()
    for name, x in groups.items():
        x = np.sort(np.asarray(x))
        ax.step(x, np.arange(1, x.size + 1) / x.size, where="post", label=name)
    ax.set_ylim(0, 1); ax.set_xlabel(xlabel); ax.set_ylabel("Proportion ≤ x")
    ax.legend(frameon=False)
    return ax
