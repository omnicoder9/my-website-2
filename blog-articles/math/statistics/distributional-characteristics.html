Distributional Characteristics

How to describe where a distribution sits, how it spreads, which way it leans, how heavy its tails are and how many peaks it has, with formulas, Python code, diagrams and exercises.

Updated 26 October 2026 · Python 3 with NumPy and SciPy[1,2]

1Location, scale and shape

A distribution is the full description of how the values of a random variable are spread out. For a random variable it is fixed by the cumulative distribution function (CDF) . For a sample it is described by the empirical CDF .[3] Distributional characteristics are the numbers and pictures that summarise without listing it in full.

These summaries fall into three families. Location says where the distribution sits (mean, median, mode). Scale says how spread out it is (standard deviation, interquartile range). Shape is everything that is left once location and scale have been removed: lean (skewness), tail weight (kurtosis and tail index), symmetry, and the number of peaks (modality).[4] This article covers the quantile-based tools first, then the moment-based tools, then the shape features that both are used to describe.

The second quartile, the fifth decile and the 50th percentile are all the median. The interquartile range is the width of the middle half of the data. Here it is ms. Because it ignores the outer quarters, the IQR has a 25% breakdown point: up to a quarter of the data can be moved arbitrarily far without making it arbitrarily large.[7] The standard deviation has a breakdown point of zero, since one bad value can inflate it without limit.

Ratios of deciles are common in applied work. Income inequality is often reported as the ratio, and the 10–90 percentile range is a scale measure that is less robust than the IQR but more sensitive to the tails.

Hinges are not always quartiles

Tukey's box plot uses hinges, which are the medians of the lower and upper halves of the data, with the median counted in both halves when is odd.[8] Hinges coincide with some quartile definitions for some and not for others, and Frigge, Hoaglin and Iglewicz found that statistical packages draw box plots with several different quartile rules.[9] For our the hinges are 49 and 60.5, identical to the type 7 quartiles.

from scipy import stats

6Skewness

Skewness describes asymmetry: whether one tail of the distribution is longer or heavier than the other. Karl Pearson introduced the term in his 1895 work on skew frequency curves.[12]

Moment skewness

The population skewness is the third standardized moment,

It is positive when the right tail dominates (right-skewed), negative when the left tail dominates, and zero for every symmetric distribution that has a third moment. Joanes and Gill compared the three sample estimators used by common packages:[11]

They converge as grows but differ noticeably in small samples. Joanes and Gill compared their bias and mean squared error and found that none of the three is best in every situation, so the choice matters less than reporting which one was used.[11]

The mean–median–mode rule is not a theorem

Textbooks often say that in a right-skewed distribution the mean exceeds the median, which exceeds the mode. That holds for many textbook continuous densities such as the gamma family, but von Hippel showed that it fails often, particularly for discrete distributions and for distributions where one tail is long and the other heavy.[13] A positive does not guarantee that the mean is above the median. Use the rule only as a heuristic.

c3_robust_shape.py
import numpy as np

def bowley_skewness(x):
    q1, q2, q3 = np.quantile(x, [0.25, 0.5, 0.75])
    return (q3 + q1 - 2 * q2) / (q3 - q1)

def moors_kurtosis(x):
    e = np.quantile(x, np.arange(1, 8) / 8)   # octiles E1..E7
    return ((e[6] - e[4]) + (e[2] - e[0])) / (e[5] - e[1])

def modified_z(x):
    x = np.asarray(x, dtype=float)
    med = np.median(x)
    mad = np.median(np.abs(x - med))
    return 0.6745 * (x - med) / mad

x = np.array([42, 45, 47, 48, 50, 51, 52, 54, 55, 57, 59, 62, 66, 71, 118])

9Modality

A mode is a local maximum of the density (or of the probability mass function for discrete data). A distribution with one mode is unimodal, with two bimodal, with more multimodal. A uniform distribution has no unique mode. Multiple modes usually signal a mixture of subpopulations, such as two machine types, two customer segments, or cached versus uncached requests.

Mixtures are not automatically bimodal

Combining two groups does not always produce two peaks. For an equal-weight mixture of two normal distributions with common standard deviation , the mixture is bimodal only if the means differ by more than .[20] Schilling, Watkins and Watkins used this result to show that adult human height, a mixture of the female and male distributions, is not bimodal, because the difference between the sexes is smaller than this threshold.[20]

Detecting modes in data

Histograms and kernel density estimates (KDEs) show modes, but the number of modes depends on the bin width or bandwidth. Too small a bandwidth produces spurious bumps. Too large a bandwidth merges real ones. Silverman turned this dependence into a test: find the smallest bandwidth at which the KDE has modes, and use the bootstrap to judge whether that bandwidth is unusually large.[21] Hartigan and Hartigan's dip test measures the maximum distance between the empirical CDF and the closest unimodal CDF, and rejects unimodality when the distance is large.[22] In Python, the dip test is available in the third-party diptest package. In R it is in the diptest package.

c4_modes.py
import numpy as np
from scipy import stats

def count_modes(x, bw, grid_size=2000):
    """Number of local maxima of a Gaussian KDE with bandwidth factor bw."""
    kde = stats.gaussian_kde(x, bw_method=bw)
    grid = np.linspace(x.min() - 3 * x.std(), x.max() + 3 * x.std(), grid_size)
    d = kde(grid)
    return int(np.sum((d[1:-1] > d[:-2]) & (d[1:-1] > d[2:])))

rng = np.random.default_rng(42)
for delta in (0.75, 1.6):
    x = np.concatenate([rng.normal(-delta, 1, 2000), rng.normal(delta, 1, 2000)])
    counts = {bw: count_modes(x, bw) for bw in (0.05, 0.1, 0.2, 0.4)}
    print(f"delta={delta}: modes by bandwidth {counts}")

10Outliers

Barnett and Lewis define an outlier as an observation that appears to be inconsistent with the remainder of the data.[23] "Inconsistent" depends on a model: 118 ms is surprising under a roughly normal model for response times, and much less surprising under a heavy-tailed one. An outlier can be a recording error, a member of a different population, or a legitimate extreme value. The statistics can flag a point. Deciding which kind it is requires knowledge of how the data were produced.

Tukey's fences

Points beyond or are flagged as mild outliers, and points beyond as extreme.[6,8] The rule uses only quartiles, so the outliers it is looking for cannot distort it. For the running example the fences are 31.75 and 77.75 (inner) and 14.5 and 95 (outer), and 118 is extreme. For normally distributed data, about 0.7% of observations fall beyond the inner fences (the fences sit at , a direct calculation from the normal CDF) even though none of them is anomalous, so with large samples the rule always flags some points.

11Heavy-tailed distributions

A distribution is heavy-tailed (on the right) if its tail decays more slowly than any exponential, that is, if[26]

The exponential distribution is the boundary case. The normal, exponential, gamma and Laplace distributions are light-tailed. The log-normal, Weibull with shape below 1, Pareto, Student and Cauchy distributions are heavy-tailed. Within the heavy-tailed class, Foss, Korshunov and Zachary distinguish nested subclasses: long-tailed, subexponential and regularly varying.[26]

Power-law tails

The most important subclass for applications has a power-law or Pareto tail,

with tail index . Then only for . With the kurtosis does not exist. With the variance is infinite, and with even the mean is infinite. Mandelbrot found that daily cotton price changes fitted such tails better than the normal distribution, which started the study of heavy tails in finance.[27]

Consequences

The largest value dominates. For subexponential distributions, as : when a sum is very large, it is because one term is very large.[26] Total insurance losses in a bad year are typically dominated by a single catastrophe.

Moment summaries become unreliable. When the variance is infinite, the sample variance keeps growing as increases. When the fourth moment is infinite, sample kurtosis does not settle down. Quantiles, the IQR and the tail index remain well defined.

Heavy tails and high kurtosis are different things. The Laplace distribution has excess kurtosis 3 but is light-tailed in the sense above. The log-normal is heavy-tailed but has all its moments. Kurtosis compares a distribution with the normal at the scale of the standard deviation. Tail heaviness is about the limiting behaviour of .

Estimating the tail index

c5_tails.py
import numpy as np

def hill(x, k):
    """Hill (1975) estimate of the tail index alpha from the k largest values."""
    xs = np.sort(np.asarray(x, dtype=float))[::-1]
    return 1.0 / np.mean(np.log(xs[:k]) - np.log(xs[k]))

rng = np.random.default_rng(7)
alpha = 1.5
pareto = rng.pareto(alpha, 100_000) + 1.0     # classical Pareto, x_m = 1
expo = rng.exponential(1.0, 100_000) + 1.0

12Distribution shape: putting it together

Once location and scale are removed, what remains is shape. Standardized moments, quantile ratios and the other measures in this article are all shape descriptors because they are invariant to with . A compact way to compare shapes is the skewness–kurtosis plane used by Pearson to organise his system of frequency curves.[4,17] Each distribution is a point or curve in the plane, where .

L-moments

Conventional moments raise deviations to the third and fourth power, which gives extreme values great weight. Hosking's L-moments are expectations of linear combinations of order statistics. They exist whenever the mean exists, they are less sensitive to outliers, and the L-skewness and L-kurtosis ratios are bounded.[29] SciPy provides them as scipy.stats.lmoment in recent versions.

    import numpy as np

def quantile_type6(x, p):
    """Hyndman-Fan type 6: Q(p) at position h = (n + 1) p, clamped to the data."""
    xs = np.sort(np.asarray(x, dtype=float))
    n = xs.size
    h = (n + 1) * p                      # 1-based position
    if h <= 1:
        return xs[0]
    if h >= n:
        return xs[-1]
    j = int(np.floor(h))
    return xs[j - 1] + (h - j) * (xs[j] - xs[j - 1])
