1Overview

A loop runs the same block of code repeatedly. Python has two loop statements. The for statement iterates over the elements of a sequence such as a string, tuple or list, or of any other iterable object, and the while statement repeats as long as an expression is true.[1] Both are compound statements: a header that ends in a colon, followed by an indented block of statements that the reference manual calls a suite.[1]

Three simple statements change what happens inside a loop. break ends the loop early, continue skips to the next cycle, and pass does nothing at all.[2] Both loop statements also accept an optional else clause, which runs only when the loop ends without a break.[1,3]

StatementWhat it doesTypical use
for x in it:Runs the body once for each item the iterable producesProcessing every element of a collection, counting with range()
while cond:Tests the condition before each pass and runs the body while it is trueRepeating until something changes: input is valid, a value converges, data runs out
breakTerminates the nearest enclosing loop and skips its elseStopping a search once the answer is found
continueStarts the next cycle of the nearest enclosing loopSkipping items that need no processing
passNothing; a null operationA placeholder where a statement is required
else: on a loopRuns when the loop finishes without breakReporting that a search found nothing

2for loops

The language reference gives the for statement this grammar:[1]

Grammar
for_stmt: "for" target_list "in" starred_expression_list ":" suite
          ["else" ":" suite]

The expression after in is evaluated once and must produce an iterable object. Python creates an iterator for it, assigns each item the iterator provides to the target list using the normal assignment rules, and executes the suite once per item. When the iterator is exhausted, the else suite runs, if there is one, and the loop terminates.[1] Python's for therefore walks over the items of a sequence in the order they appear, rather than stepping a numeric counter as C-style loops do.[3]

2.1 Iterables and iterators

An iterable is an object capable of returning its members one at a time. All sequence types (list, str, tuple) are iterables, and so are some non-sequence types such as dict and file objects.[4] Passing an iterable to the built-in iter() returns an iterator, an object whose __next__() method returns successive items and raises StopIteration once no data remain.[4,5] A for loop does this for you, holding the iterator in a temporary unnamed variable for the duration of the loop.[4]

The example below steps an iterator by hand, then rewrites a for loop as the equivalent while loop to show the protocol at work.[6]

2.2 Counting with range()

Despite looking like a function call, range is an immutable sequence type.[5] It is commonly used for looping a specific number of times. Its arguments are start (default 0), stop, and step (default 1), and a step of zero raises ValueError.[6] The end point is never part of the generated sequence, so range(10) produces exactly 10 values, which are the legal indices of a 10-item sequence.[3] A range object takes the same small amount of memory however large it is, because it stores only start, stop and step and calculates items as needed.[6]

2.3 Looping techniques

The standard library provides helpers that make loops clearer than manual index arithmetic:

  • dict.items() retrieves each key and its value together.[7]
  • enumerate(iterable, start=0) yields pairs of a count and an item, so you get the position and the value at the same time.[5,7]
  • zip() pairs up the entries of two or more iterables so you can loop over them in parallel.[7]
  • reversed() returns a reverse iterator over a sequence.[5,7]
  • sorted() returns a new sorted list and leaves the source unaltered. Its key argument names a function that extracts a comparison key from each item.[7,5]
Style tip

When you need both an index and a value, prefer for i, item in enumerate(seq) to for i in range(len(seq)) followed by seq[i]. It reads more directly, and it also works on iterables that cannot be indexed, such as files and generators.

2.4 Uneven lengths and zip(strict=True)

By default zip() stops as soon as the shortest input is exhausted. PEP 618 points out that this default lets faulty refactoring or logic errors silently lose data. Since Python 3.10, passing strict=True raises ValueError if one argument runs out before the others.[8]

2.5 What happens to the loop variable

Each iteration assigns the next item to the target variable, overwriting anything assigned to it earlier, including assignments made inside the loop body. Reassigning the variable in the body therefore has no effect on the next iteration. The variable is not deleted when the loop ends, so it keeps the last value it held. If the iterable was empty, the loop never assigns it at all.[1]

2.6 Changing a collection while you loop over it

The tutorial warns that code which modifies a collection while iterating over that same collection can be tricky to get right. It is usually simpler to loop over a copy, or to build a new collection.[3,7]

3while loops

Grammar
while_stmt: "while" assignment_expression ":" suite
            ["else" ":" suite]

A while loop tests its expression and, if it is true, executes the suite, then tests again. When the expression is false, which may be the very first time it is tested, the else suite runs if present and the loop terminates.[1] Because the test comes first, the body of a while loop can run zero times.

Use while when you cannot say in advance how many repetitions you need. Something inside the body must eventually make the condition false, or the loop never ends.

3.1 while True with break

When the natural place to decide whether to stop is in the middle of the body, write while True: and leave with break. Input validation is the classic case. The example below feeds in canned replies so it runs without a keyboard; in a real program ask() would call input().

3.2 Emulating a do-while loop

Some languages have a do ... while loop that always runs its body at least once. Python does not: for and while are its only loop statements.[1] The usual substitute is while True: with the exit test at the end of the body.

3.3 Assignment expressions in the condition

The assignment expression operator :=, added in Python 3.8, assigns a value to a name and also returns that value. It needs no extra parentheses in a while header, which makes it a compact way to read a stream in chunks until no data remain.[9]

4Nested loops

A loop body can contain another loop. The inner loop runs to completion on every pass of the outer loop, so the inner body executes (outer count) × (inner count) times: 3 × 4 = 12 times in the multiplication table below.

4.1 Flattening nested loops with itertools.product

itertools.product() computes the Cartesian product of its input iterables and is roughly equivalent to nested for loops.[10] It saves one level of indentation when every combination is needed.

4.2 Leaving several loops at once

break and continue affect only the nearest enclosing loop.[2,3] Python has no labelled break for leaving an outer loop directly; PEP 3136 proposed labelled break and continue in 2007 and was rejected.[11] Three common patterns fill the gap:

  1. A flag variable that the outer loop checks after the inner loop ends.
  2. A function that wraps the loops and uses return, which leaves every loop in the function at once. This is usually the clearest choice.
  3. The for ... else idiom, where the inner loop's else runs continue and the line after it runs break. See section 8.

5break

break may appear only inside a for or while loop, and not inside a function or class definition nested within that loop. It terminates the nearest enclosing loop and skips that loop's optional else clause. If it ends a for loop, the loop variable keeps its current value.[2]

If break leaves a try statement that has a finally clause, the finally clause runs before the loop is really left.[2]

Python 3.14 and later

Placing break, continue or return inside a finally block, so that it leaves the block, now makes the compiler emit a SyntaxWarning, as specified by PEP 765.[12] The pattern above is fine because break sits in the try block, not in finally.

6continue

continue follows the same placement rule as break and continues with the next cycle of the nearest enclosing loop.[2] In a for loop that means the next item, or the else clause if there are no more items. In a while loop control goes back to testing the condition.[1]

Watch the update step

In a while loop, put the statement that moves toward the exit condition (here n += 1) before any continue. If continue skips it, the condition never changes and the loop runs forever.

7pass

pass is a null operation: when it executes, nothing happens.[2] It exists because Python's grammar requires at least one statement in a suite, so it fills that slot when the program needs no action. Common uses are minimal classes, such as custom exceptions, and placeholders for function or conditional bodies you have not written yet.[3] Many programmers write ... (the Ellipsis literal) for the same purpose, although it has no special meaning to Python.[3]

Inside a loop bodyEffect on this iterationEffect on the loop
passNone; the following statements still runNone
continueSkips the rest of the bodyMoves on to the next cycle
breakSkips the rest of the bodyEnds the loop and skips its else

8else with loops

Both loop statements accept an else clause. In a for loop it runs when the iterator is exhausted, and in a while loop it runs when the condition becomes false. In either case it does not run if the loop was ended by break.[1,3] A useful way to read it is as “no break”: the else block is where you handle the case where the loop never found a reason to stop early.

The tutorial's own example searches for factors. The else lines up with the inner for, not with the if, so it runs only when no divisor was found.[3]

The same clause on a while loop expresses “retry until success, or give up” without a separate success flag. The last part of this example also shows that else runs when the loop body never ran at all, because the iterator was exhausted immediately.[1]

When to use it

Loop else is clearest in short search loops where break means “found”. If the loop is long, or readers on your team are unfamiliar with the construct, a helper function that returns early may be easier to follow.

Forgetting that range() excludes stop[3]Off-by-one: the last value is missingUse range(1, n + 1) to include n
Condition never becomes falseThe program hangs in a while loopCheck that every path through the body, including continue, updates the condition
Changing a collection while iterating over it[3]Skipped items or RuntimeErrorIterate over a copy or build a new collection

Print the numbers 1 to 15. For multiples of 3 print Fizz instead, for multiples of 5 print Buzz, and for multiples of both print FizzBuzz.

Show solution

Exercise 2 Digit sum

while

Write digit_sum(n), which returns the sum of the decimal digits of an integer, using a while loop and arithmetic only (no conversion to str).

Show solution

n % 10 extracts the last digit and n //= 10 removes it. The loop stops when no digits remain, and for 0 the body never runs.
