1What bioinformatics is

Bioinformatics is the application of computer science, mathematics and statistics to biological information. A widely cited definition describes it as “conceptualising biology in terms of molecules … and applying informatics techniques … to understand and organise the information associated with these molecules, on a large scale” [1]. In practice the field has three intertwined jobs: building the data resources that store sequences, structures and annotations; developing algorithms and models that extract patterns from those data; and applying both to biological and medical questions [1,2].

The word itself predates the genome era. Paulien Hogeweg and Ben Hesper coined bioinformatica around 1970 for “the study of informatic processes in biotic systems”, a broader, theory-driven meaning than today’s data-centred usage [3]. In human biology the field now underpins clinical genome sequencing, drug-target discovery, the interpretation of disease variants and quantitative models of organs such as the heart [4,5].

The rest of this article follows the four pillars named in the brief. Genomics and proteomics produce the raw data; biological databases make the data findable and comparable; computational modeling turns mechanisms into equations that can be simulated; and statistical analysis decides which patterns are real.

2A short history

Bioinformatics grew out of three older threads: molecular structure determination, protein sequence comparison and the collection of sequence data in shared archives [3,6]. The timeline below lists landmarks most relevant to human biology.

  2. 1958

  9. 1982–88

  10. 1990

  11. 2001–04

  16. 2024

3Core concepts: sequences, scoring and alignment

3.1 Sequences as strings

Computationally, DNA is a string over the alphabet {A, C, G, T} and a protein is a string over 20 amino-acid letters. Many core questions reduce to string problems: does a read match the reference genome, is this protein related to that one, where do genes start and stop [27]. Biopython provides tested implementations of the basic operations [28]:

Python
from Bio.Seq import Seq
from Bio.SeqUtils import gc_fraction

# 72-nt fragment encoding residues 1-24 of human p53 (TP53)
cds = Seq("ATGGAGGAGCCGCAGTCAGATCCTAGCGTCGAGCCCCCTCTGAGTCAGGAAACATTTTCAGACCTATGGAAA")

print(len(cds))                          # 72
print(round(gc_fraction(cds), 3))        # 0.528
print(cds.reverse_complement()[:30])     # TTTCCATAGGTCTGAAAATGTTTCCTGACT
print(cds.translate())                   # MEEPQSDPSVEPPLSQETFSDLWK

The translated product matches the first 24 residues of the UniProt reference sequence for p53, a good sanity check that the reading frame is correct [29].

3.2 Scoring similarity

To compare two sequences we need a score that rewards plausible evolutionary events and penalises implausible ones. For proteins, substitution matrices encode how often one amino acid replaces another in related proteins. Dayhoff’s PAM matrices were extrapolated from closely related sequences, one PAM unit corresponding to one accepted point mutation per 100 residues [13]. The BLOSUM family was instead computed directly from conserved blocks of more distant proteins; BLOSUM62, built from sequences clustered at 62% identity, is the default in most protein searches [30]. Gaps (insertions or deletions) receive separate penalties, usually an opening cost plus a smaller extension cost [27].

3.3 Dynamic programming: a worked example

The Needleman–Wunsch algorithm finds the best-scoring global alignment by filling a matrix F in which each cell holds the best score for aligning the first i letters of one sequence with the first j of the other [10]:

F(i,j) = max{ F(i−1,j−1) + s(ai,bj),  F(i−1,j) + g,  F(i,j−1) + g }

The algorithm runs in time proportional to the product of the sequence lengths [10,27]. Smith–Waterman modifies it for local alignment by adding zero as a fourth option, so poor regions are dropped rather than penalised [14]. The table shows the filled matrix for aligning GATTACA against GCATGCA with match = +1, mismatch = −1 and gap = −2. The highlighted cells trace the optimal path back from the bottom-right corner.

Python
import numpy as np

def needleman_wunsch(a, b, match=1, mismatch=-1, gap=-2):
    n, m = len(a), len(b)
    F = np.zeros((n + 1, m + 1), dtype=int)
    F[:, 0] = np.arange(n + 1) * gap
    F[0, :] = np.arange(m + 1) * gap
    for i in range(1, n + 1):
        for j in range(1, m + 1):
            s = match if a[i - 1] == b[j - 1] else mismatch
            F[i, j] = max(F[i - 1, j - 1] + s, F[i - 1, j] + gap, F[i, j - 1] + gap)
    # traceback
    i, j, top, bot = n, m, "", ""
    while i > 0 or j > 0:
        s = match if i and j and a[i - 1] == b[j - 1] else mismatch
        if i and j and F[i, j] == F[i - 1, j - 1] + s:
            top, bot, i, j = a[i - 1] + top, b[j - 1] + bot, i - 1, j - 1
        elif i and F[i, j] == F[i - 1, j] + gap:
            top, bot, i = a[i - 1] + top, "-" + bot, i - 1
        else:
            top, bot, j = "-" + top, b[j - 1] + bot, j - 1
    return int(F[n, m]), top, bot

print(needleman_wunsch("GATTACA", "GCATGCA"))   # (1, 'GATTACA', 'GCATGCA')

# The same result with Biopython's optimised aligner
from Bio import Align
aligner = Align.PairwiseAligner(mode="global", match_score=1,
                                mismatch_score=-1, gap_score=-2)
print(aligner.score("GATTACA", "GCATGCA"))       # 1.0

With these penalties the optimum has four matches, three mismatches and no gaps (score 4 − 3 = 1), because a single gap costs as much as two mismatches.

3.4 Heuristics and probabilistic models

Exact dynamic programming against a database of billions of residues is too slow for routine use. BLAST accelerates search by first finding short exact “word” hits and extending only those, and it reports an expect value (E) for the number of hits of that score expected by chance [17]. Profile hidden Markov models generalise substitution scores to position-specific probabilities learned from a family of aligned sequences, and are the basis of protein-domain databases and gene finders [27,31].

4Genomics and proteomics

4.1 The human genome

The haploid human genome is about 3.1 billion base pairs. The first gap-free assembly, T2T-CHM13, measures 3.055 billion bp and added roughly 8% of sequence that earlier references had left unresolved, mostly centromeric satellites and segmental duplications [25]. The 2004 finished assembly revised the protein-coding gene count down to 20,000–25,000 [21]; current GENCODE annotation lists roughly 20,000 protein-coding genes, alongside a larger number of non-coding genes [36].

Sequencing throughput rose and cost fell faster than Moore’s law after 2008: the cost of a human genome dropped from about US$100 million in 2001 to under US$1,000 by the early 2020s [37]. Short-read instruments produce hundreds of millions of 100–300 bp reads per run [22], while long-read platforms produce reads of tens of kilobases that resolve repeats and structural variants [38,39].

4.2 From reads to variants

A standard germline resequencing pipeline aligns reads to a reference, marks duplicates, recalibrates base qualities and calls variants [40]. Each stage has a widely used tool and an output format:

BWA indexes the reference with the Burrows–Wheeler transform so that reads can be placed in time that scales with read length rather than genome size [41]. Population reference panels then put each variant in context. The 1000 Genomes Project catalogued over 88 million variants across 2,504 individuals [23], and gnomAD aggregated exome and genome data from 141,456 people to measure how strongly each gene resists loss-of-function variation [42]. Clinical laboratories classify variants into five tiers (pathogenic, likely pathogenic, uncertain significance, likely benign, benign) under ACMG/AMP guidelines that combine population frequency, computational predictions, segregation and functional data [5].

4.3 Transcriptomics

RNA sequencing measures gene expression by counting reads derived from each transcript [44,45]. Its output is a genes × samples matrix of non-negative integer counts, which shapes the statistical methods used to analyse it (Section 7). Single-cell RNA-seq extends this to thousands of individual cells per experiment, and the Human Cell Atlas aims to use it to map every human cell type [46,47].

4.4 Proteomics

The term proteome, the full complement of proteins expressed by a genome, was introduced by Wilkins and colleagues in the mid-1990s [48]. Most large-scale proteomics today is “bottom-up” mass spectrometry: proteins are digested with trypsin, which cleaves after lysine and arginine, and the resulting peptides are separated by liquid chromatography and fragmented in a tandem mass spectrometer [49]. Software then matches each fragment spectrum to theoretical spectra of peptides from a sequence database [49,50].

Because millions of spectra are searched, false matches are inevitable. The target–decoy strategy estimates the false discovery rate by also searching reversed or shuffled “decoy” sequences: decoy hits above a score threshold estimate how many target hits above it are wrong [51]. The in-silico digestion below shows the first step of database search, computing peptide masses from the N-terminal region of p53:

Python
import re
from Bio.SeqUtils import molecular_weight

# Residues 1-65 of human p53 (UniProt P04637)
protein = "MEEPQSDPSVEPPLSQETFSDLWKLLPENNVLSPLPSQAMDDLMLSPDDIEQWFTEDPGPDEAPR"

# Trypsin rule: cut after K or R, but not before P
peptides = re.sub(r"(?<=[KR])(?!P)", " ", protein).split()
for pep in peptides:
    mass = molecular_weight(pep, seq_type="protein", monoisotopic=True)
    print(f"{pep:<45} {mass:10.4f} Da")

# MEEPQSDPSVEPPLSQETFSDLWK                       2775.2585 Da
# LLPENNVLSPLPSQAMDDLMLSPDDIEQWFTEDPGPDEAPR      4591.1411 Da

In 2014 two groups published draft maps of the human proteome, each detecting products of roughly 17,000–18,000 genes [52,53]. The Human Protein Atlas added antibody-based localisation across tissues [54], and by 2020 the HUPO Human Proteome Project reported high-stringency mass-spectrometry evidence for more than 90% of predicted human proteins [55]. Raw proteomics data are deposited in PRIDE and other ProteomeXchange repositories [56].

4.5 Structural bioinformatics

Sequence determines structure, and structure determines function. The Protein Data Bank held more than 200,000 experimentally determined structures by 2023 [57]. Since 1994 the biennial CASP experiment has tested prediction methods blind against newly solved structures [58]. At CASP14 in 2020, AlphaFold reached accuracy competitive with experiment for most targets [24]. Applied to the human proteome, it produced models for 98.5% of human proteins, with 58% of residues predicted confidently [59]. The AlphaFold Protein Structure Database now covers more than 214 million sequences [60], and AlphaFold 3 extends prediction to complexes with nucleic acids, ligands and ions [61].

5.3 Data stewardship

The FAIR principles state that research data should be Findable, Accessible, Interoperable and Reusable, by machines as well as humans [72]. In practice that means persistent identifiers, rich metadata, open formats and controlled vocabularies such as the Gene Ontology [68,72]. Human genomic data add a further constraint: they are identifiable, so large cohorts such as UK Biobank grant access to approved researchers under governance agreements rather than publishing records openly [73].

6.1 Enzyme kinetics

The Michaelis–Menten equation, v = Vmax[S] / (Km + [S]), describes the rate of an enzyme-catalysed reaction as a function of substrate concentration [75]. Integrating it gives the time course of substrate depletion. The example uses SciPy’s ODE solver [83]:

Python
import numpy as np
from scipy.integrate import solve_ivp

Vmax, Km = 1.0, 0.5            # mM/min, mM

def rhs(t, y):
    S, P = y
    v = Vmax * S / (Km + S)
    return [-v, v]

sol = solve_ivp(rhs, (0, 10), [5.0, 0.0], t_eval=[0, 2, 4, 6, 8, 10])
print(np.round(sol.y[0], 3))   # substrate: [5.    3.22  1.577 0.342 0.012 0.   ]

Note the shape of the result: while [S] ≫ Km the enzyme is saturated and substrate falls almost linearly at about Vmax; once [S] drops below Km the decay becomes approximately exponential.

6.2 The Hodgkin–Huxley model

Hodgkin and Huxley’s 1952 model of the squid giant axon is the archetype of quantitative physiology. It represents the membrane as a capacitor in parallel with voltage-gated sodium and potassium conductances and a leak, with gating variables m, h and n obeying first-order kinetics [76]:

Cm dV/dt = Iext − ḡNam3h(V−ENa) − ḡKn4(V−EK) − ḡL(V−EL)

Denis Noble adapted the formalism to cardiac Purkinje fibres in 1962 [77], beginning a line of cardiac cell and whole-heart models now used to study arrhythmia and drug safety [4]. Models are exchanged in standard formats such as SBML so they can be rerun by others [84].

Python
import numpy as np
from scipy.integrate import solve_ivp

C, gNa, gK, gL = 1.0, 120.0, 36.0, 0.3          # uF/cm2, mS/cm2
ENa, EK, EL = 50.0, -77.0, -54.387              # mV (modern sign convention)

a_m = lambda V: 0.1 * (V + 40) / (1 - np.exp(-(V + 40) / 10))
b_m = lambda V: 4.0 * np.exp(-(V + 65) / 18)
a_h = lambda V: 0.07 * np.exp(-(V + 65) / 20)
b_h = lambda V: 1 / (1 + np.exp(-(V + 35) / 10))
a_n = lambda V: 0.01 * (V + 55) / (1 - np.exp(-(V + 55) / 10))
b_n = lambda V: 0.125 * np.exp(-(V + 65) / 80)
I_ext = lambda t: 10.0 if 5 <= t <= 6 else 0.0  # 1 ms pulse, uA/cm2

def hh(t, y):
    V, m, h, n = y
    I_ion = gNa * m**3 * h * (V - ENa) + gK * n**4 * (V - EK) + gL * (V - EL)
    return [(I_ext(t) - I_ion) / C,
            a_m(V) * (1 - m) - b_m(V) * m,
            a_h(V) * (1 - h) - b_h(V) * h,
            a_n(V) * (1 - n) - b_n(V) * n]

V0 = -65.0
y0 = [V0] + [a(V0) / (a(V0) + b(V0)) for a, b in [(a_m, b_m), (a_h, b_h), (a_n, b_n)]]
sol = solve_ivp(hh, (0, 30), y0, max_step=0.01, t_eval=np.linspace(0, 30, 1501))
V = sol.y[0]
print(f"peak {V.max():.1f} mV at {sol.t[V.argmax()]:.2f} ms")   # peak 39.1 mV at 7.52 ms

6.3 Constraint-based metabolic models

Kinetic parameters are unknown for most of metabolism, so genome-scale models instead use stoichiometry. Flux balance analysis assumes steady state (S·v = 0, where S is the stoichiometric matrix and v the flux vector), bounds each flux, and uses linear programming to find the flux distribution that maximises an objective such as biomass or ATP production [79]. Recon3D, a reconstruction of human metabolism, contains over 13,000 reactions and links them to protein structures and genetic variants [80]. A three-metabolite toy model shows the method:

Python
import numpy as np
from scipy.optimize import linprog

# Metabolites (rows): A, B, C.  Reactions (columns):
# v1: uptake -> A   v2: A -> B   v3: A -> C   v4: B + C -> biomass
S = np.array([[1, -1, -1,  0],
              [0,  1,  0, -1],
              [0,  0,  1, -1]])
bounds = [(0, 10), (0, 6), (0, None), (0, None)]   # uptake <= 10, v2 <= 6
res = linprog(c=[0, 0, 0, -1], A_eq=S, b_eq=np.zeros(3),
              bounds=bounds, method="highs")        # maximise v4
print(res.x, -res.fun)                              # [10. 5. 5. 5.] 5.0

Uptake is the binding constraint: ten units of A split evenly between B and C, supporting five units of biomass. Genome-scale analyses apply the same logic to thousands of reactions, for instance to predict which gene knockouts are lethal in a given tissue [79,80].

7Statistical analysis of biological data

Statistics has been part of human genetics from the start. Fisher’s 1918 paper reconciled Mendelian inheritance with continuous traits and introduced the analysis of variance [85]. Genome-scale data raise three particular problems: testing thousands to millions of hypotheses at once, modelling counts with complex variance, and separating biology from technical artefacts [86,87].

7.1 Multiple testing

If 20,000 genes are tested at α = 0.05 and none is truly changed, about 1,000 will still appear significant. The Bonferroni correction controls the chance of any false positive by testing at α/m, but it is very conservative. Benjamini and Hochberg instead control the false discovery rate (FDR), the expected proportion of false positives among discoveries [87]. The procedure sorts m p-values and finds the largest rank k for which p(k) ≤ (k/m)·q. Storey’s q-value generalises the idea by estimating the proportion of true null hypotheses [88].

7.2 Differential expression from RNA-seq counts

RNA-seq counts are overdispersed: their variance exceeds the mean, so the Poisson distribution fits poorly. DESeq2 and edgeR model counts with the negative binomial distribution and borrow information across genes to stabilise per-gene dispersion estimates, which matters when there are only a few replicates [89,90]. limma takes a different route, transforming counts and applying linear models with empirical-Bayes moderated variances [91]. All three are distributed through Bioconductor, the open-source R project for genomic analysis [92,93]. The example below analyses the airway dataset, RNA-seq of human airway smooth-muscle cells from four donors treated with the glucocorticoid dexamethasone or left untreated [94]:

R
# Bioconductor: BiocManager::install(c("DESeq2", "airway"))
library(DESeq2)
library(airway)

data(airway)                                   # SummarizedExperiment of counts
airway$dex <- relevel(airway$dex, ref = "untrt")

# Pairing on donor (cell line) removes donor-to-donor variation
dds <- DESeqDataSet(airway, design = ~ cell + dex)
dds <- dds[rowSums(counts(dds)) >= 10, ]       # drop near-empty genes
dds <- DESeq(dds)                              # size factors, dispersions, Wald tests

res <- results(dds, contrast = c("dex", "trt", "untrt"), alpha = 0.05)
summary(res)                                   # counts of up/down genes at FDR 5%
res <- res[order(res$padj), ]
head(res[, c("baseMean", "log2FoldChange", "padj")])

# Shrunken fold changes are better for ranking and plotting
res_shr <- lfcShrink(dds, coef = "dex_trt_vs_untrt", type = "apeglm")
plotMA(res_shr, ylim = c(-5, 5))

7.3 Genome-wide association studies

A GWAS tests hundreds of thousands to millions of common variants for association with a trait or disease [95]. The conventional genome-wide significance threshold, p < 5 × 10−8, corresponds to a Bonferroni correction for roughly one million independent common variants in European-ancestry genomes [96]. Quality control removes variants that deviate strongly from Hardy–Weinberg proportions in controls, a sign of genotyping error [95,97]. Because allele frequencies differ between ancestral populations, uncorrected population structure creates false associations; including the top principal components of the genotype matrix as covariates corrects much of it [98]. A single-variant allelic test looks like this:

Python
from scipy.stats import chi2_contingency, fisher_exact

#            allele A  allele a
table = [[420, 580],     # cases    (500 people, 1,000 alleles)
         [350, 650]]     # controls (500 people, 1,000 alleles)

chi2, p, dof, _ = chi2_contingency(table, correction=False)
odds_ratio, p_fisher = fisher_exact(table)
print(f"chi2={chi2:.2f}  p={p:.2e}  OR={odds_ratio:.2f}")
# chi2=10.35  p=1.30e-03  OR=1.34
print(p < 5e-8)   # False: nominally significant, far from genome-wide significance

The example illustrates why GWAS need large samples: an odds ratio of 1.34, larger than most common-variant effects [95], is nowhere near genome-wide significance with 500 cases and 500 controls. This is why cohorts like UK Biobank, with about half a million participants, have become central to the field [73].

7.4 High-dimensional data and batch effects

With far more features (genes) than samples, exploratory analysis relies on dimensionality reduction. Principal component analysis finds orthogonal directions of maximal variance and is the usual first look at any expression or genotype matrix [99]. Non-linear embeddings such as t-SNE are widely used to visualise single-cell data, but distances between clusters in these plots are not directly interpretable [47,100]. Supervised machine learning for prediction from such data requires regularisation and cross-validation to avoid overfitting [101].

Technical variables (processing date, reagent lot, sequencing run) often explain more variation than biology. When batch is confounded with the condition of interest, no statistical method can separate the two, so balanced experimental design is the first defence and batch terms in the model the second [86]. Finally, a p-value measures incompatibility between data and a model; it is not the probability that a hypothesis is true, nor a measure of effect size, and conclusions should not rest on whether it crosses a threshold [102].

import numpy as np

def pca(X, k=2):
    """X: samples x genes (log-scale). Returns scores and variance explained."""
    Xc = X - X.mean(axis=0)                      # centre each gene
    U, s, Vt = np.linalg.svd(Xc, full_matrices=False)
    scores = U[:, :k] * s[:k]
    var_explained = s**2 / np.sum(s**2)
    return scores, var_explained[:k]

8Outlook

Several trends are reshaping bioinformatics in human biology. Gap-free and long-read assemblies are exposing variation in regions that short reads could not reach [25,38]. Structure prediction has moved from a research problem to a routine database lookup [60,61]. Single-cell and spatial methods are turning tissue-level averages into cell-level maps [46]. Across all of these, the durable skills remain the ones described here: knowing the data formats and resources, understanding what an algorithm or model assumes, and applying statistics that respect the scale and structure of the data [2,86].
